# 快速上手

本指南帮你快速上手抖音保存，从拿到分享口令到保存无水印视频，全程只要几步。

抖音保存是一个纯粹的本地下载工具，装好就能用，不需要注册账号，也不会上传你的任何数据。

## 界面概览

打开 App，主界面非常简单，只有三块内容：

1. **输入框**：顶部一个多行输入框，用来粘贴抖音分享口令或视频链接。右边有个「粘贴」按钮，一键从剪贴板取链接。
2. **解析按钮**：输入框下面那个醒目的「解析视频」按钮，点了就开始解析。
3. **解析结果卡片**：解析完成后出现，显示标题、作者、内容类型（视频 / 图文 N 张），以及下载按钮和进度条。

宽屏设备（平板、桌面）会自动把内容居中限宽，看起来更舒服；手机上是全宽显示。

## 基础操作

### 第一步：在抖音复制分享口令

1. 打开抖音 App，找到想保存的视频或图文。
2. 点右侧的 **分享** 按钮（那个向右的箭头）。
3. 在分享面板里点 **复制链接**，或者在「分享给朋友」时选微信/QQ 之类的，系统会复制一段带链接的文字到剪贴板。

复制下来的内容通常长这样：

```
7.69 复制打开抖音，看看【xxx的好作品】 https://v.douyin.com/iAbCdEf/ 🔗
```

前面那串数字和后面的描述都无所谓，App 会自动从这段文字里把链接挑出来。

### 第二步：打开抖音保存粘贴口令

1. 打开抖音保存，光标停在输入框。
2. 点输入框右侧的 **粘贴按钮**（剪贴板图标），刚复制的口令会自动填进去。也可以手动长按输入框选「粘贴」。
3. 确认输入框里有口令后，点下面的 **解析视频** 按钮。

如果剪贴板是空的，会提示「剪贴板是空的」，回抖音重新复制一次就行。

### 第三步：解析并预览视频信息

1. 点完「解析视频」后，按钮下方会出现一个转圈，表示正在调用解析引擎。
2. 解析通常只要几秒，完成后下方弹出一张结果卡片：
   - **标题**：这条抖音的标题或描述文字
   - **作者**：发布者的昵称
   - **类型**：视频 或 图文 N 张，用图标区分
3. 确认这条内容是想要的，再进入下一步。

### 第四步：下载到本地

1. 在结果卡片里点 **下载视频** 按钮。
2. 按钮下方出现一条进度条和百分比，实时显示下载进度。
3. 等进度走到 100%，按钮变成 **已保存到下载文件夹**，下方显示具体保存路径。
4. 提示「已保存到下载文件夹」，去系统的下载目录就能找到这个文件。

下载完成后可以点 **下载下一个**，清空当前结果回到初始状态，继续保存下一条。

## 进阶操作

### 图文类型怎么看

抖音除了视频还有「图文」内容（图片轮播配音乐）。解析结果卡片里会明确标出：

- 显示 **视频** 图标 → 是普通视频，点下载保存的就是视频文件
- 显示 **图文 N 张** 图标 → 是图文类型，里面包含 N 张图片

当前版本以视频下载为主，图文类型会正确识别并显示张数。

### 查看保存位置

下载完成后，结果卡片里会显示完整保存路径，比如：

- **Android**：`/storage/emulated/0/Download/视频标题.mp4`
- **macOS / Windows**：系统下载目录下的 `视频标题.mp4`

文件名直接用视频标题（清理掉不能当文件名的字符），方便回找。如果标题为空，会兜底用 `douyin_时间戳` 命名。

### 宽屏与桌面使用

在平板、macOS、Windows 上用抖音保存时，界面会自动限宽居中，不会在大屏上拉得过宽。粘贴、解析、下载的操作流程和手机上完全一致。
