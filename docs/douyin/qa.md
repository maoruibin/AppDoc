# 常见问题

## 基础问题

### 抖音保存是什么？

抖音保存是一款纯粹的无水印抖音视频/图文下载工具。把抖音的分享口令或链接粘贴进来，App 会解析出无水印视频地址，一键保存到本地下载目录。

### 抖音保存是免费的吗？

是的，完全免费，没有内购，也不需要注册账号。

### 抖音保存支持哪些平台？

支持 Android、iOS、macOS、Windows 四个平台，一套代码多端运行。桌面端会自动适配宽屏布局。

### 抖音保存会联网上传我的数据吗？

不会。抖音保存是一个本地工具，不联网上传用户的任何数据。解析和下载时需要联网访问抖音，但那是去取视频信息，不是上传你的资料。详见 [隐私政策](private.md)。

## 解析相关

### 解析失败怎么办？

解析失败通常有几种原因，按顺序排查：

1. **链接格式不对**：确认粘贴的是抖音的分享口令或链接。App 会自动从一段文字里提取链接，但如果文字里压根没有抖音链接，会提示「未识别到抖音链接」。
2. **Chrome 没登录抖音**：解析需要 Chrome 浏览器里的抖音登录 cookie。用 Chrome 打开 [douyin.com](https://www.douyin.com) 确认已登录，必要时先关掉 Chrome 再重试。
3. **视频已被删除或不可访问**：如果原视频被作者删除或设为私密，会提示「视频可能已被删除或不可访问」，这种情况任何工具都救不回来。
4. **网络问题**：抖音服务器偶尔会拒绝请求，稍等几分钟重试一般就好。

### 为什么提示「未识别到抖音链接」？

说明粘贴进输入框的文字里没有找到抖音链接。常见情况：

- 复制的时候只复制了描述文字，没带上链接。
- 粘贴的是别的平台（比如快手、B 站）的链接，目前只支持抖音。

回抖音重新走一遍分享流程，确保点的是「复制链接」。

### 为什么需要 Chrome 登录抖音？

抖音的视频信息接口需要登录态才能正常返回数据。App 通过 yt-dlp 读取 Chrome 浏览器里已登录的抖音 cookie，相当于借了你浏览器的身份去请求，不需要你单独输入账号密码。

使用前请在 Chrome 浏览器里登录一次 [douyin.com](https://www.douyin.com)。如果遇到「Fresh cookies」之类的报错，去 Chrome 重新登录一下抖音，必要时关掉 Chrome 再试。

## 下载相关

### 下载下来的视频会有水印吗？

不会。下载时 App 显式指定 `play_addr` 这个无水印视频流，保存下来的是干净的原片，没有抖音平台水印。

### 下载速度很慢怎么办？

下载速度主要取决于你的网络和抖音服务器，App 本身不做限速。可以试试：

- 切换到更快的网络（比如从移动数据切到 WiFi）。
- 错开高峰时段重试。
- 如果一直很慢，可能是抖音对该 IP 限流，换个网络环境试试。

### 下载的视频保存在哪里？

统一保存到系统的下载目录：

- **Android**：系统下载文件夹（`Download/`）
- **iOS**：App 沙盒内的下载目录
- **macOS**：`~/Downloads`
- **Windows**：用户的下载文件夹

下载完成后，结果卡片上会显示完整的保存路径。文件名直接用视频标题。

### 能保存图文类型的抖音吗？

图文类型（多图配音乐）会被正确识别，结果卡片上会标出「图文 N 张」。当前版本以视频下载为主，图文里的图片列表会解析并展示出来。

### 视频质量怎么样？

下载的是抖音原始播放地址（`play_addr`），也就是作者上传后平台分发的最高清晰度版本，质量和你刷抖音时看到的一致，不会被二次压缩。

## 报错相关

### 提示「需要登录信息」怎么办？

说明 Chrome 里的抖音 cookie 失效了或读取不到。解决办法：

1. 用 Chrome 打开 [douyin.com](https://www.douyin.com)，确认登录状态正常。
2. 如果 Chrome 正在运行，yt-dlp 可能读不到 cookie，**先完全退出 Chrome**（关掉所有窗口和后台进程），再回 App 重试。
3. 实在不行，在 Chrome 里退出抖音再重新登录一次。

### 提示「抖音拒绝了请求」怎么办？

通常是抖音服务器临时限流或网络波动。等几分钟再试，或者切换一下网络（WiFi ↔ 移动数据）一般就能恢复。
