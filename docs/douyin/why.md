# 为什么做抖音保存

## 一个只想把抖音视频保存下来的小工具

抖音上经常能刷到想留存的内容：一个有用的教程、一段好玩的片段、一组好看的图文。但抖音自己的保存功能会给视频打上平台水印，分享到别的平台还会被二次压缩，画质糊一截。想要一个干净的、能直接存到本地的版本，反而要折腾半天。

抖音保存就是为这件事做的。它的全部逻辑就一句话：**粘贴口令，保存无水印**。

## 几条不变的原则

- **简单纯粹**。一个输入框、一个解析按钮、一个下载按钮，没了。不搞收藏夹、不搞云盘、不搞推荐流，更不会塞广告。打开 App 离"保存好这条视频"只有三步操作。

- **干净无水印**。解析的是抖音原始播放地址（`play_addr`），保存下来的就是作者上传后的原片质量，没有平台水印，不做二次压缩。

- **本地优先**。下载的文件直接落到你系统的下载目录，用任何文件管理器都能找到、能分享、能备份。App 本身不存你的数据，也不联网上传。

- **多端通用**。基于 Flutter 构建，Android、iOS、macOS、Windows 一套代码通吃，手机上能用、电脑上也能用。

## 站在 yt-dlp 的肩膀上

抖音的反爬机制一直在变，自己从头写解析很容易今天能用明天就失效。抖音保存直接基于成熟的开源工具 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 构建解析能力——它有活跃的社区在持续维护对各个平台的支持，稳定性比自己造轮子高得多。App 把 yt-dlp 二进制随包打包进去，开箱即用，不用你额外装东西。

登录态的处理也借力了浏览器：直接读 Chrome 里已登录的抖音 cookie，省去单独输账号密码的麻烦，也不会在你的设备上多存一份密码。

## 一点点私心

作为个人开发者，做抖音保存也是给自己造工具——我就是想要一个粘贴即存、没有水印、能跨设备用的保存器，市面上的同类工具要么塞满广告、要么只支持单一平台、要么解析三天两头失效。于是自己写一个，顺手分享出来。
