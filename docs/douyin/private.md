# 隐私政策

更新日期：2026 年 8 月 9 日

北京小茅屋科技有限公司（以下简称"我们"）深知个人信息对用户的重要性，《抖音保存》将按照法律法规的要求，采用相应安全保护措施来保护你的个人信息安全可控。

本《隐私政策》主要向你说明我们如何收集和使用你的个人信息、如何存储和保护、如何共享以及你如何管理你的个人信息等内容。请你认真阅读本政策，在确认充分理解并同意后使用我们的产品和服务。

##  1. 我们会收集什么信息？

《抖音保存》是一款纯粹的本地下载工具，非常重视用户的隐私保护，不联网上传用户的任何个人数据，不收集任何用户个人隐私信息。

### 使用数据

- 你粘贴进 App 的抖音分享口令仅在本机用于解析视频信息，不会上传到任何服务器
- 解析得到的视频信息（标题、作者、封面等）仅在你设备的屏幕上展示
- 下载的视频、图片文件直接保存到你的设备本地下载目录，不会经过任何中间服务器
- App 不需要注册账号，不收集任何个人身份信息

### 解析与下载时的网络行为

抖音保存在解析和下载时需要联网，但所有网络请求都是直接发往抖音服务器，目的是获取视频信息和无水印视频流：

- 解析时：通过内嵌的 yt-dlp 工具，携带本机 Chrome 浏览器里的抖音 cookie，请求抖音的 web 详情接口
- 下载时：直接从抖音返回的视频地址下载视频流到本地

这些请求过程中不经过我们或任何第三方的服务器，App 不会把你下载的内容、解析的链接回传给我们。

### 我们不会收集

- 不会收集你的通讯录、位置信息
- 不会收集你的设备标识符用于追踪
- 不会在后台偷偷上传你的任何数据
- 不会把你下载的视频、图片上传到任何服务器
- 不需要注册账号，不收集任何个人身份信息
- 不会读取 Chrome cookie 之外的其他浏览器数据，cookie 仅用于本机解析、不外传

##  2. 权限申请说明

| 权限 | 用途 |
|------|------|
| 存储权限 | 把下载的视频、图片保存到设备本地下载目录 |
| 网络权限 | 解析抖音视频信息、下载无水印视频流（请求直接发往抖音） |
| 剪贴板访问 | 仅在你主动点击"粘贴"按钮时读取剪贴板内容，不会自动读取或上传 |

抖音保存不会私自访问或修改你存储中的其他无关文件，仅向系统下载目录写入下载的文件。

##  3. 第三方工具与 cookie 说明

抖音保存基于开源工具 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 实现解析与下载能力。yt-dlp 在运行时：

- 会读取本机 Chrome 浏览器里抖音域名的 cookie，用于以登录态请求抖音接口。
- cookie 数据始终在本机处理，不会上传到任何服务器，也不会被 yt-dlp 收集。

这一过程相当于"借用"了你浏览器的登录身份去访问抖音，和你在 Chrome 里打开抖音网页是同一回事，不会额外暴露账号信息。

##  4. 数据的存储与安全

- 所有下载的视频、图片始终保存在你的设备本地，抖音保存不会将其上传或同步至云端。
- 解析过程中产生的临时数据（如 yt-dlp 的输出 JSON）仅用于本次解析，不会被持久化保存。
- 抖音保存不会将你的数据分享给任何第三方。

##  5. 信息的披露

《抖音保存》不会收集你的个人隐私信息，不会向他人分享这些信息，亦不会将其出售、出租以及其他方式分发给他人。

##  6. 未成年人信息及使用

《抖音保存》非常重视对未成年人个人信息的保护，我们希望未成年人仅在接受其父母或法定监护人指导、监督并经其同意的前提下使用。
