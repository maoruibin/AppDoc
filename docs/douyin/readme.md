# 抖音保存

<img src="../public/img/douyin_icon.png" width="13%" alt="抖音保存">

> 粘贴口令，保存无水印

抖音保存是一款纯粹的无水印抖音视频/图文下载工具。把抖音分享口令粘贴进来，App 自动解析出无水印地址，一键保存到本地。没有花哨功能，只想把"保存"这件事做顺、做干净。

## 核心功能

- **无水印视频下载**：解析抖音原始播放地址，保存下来的就是干净的视频，没有平台水印
- **图文类型支持**：抖音图文内容也能识别，自动区分视频和图文类型
- **多平台支持**：基于 Flutter 构建，同时覆盖 Android、iOS、macOS、Windows
- **解析预览**：下载前先看到标题、作者、类型，确认没问题再保存
- **实时进度**：下载过程显示百分比进度条，心里有数
- **本地保存**：下载完成的文件直接落到系统下载目录，用文件管理器就能找到
