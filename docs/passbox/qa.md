# 常见问题

## 安全相关

### PassBox 会把我的密码上传到服务器吗？

不会。PassBox 是纯本地应用，所有密码加密存储在你的设备本地，**永不上传**。云同步是你主动配置的 WebDAV 服务，数据直接传到你自己的网盘，不经过我们的服务器。

### 数据是怎么加密的？

所有敏感字段（账号、密码、备注、自定义属性）使用 **AES-256-GCM** 加密算法存储。这是目前业界最先进的加密标准之一，即使别人拿到了你的数据库文件，没有密钥也无法解密。

### 忘记 PIN 码怎么办？

很遗憾，PIN 码无法找回。设置时填写的「密码提示」是唯一的帮助。如果实在想不起来，只能卸载重装（数据会丢失），所以请务必牢记 PIN 码，或开启指纹解锁作为备用。

### 为什么没有「主密码」？

PassBox 的数据加密使用设备无关的内置密钥，多设备同步时无需在各端输入相同主密码。用户层面的安全验证靠 PIN + 指纹，这是刻意的设计取舍 —— 让安全对用户无感，同时保证数据始终加密。

### 指纹解锁失败怎么办？

指纹连续识别失败会自动回退到 PIN 码输入。如果设备的指纹硬件未录入指纹，App 会提示你去系统设置中录入。

### 多任务切换时别人会看到我的密码吗？

不会。退到后台时 PassBox 会用不透明遮罩盖住整个界面，多任务切换的预览图看不到任何内容。

## 使用相关

### 为什么搜索找不到某些密码？

PassBox 支持**全字段解密搜索**，可以搜名称、账号、备注、自定义属性值和附件名。如果搜不到，可能是关键词与实际内容不完全一致——搜索需要包含完整词（不支持模糊/拼音）。建议给密码起一个容易记住的名称作为兜底。

### 为什么列表顺序会变？

PassBox 按最近访问时间 + 访问频率自动排序，你最近看过、看得多的密码会自动排到前面。这是为了让常用密码触手可及，无需手动整理。

### 一条密码最多能加几个标签？

最多 3 个。标签用于分类筛选，底部标签栏会自动汇总所有标签。

### 自定义属性是什么？

除了名称、账号、密码、备注外，你还可以给密码附加键值对，比如「链接 → google.com」「安全问题 → 我的家乡」。免费版最多 1 个自定义属性，PRO 版无限制。

### 附件是什么？怎么加？

附件可以给密码条目挂上图片（身份证、银行卡照片）、PDF 或任意文件。打开密码详情，点附件区的「+」，可从相册选、拍照或选文件。附件会以 AES-256-GCM 加密存储，PRO 用户还能随 WebDAV 云同步。

::: tip 附件上限
每个密码条目最多 18 个附件，附件功能为 PRO 专属。
:::

### 复制的密码会一直在剪贴板里吗？

不会。复制后 **30 秒自动清除**，最后 5 秒会有红色闪烁提醒。清除前会校验剪贴板内容，如果你期间复制了其他文本，不会被误删。

## 同步相关

### WebDAV 同步支持哪些网盘？

支持任何标准 WebDAV 服务，实测推荐：

- **坚果云**（国内首选，需用「应用密码」而非登录密码）
- **Nextcloud**
- **NAS**（群晖等自建 WebDAV）

### 坚果云连不上？

坚果云需要在官网「安全选项 → 第三方应用管理」里生成一个**应用密码**，用它代替登录密码填入 PassBox。

### 多设备编辑会冲突吗？

不会。同步采用基于更新时间的智能合并（Last-Write-Wins）：同一条密码，哪边改得新就保留哪边，不会互相覆盖丢失数据。

### 换手机了怎么迁移数据？

有三种方式：

1. **WebDAV 同步**（推荐）：新手机装好 App，配置同一个 WebDAV 账号，自动拉取数据
2. **加密备份**：旧手机导出加密密文，新手机粘贴导入
3. **从其他平台导入**：如果是第一次用，可从 Chrome / Bitwarden 导入

## 其他

### 怎么生成强密码？

添加或编辑密码时，点密码框右侧的 **⚡** 图标，可自定义长度（8-32 位）和字符集，一键生成。

### 怎么关闭应用锁？

路径：**设置 → 通用 → 应用锁**，可以关闭。但不推荐，关闭后任何人都能直接打开 App。

### 注销账号会怎样？

注销账号会永久删除账号及关联的权益数据，不可恢复。需要输入「注销账号」四个字确认。本地密码数据不会因注销账号而删除。
