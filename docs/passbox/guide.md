# 使用指南

本指南帮助你快速上手 PassBox，安全地管理你的各类密码。

## 首次使用

### 1. 设置 PIN 码

首次打开 App 会要求设置一个 6 位数字 PIN 码，这是打开应用的主验证方式。

1. 输入 6 位数字
2. 再次输入确认
3. 设置一个密码提示（最多 50 字，如「我的生日」），防止遗忘

> PIN 码以 SHA-256 哈希加盐存储，绝不保存明文。忘记 PIN 只能通过提示回忆，无法找回，请务必牢记。

### 2. 开启指纹解锁（可选）

如果设备支持指纹 / 面容识别，可以在设置中开启生物识别解锁，以后打开 App 用指纹即可，无需每次输 PIN。

路径：**设置 → 通用 → 指纹解锁**

## 管理密码

### 添加密码

1. 首页点击右下角的 **+** 按钮
2. 填写信息：
   - **名称**（必填）：如「Google」「招商银行」，用于显示和搜索
   - **账号**（必填）：用户名 / 手机号 / 邮箱
   - **密码**（必填）：可手动输入，或点右侧 ⚡ 用密码生成器
   - **备注**（可选）：额外信息
   - **标签**（可选）：最多 3 个，如「社交」「工作」
   - **自定义属性**（可选）：键值对，如「链接 → google.com」。免费版最多 1 个，PRO 无限制
3. 点击保存

### 编辑密码

1. 在列表点击对应密码进入详情
2. 点击编辑按钮
3. 修改后保存

### 删除密码

1. 打开密码详情
2. 滑出底部操作区，点击红色的**「确定粉碎」**
3. 二次确认后永久删除

### 智能排序

PassBox 的列表排序是自动的，无需手动设置：

- **主排序**：最近访问时间（最近看过的排最前）
- **次排序**：访问频率（看得多的靠前）
- **末排序**：创建时间

这样的设计让你最常用的密码永远触手可及。打开一条密码后，它的排序会在下次刷新列表时自动更新。

::: tip 为什么点开后列表没立即重排？
为了避免列表「乱窜」影响体验，访问记录会在后台静默更新，下次进入列表时才体现新的顺序。
:::

### 标签与筛选

- 添加密码时可以打标签（每条最多 3 个）
- 首页底部标签栏会自动汇总所有标签
- 点击标签可筛选该分类下的密码
- 物理返回键优先清除搜索词，再清除标签筛选

### 搜索

首页顶部搜索框，支持**全字段解密搜索**。

搜索时会实时解密并匹配以下字段：

- **名称**（如「Google」「招商银行」）
- **账号**（用户名、手机号、邮箱）
- **备注**
- **自定义属性**的值
- **附件名称**（如附件文件名）

::: tip 安全说明
搜索仅在本地设备上进行，解密发生在内存中，不会将任何明文写入磁盘或上传网络。你输入的搜索词不会被记录。
:::

::: warning 性能提示
全字段解密搜索需要逐条解密比对，密码条目较多时首次搜索可能略慢，属正常现象。
:::

## 密码生成器

添加或编辑密码时，点击密码框右侧的 **⚡** 图标打开生成器：

- **长度**：滑块调节 8-32 位（默认 16）
- **字符集**（可多选）：
  - 大写字母 A-Z
  - 小写字母 a-z
  - 数字 0-9
  - 特殊符号 !@#$%^&*()_+-=[]{}|;:,.<>?
- 下方实时预览，确认后一键填充

生成器使用加密级安全随机源（`Random.secure`），生成的密码足够强。

## 附件功能

::: tip PRO 功能
附件功能为 PRO 专属，免费版不可添加附件。每个密码条目最多可添加 **18 个附件**，PRO 用户还可将附件随密码库一起 WebDAV 云同步。
:::

### 添加附件

1. 打开任意密码详情页，点击**附件区**的「+」
2. 选择来源：
   - **从相册选择**（支持多选）
   - **拍照**
   - **选择文件**（PDF、文档等任意文件）
3. 附件会立即用 AES-256-GCM 加密后存入应用私有目录（`.enc` 格式）

### 支持的附件类型

| 类型 | 说明 |
|:---|:---|
| 图片 | JPG / PNG 等，支持缩略图预览 |
| PDF | 文档类附件 |
| 其他文件 | 任意格式，以文件名展示 |

### 查看 / 管理

- 图片附件支持点开查看大图，可多选批量管理
- 附件会随密码条目一起云同步（需开启 WebDAV 同步）
- 删除密码条目时，其附件一并加密删除

::: tip 加密存储
所有附件都以加密形式（`.enc`）保存在本地，离开 PassBox 无法直接打开。同步到云端时也是加密传输，云端看不到原文。
:::

## 安全功能

### 应用锁

路径：**设置 → 通用 → 应用锁**

- 开启后，每次打开 App 需验证 PIN 或指纹
- 可随时关闭（不推荐）

### 自动锁定

路径：**设置 → 通用 → 自动锁定时间**

| 选项 | 说明 |
|:---|:---|
| 立即锁定 | 切到后台立刻锁定 |
| 1 分钟（默认）| 离开 1 分钟内回来免验证 |
| 2 分钟 | 宽限期 2 分钟 |
| 10 分钟 | 宽限期 10 分钟 |

- 退到后台时会有**隐私遮罩**盖住内容，防止多任务切换预览图泄露密码
- 仅真正退到后台才计时，下拉通知栏等操作不会误锁

### 剪贴板自毁

复制账号 / 密码 / 自定义属性后，剪贴板会在 **30 秒后自动清除**：

- 倒计时最后 5 秒会红色闪烁警告
- 自毁前会校验剪贴板内容，如果你在这期间复制了其他内容，不会被误删

### 修改 PIN 码

路径：**设置 → 通用 → 修改密码**

需要先验证旧 PIN，再设置新 PIN。

## 数据备份

### 加密备份（导出）

路径：**设置 → 数据 → 导出加密备份**

1. 设置一个**备份密码**（与 PIN 码无关，独立用于备份文件）
2. App 用 PBKDF2 + AES-256-GCM 加密整个密码库
3. 生成一段加密密文
4. 复制保存到任意安全位置（笔记、邮箱、U 盘等）

::: tip 备份密码很重要
备份密码丢失将无法恢复数据，请妥善保管。密文本身没有密码完全无法解密。
:::

### 恢复备份（导入）

路径：**设置 → 数据 → 导入加密备份**

1. 粘贴之前导出的密文
2. 输入备份密码
3. 解密成功后**覆盖**当前密码库（操作前有红色警告提示）

### 从其他平台导入

路径：**设置 → 数据 → 导入数据**

支持以下格式（文件大小限制 10MB）：

| 来源 | 格式 | 说明 |
|:---|:---|:---|
| Google Chrome | `.csv` | Chrome 密码导出文件，URL 会存为自定义属性 |
| Bitwarden | `.json` | 支持登录项和安全备注，含多 URI 和 TOTP |
| 咕咚密码 | `.json` | 旧版咕咚密码导出文件 |
| 账号本子 | `.txt` / `.json` | 账号本子 App 导出文件 |

导入流程：选格式 → 选文件 → 预览确认 → 执行导入。所有导入数据入库前都会加密。

## WebDAV 云同步

::: tip PRO 功能
WebDAV 云同步、自动同步、云端存档均为 PRO 功能，[详见 PRO 说明](/passbox/pro_version)。
:::

### 配置 WebDAV

路径：**设置 → 数据 → 云同步备份**

1. 填写三项信息：
   - **服务器地址**：如 `https://dav.jianguoyun.com/dav/`
   - **用户名**
   - **密码**（应用密码，非登录密码）
2. 点击测试连接
3. 连接成功后即可手动同步

### 支持的 WebDAV 服务

- **坚果云**（需使用应用密码，非登录密码）
- **Nextcloud**
- **NAS**（自建 WebDAV）
- 任何标准 WebDAV 服务

### 同步机制

- **增量同步**：比对云端文件变化，无变化时跳过下载
- **智能合并**：基于更新时间（Last-Write-Wins），多设备编辑不会互相覆盖
- **3 秒去抖**：多次编辑合并为一次同步
- **双重加密**：数据本身已加密，同步快照再加密一次

### 数据中心（存档管理）

路径：**设置 → 数据 → 数据中心**（PRO 功能）

- 手动创建本地 / 云端存档
- 查看历史存档列表
- 恢复任意存档（覆盖本地库）
- 本地 + 云端各保留最近 20 份，超出自动删旧

## 主题设置

路径：**设置 → 通用 → 外观**

- 日间模式
- 夜间模式
- 跟随系统
