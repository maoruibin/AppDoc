# PRO 专业版

PassBox 的核心功能完全免费。PRO 专业版面向有多设备同步需求的高级用户，解锁云同步相关能力。

## 免费功能

以下功能无需付费，永久可用：

- 密码的增删改查
- AES-256-GCM 加密存储
- 指纹 / 面容解锁
- 6 位 PIN 码 + 自动锁定
- 标签分组 + 搜索
- 密码生成器
- 本地自动存档（最近 20 份）
- 加密备份导出 / 导入
- 从 Chrome / Bitwarden 等平台导入
- 1 个自定义属性

## PRO 专属功能

升级 PRO 后额外解锁：

| 功能 | 说明 |
|:---|:---|
| **WebDAV 云同步** | 配置坚果云 / Nextcloud / NAS，多设备数据互通 |
| **立即同步** | 手动一键上传 / 拉取云端数据 |
| **自动同步** | 编辑密码后自动上传，无需手动操作 |
| **自动云端存档** | 每次编辑自动在云端创建存档，随时回滚 |
| **数据中心** | 管理本地 + 云端历史存档，一键恢复任意版本 |
| **无限自定义属性** | 每条密码可添加任意数量的自定义属性 |

## 购买 PRO

进入 **设置 → 账号与权益** 即可查看套餐并购买。

::: tip 一次购买，全设备通用
PRO 权益绑定咕咚账号，同一账号在所有设备上登录即可享受 PRO，无需重复购买。
:::

## PRO 使用场景

### 多设备办公

公司电脑记的密码，回家手机上也能用。配置好 WebDAV 后，所有设备的 PassBox 自动保持同步。

### 数据安全兜底

开了自动云端存档后，每次编辑密码都会在云端留一份快照。万一误删了某条密码，可以在数据中心找回。

### 密码信息更完整

免费版每条密码限 1 个自定义属性，PRO 解除限制后，你可以给每条密码记录更多附属信息：链接、安全问题、恢复码、绑定手机号等。
