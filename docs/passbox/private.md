# 隐私政策

更新日期：2026 年 7 月 11 日

北京小茅屋科技有限公司（以下简称"我们"）深知个人信息对您的重要性，PassBox（密匣）将按照法律法规的要求，采用相应安全保护措施来保护您的个人信息安全可控。

本《隐私政策》主要向您说明我们如何收集和使用您的个人信息、如何存储和保护、如何共享以及您如何管理您的个人信息等内容。请您认真阅读本政策，在确认充分理解并同意后使用我们的产品和服务。

##  1.我们会收集什么信息？

PassBox 是一款离线密码管理器，核心设计是本地优先，非常重视用户的隐私保护。

### 本地存储的数据

- 您保存的密码记录（标题、用户名、密码、备注、自定义字段）全部经过 AES-256-GCM 加密后存储在设备本地数据库中
- 应用设置（主题、锁定时间等）存储在设备本地
- 应用锁 PIN 码以 SHA-256 加盐哈希形式存储在系统安全区域（iOS Keychain / Android Keystore），绝不存储明文

### 账号相关（仅登录后）

- 邮箱地址：用于账号注册、登录和权益核验
- 设备 ID：用于设备识别和权益绑定
- 以上信息通过 HTTPS 加密传输至我们的服务器

### 我们不会收集

- 不会收集您的通讯录、位置信息
- 不会收集您的设备标识符用于广告追踪
- 不会在后台上传您的密码数据
- 密码内容仅在本地解密展示，联网同步时以加密快照形式传输

##  2.权限申请说明

- 生物识别（指纹/面容）：仅用于应用解锁验证，指纹数据由系统管理，PassBox 无法读取
- 存储权限：仅用于本地数据库存储和备份文件导出
- 网络权限：仅用于账号登录、PRO 权益验证和 WebDAV 云同步（PRO 功能）

##  3.数据的安全保护

### 加密措施

- 所有敏感数据字段采用 AES-256-GCM 算法加密
- 加密密钥安全存储在 iOS Keychain / Android Keystore 中
- 应用锁 PIN 码使用 SHA-256 加盐哈希，不可逆推

### 本地优先

- 核心功能完全离线可用，无需联网
- 密码数据不会上传至我们的服务器

##  4.WebDAV 云同步（PRO 功能）

- 云同步通过 WebDAV 协议将加密快照文件上传至您指定的第三方云盘
- 同步的文件是经过加密的快照，第三方无法读取明文
- 云盘服务（如坚果云、NAS）由您自行选择和配置，其数据安全由对应服务商负责
- 我们不接触、不存储您的 WebDAV 凭据明文

##  5.账号系统与第三方 SDK

### 账号系统

- 账号系统由我们的后端服务（gudong-api）提供，用于跨应用账号互通和 PRO 权益管理
- 密码传输采用 HTTPS 加密，后端使用 MD5 加盐校验

### 支付（XorPay）

- 支付过程由 XorPay 和支付宝 SDK 处理
- 我们不接触您的银行卡或支付密码
- 仅保留订单号和支付状态用于权益核验

##  6.支付信息安全

- PassBox 支持通过支付宝购买 PRO 功能
- 支付过程由支付宝 SDK 处理，PassBox 不接触也不存储您的银行卡、支付密码等敏感信息
- 我们仅保留必要的订单信息用于权益核验

##  7.信息的披露

PassBox 不会向他人分享您的个人隐私信息，不会将其出售、出租以及其他方式分发给他人。法律法规要求披露的除外。

##  8.账号注销

您可以随时在 App 的设置页面进行账号注销操作。注销后：

- 账号信息将被删除
- 本地密码数据不受影响，仍加密保留在您的设备上

##  9.未成年人信息及使用

PassBox 非常重视对未成年人个人信息的保护，我们希望未成年人仅在接受其父母或法定监护人指导、监督并经其同意的前提下使用。

##  10.隐私政策更新

我们可能会不时更新本隐私政策，更新后的政策将在应用内或官方文档站点公布。继续使用即视为您同意更新后的政策。
