# PassBox 密匣

极简离线密码管理器，安全地管理你的各类账号密码。本地加密存储，永不上传服务器，简洁高效。

## 为什么做这个 App

密码越来越多，浏览器记住的不方便迁移，各平台自带的又不互通，用记事本记又怕不安全。PassBox 就是为此而生 —— 一个纯粹的密码保险箱，所有数据加密存在你自己的设备上，打开即用，安全可控。

## 核心特点

- **AES-256-GCM 加密**：账号、密码、备注、自定义属性全部加密后存储在本地，离线可用，永不上传
- **指纹 / 面容解锁**：支持生物识别一键解锁，打开 App 秒级进入
- **应用密码锁**：6 位 PIN 码保护，支持立即 / 1 分钟 / 2 分钟 / 10 分钟自动锁定
- **智能排序**：按最近访问时间 + 访问频率自动排序，常用密码永远在最前面
- **标签分组**：用标签组织密码，每条最多 3 个标签，底部抽屉一键筛选
- **密码生成器**：8-32 位自定义长度，可选大小写字母、数字、特殊符号
- **WebDAV 云同步**：支持坚果云、Nextcloud、NAS 等多设备同步（PRO 功能）
- **加密备份**：一键导出加密密文，用你自己的备份密码保护
- **多格式导入**：支持从 Chrome、Bitwarden、咕咚密码、账号本子导入
- **剪贴板自毁**：复制的密码 30 秒后自动清除，防止泄露

## 安全架构

PassBox 采用双层安全设计：

```
第一层：应用锁（用户可见）
  指纹 / 面容 / 6 位 PIN —— 控制谁能打开 App

第二层：数据加密（用户无感）
  AES-256-GCM —— 所有密码字段始终加密存储
```

> 注意：PassBox 没有"主密码"的概念。数据加密使用设备无关的密钥，多设备同步天然互通；用户层面的验证靠 PIN + 生物识别。
