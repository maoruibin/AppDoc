# PassBox 密匣

极简离线密码管理器，安全地管理你的各类账号密码。

## 特点

- **本地加密存储**：所有密码经 AES-256-GCM 加密后存储在设备本地，离线可用
- **生物识别解锁**：支持指纹/面容 ID 一键解锁
- **应用密码锁**：可设置 6 位 PIN 码保护，支持自动锁定
- **多格式导入**：支持从 Chrome、Bitwarden、咕咚密码等导入
- **加密备份**：一键导出加密备份文件
- **WebDAV 云同步**：PRO 功能，支持坚果云、NAS 等多设备同步
