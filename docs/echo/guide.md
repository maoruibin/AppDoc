# 使用指南

## 1. 添加文章

EchoRead支持通过 URL 添加文章，将好内容收入你的个人知识库。

1. 点击主界面的「+」按钮
2. 粘贴文章链接（支持微信公众号文章、网页链接等）
3. 点击确认，文章将被自动解析并保存为 Markdown 格式

文章保存后，AI 会自动进行**认知研磨**，为你提炼出：
- 一句话本质摘要
- 3 条底层逻辑/独特洞察
- 可落地的行动建议
- 精准标签
- 针对你个人身份的独到观察

## 2. 与 Stitch AI 对话

Stitch 是EchoRead内置的 AI 认知助手，它了解你收藏的所有文章，可以和你进行深度对话。

### 三种对话模式

Stitch 会根据对话内容自动切换模式：

- **沉浸模式（Immersion）**：专注讨论一个话题，深入挖掘
- **链接模式（Linking）**：跨话题联想，连接不同文章中的相关洞察
- **结晶模式（Crystallization）**：当某主题积累足够多时，主动提议形成永久认知卡片

### 对话技巧

- 「我最近收藏了什么？」— 查看最近文章
- 「这些内容对我的主业有什么启发？」— 跨文章综合分析
- 「我之前对 XX 说过什么？」— 召回历史记忆
- 直接就某篇文章提问 — AI 会阅读全文并回答

## 3. 认知晶格

认知晶格是EchoRead的核心创新，帮你将碎片化的认知沉淀为结构化的脑部资产。

### 碎玉

对话中的高光时刻会被自动捕获为「碎玉」——一段值得长期记住的原话或洞察。你也可以主动说「记下来」来触发捕获。

### 结晶

当某个主题积累了 4 张以上的碎玉后，AI 会提议将它们「结晶」为一张永久认知卡片，写出这些碎玉为什么聚在一起、共同指向什么认知。

### 行动提议

结晶形成后，AI 会建议一条具体、可在 30 天内完成的行动，让认知真正落地。

## 4. 用户画像

在设置中填写你的用户画像（职业、关注领域、当前项目等），AI 在研磨文章时会透过你的视角去理解内容，给出和你强关联的洞察，而不是「放之四海而皆准」的摘要。

## 5. AI 引擎配置

EchoRead使用 DeepSeek AI 引擎提供智能分析服务。你可以：

- 使用官方提供的默认引擎（开箱即用）
- 在设置中填入自己的 API Key（完全自控，费用自理）

默认模型为 DeepSeek，研磨模型使用更强大的版本以确保洞察质量。

## 6. 语义搜索

除了关键词搜索，EchoRead 还内置了**语义搜索**：基于向量语义的智能检索，不局限于字面匹配，能找到「意思相近」的文章。

### 它和普通搜索的区别

| 维度 | 关键词搜索 | 语义搜索 |
|------|-----------|----------|
| 原理 | 标题/摘要里是否包含某个词 | 文章整体语义和查询是否相近 |
| 例子 | 搜「时间管理」只能命中含这几个字的文章 | 搜「如何高效安排一天」也能找到讲时间管理的文章 |
| 依赖 | 即开即用 | 需要文章已生成语义向量 |

### 工作原理

每当一篇文章研磨完成，EchoRead 会把它的**标题 + 摘要 + 核心观点 + 标签 + 观察 + 收藏意图**（而不是全文，信号密度更高、速度更快）送给智谱 embedding-3 模型，生成一段语义向量，和文章一起存进本地数据库。检索时用同样的方式把你的查询变成向量，再用余弦相似度算出最接近的 Top N 篇。

::: tip 两个隐藏能力
- **跨文联想**：读完一篇文章想找类似的，AI 会基于语义给你推荐相关文章（「和这篇关联最大的是哪些」）。
- **碎玉互连**：每张升格的碎玉也会生成向量，相似度 ≥ 0.75 的碎玉会自动连成「语义晶格连接」，为后续结晶做铺垫。
:::

### 怎么用

你不需要手动操作，语义搜索由 Stitch AI 在对话中自动调用：

- 直接用自然语言提问，比如「我之前收藏过关于专注力的内容吗」「有哪些讲产品决策的文章」——AI 会先做语义检索再回答。
- 也可以问「这篇还有什么类似的」让 AI 帮你找相关文章。

### 启用前提：配置智谱 API Key

语义搜索依赖智谱的 embedding-3 模型，**必须单独配置智谱 API Key 才能生效**：

1. 进入 **我的 → AI 引擎配置**。
2. 在「智谱 AI（向量化/RAG）」一栏填入你的智谱 API Key（从智谱开放平台获取）。
3. 保存。

::: warning 没配 Key 会怎样
没配 Key 时，新文章的语义向量会被标记为「未配妥，已略过」，语义搜索和相关推荐会失效，但**不影响**文章研磨、对话、记忆系统等其他功能——它们由 DeepSeek 引擎提供，照常工作。AI 在需要语义检索时会提示你改用关键词搜索。
:::

### 给历史文章补向量

如果你在收藏了很多文章之后才配置智谱 Key，这些老文章还没有语义向量。开发者工具里的「**Embedding 补齐**」可以一键为所有 pending/failed 状态的历史文章批量生成向量，完成后它们也能被语义搜索命中。

> 「Embedding 补齐」入口在 **我的 → 开发者工具**，按篇进度实时显示，失败的文章会单独统计。
