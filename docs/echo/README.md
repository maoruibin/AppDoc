# EchoRead

<img src="https://gudong.s3.bitiful.net/icon/echo_read_icon.png?no-wait=on" width="13%" alt="">

> 别做知识的搬运工，把高手的干货，复刻成你的脑资产！

EchoRead 是一款 AI 驱动的个人知识管理工具，专为创作者和研究者打造。它不只是收藏文章，而是通过 AI 认知研磨，将高手的干货真正内化为你的脑部资产。

## 核心特性

- **AI 认知研磨** — 保存文章后，AI 自动提炼核心洞察、底层逻辑和可落地的行动建议
- **Stitch AI 对话** — 基于你的文章库，AI 可以跨文章联想、主动复盘、回答深度问题
- **记忆系统** — AI 记住你的身份、偏好和关注主题，越用越懂你
- **认知晶格** — 对话中的高光时刻自动捕获为「碎玉」，积累到阈值后结晶为永久认知卡片
- **语义搜索** — 基于向量语义的智能检索，不局限于关键词匹配
- **本地优先** — 所有数据存储在本地设备，你的知识资产完全由你掌控

## 与传统剪藏的区别

| 维度 | 传统剪藏 App | EchoRead |
|------|-------------|------|
| 核心目的 | 收藏、防丢失 | 消化、内化、二次创作 |
| AI 的角色 | 辅助工具 | 常驻的 AI 认知助手 |
| 数据关系 | 文件夹/标签 | 网状认知图谱 |
| 目标用户 | 信息焦虑的大众 | 创作者、研究者 |
