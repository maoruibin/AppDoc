# 常见问题

## 支持哪些平台？
> EchoRead支持 Android、iOS 和 macOS，基于 Flutter 跨平台开发。

## 数据安全吗？
> EchoRead采用本地优先架构，所有文章数据、对话记录、记忆数据均存储在你的设备本地 SQLite 数据库中。AI 处理时会将文章内容发送至 AI 接口进行分析，但不会持久化存储在你的设备之外。

## 可以用自己的 API Key 吗？
> 可以。在设置中切换为自定义 AI 引擎，填入你自己的 DeepSeek API Key 即可。使用自定义 Key 时，所有 API 费用由你自行承担。

## 认知研磨是什么？
> 认知研磨是EchoRead的核心功能。当你保存一篇文章后，AI 不是简单做摘要，而是像一个「认知研磨引擎」一样，提炼出底层逻辑、独特洞察和可落地的行动建议，并结合你的个人画像给出针对性分析。

## 什么是认知晶格？
> 认知晶格是EchoRead的知识沉淀机制。对话中的高光时刻会被捕获为「碎玉」，当某个主题的碎玉积累到一定密度时，AI 会将它们融合为一张永久的「结晶」卡片，并建议具体行动让认知落地。

## 为什么 AI 说我可以设置用户画像？
> 用户画像帮助 AI 透过你的视角理解文章。同一个系统设计文章，给开发者提炼的是「架构解耦」，给产品经理提炼的则是「业务边界」。设置画像后，AI 的每次研磨都会和你强关联。

## AI 对话的三种模式是什么？
> - **沉浸模式**：你专注聊一个话题时，AI 深入挖掘不跑题
> - **链接模式**：你开始跨话题联想时，AI 检索相关的历史碎玉融入回答
> - **结晶模式**：某主题碎玉密度够高时，AI 主动提议结晶为永久卡片

## 支持哪些类型的文章链接？
> 支持微信公众号文章、普通网页链接等。通过服务端解析，将网页内容提取为干净的 Markdown 格式。
