# 功能详解

书咚咚是一个本地优先的 EPUB 阅读器：无账号、无推荐流、不打断，把「安静读书」这一件事做好。下面按「导入 → 阅读 → 划线笔记 → 分享 → 回顾」的顺序逐一介绍。

## 书架


- **网格 / 列表双视图**：一屏看更多书，或一列看清进度
- **自动解析**：导入后自动提取封面、书名、作者
- **搜索**：按书名快速找书
- **存储管理**：按书查看空间占用，长按删除不需要的书

支持三种导入方式：App 内文件选择、系统分享到书咚咚、文件管理器「打开方式」。首次使用且书架为空时，会自动导入内置示例书《苏东坡传》。

## 阅读器


### 横滑翻页

翻页交互参考纸质书：横向滑动翻页，手势完全留在正文里，不打架。也可以点击屏幕两侧翻页；Android 上还支持音量键翻页（设置中开启，翻页时不弹系统音量条）。

### 沉浸式界面

进入正文后顶栏底栏自动收起，点击屏幕中间呼出。菜单、目录、搜索都是悬浮层，书始终可见。

### 排版

| 项目 | 说明 |
|------|------|
| 字号 | 多级字号，即时预览 |
| 行距 | 松紧可调 |
| 页边距 | 适配不同屏幕比例 |
| 皮肤 | 纸白 / 米黄 / 夜间 / 豆绿 / 浅灰，五色五情境 |
| 字体 | 内置思源宋体、霞鹜文楷，随 App 分发不依赖系统，各品牌手机显示一致 |

### 目录、搜索与书签

- 章节目录一键跳转
- 全书全文搜索，结果定位到原文
- 阅读中随手加书签，跨章节回跳

### 进度

每本书自动记住阅读位置与百分比，重开即续读。页脚显示当前章节页码进度（`12 / 34` 式极简数字）。

## 划线与想法


长按选中文字，弹出极简气泡：**复制 / 划线 / 写想法 / 书摘** 四键一层，不堆功能。

### 三种划线样式

- 波浪线、直线、背景色，各配五种颜色
- 点按已有划线即可改样式或删除，样式即时生效

### 多条想法

一条划线可以追加多条想法，适合同一段话反复读、反复记。所有编辑都在右侧**详情浮窗**完成：点划线弹出，改样式、写想法、删划线一处搞定，不打断阅读。

### 笔记本

- **单本书笔记**：本书全部划线与想法，按章节归位
- **全部读书笔记**：书架侧总览，以书为维度进入管理

## 书摘分享


把划线一键生成金句卡片：排版、书名、出处自动就位，分享微信好友（微信绿气泡样式）或朋友圈，也可保存为图片。

## 读书印记


书架顶部的「读书印记」条，用克制的数字回答「我最近读得怎么样」：

- **今日时长**：今天读了多久
- **连续天数**：连续阅读打卡
- **近 7 日足迹**：最近一周的阅读痕迹

阅读时长由本机统计（阅读会话级记录，挂机自动冻结），不上传任何服务器。

## 无账号、本地优先

书咚咚没有登录页。书、进度、笔记、统计全部在本机；除检查更新外不联网，飞行模式也完整可用。
