# 读咚咚

> 本地优先的 EPUB 阅读器，安静读书这一件事。

读咚咚（Reader Dong）是一个本地优先的 EPUB 阅读器：把书导进来，横滑翻页，安静读完。它不社交、没有推荐流、不打断——工具收起来，只在需要时出现。

## 核心功能

- **本地书架** — EPUB 一键导入，封面与作者信息自动解析
- **横滑翻页** — 交互参考纸质书的横向翻页，手势留在正文里
- **目录与搜索** — 章节目录跳转，全书全文搜索
- **排版可控** — 字号、行距、页边距，白/米黄/夜间/豆绿/浅灰五色皮肤
- **进度与书签** — 自动记录阅读进度，随手加书签
- **本地优先** — 书和进度都存本机，不联网也能完整使用
