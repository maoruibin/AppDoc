# 使用指南

欢迎使用书咚咚！这里帮你快速上手：把书导进来，安静读完。

## 导入书籍

书咚咚专注 EPUB 格式，三种导入方式任选：

- **文件导入**：书架右上角 **+**，选择本机的 EPUB 文件
- **系统分享**：在微信、文件管理器里打开 EPUB，分享到书咚咚
- **打开方式**：文件管理器中长按 EPUB → 打开方式 → 书咚咚

导入后封面、书名、作者会自动解析。

::: tip 第一次打开
书架为空时，会自动为你导入一本内置的《苏东坡传》作为示例，可以先拿它熟悉操作。
:::


## 开始阅读

点击书架上的书即进入阅读页，自动定位到上次的进度。

- **翻页**：左右横滑，或点击屏幕左右两侧区域；也可在设置中开启音量键翻页
- **呼出菜单**：点击屏幕中间区域，顶栏/底栏会浮现
- **翻页方向**：参考纸质书，从右往左滑是下一页


### 排版调整

底栏的排版面板可以调整：

- **字号**、**行距**、**页边距**
- **皮肤**：纸白 / 米黄 / 夜间 / 豆绿 / 浅灰五色
- **字体**：内置思源宋体（衬线）与霞鹜文楷（手写感），不依赖系统字体，各品牌手机显示一致


### 目录、搜索与书签

- **目录**：底栏打开章节目录，快速跳转
- **搜索**：全书全文搜索，结果直接定位到原文
- **书签**：阅读中随手加书签，从目录面板可回跳

## 划线与想法

在正文中**长按并拖动**选中文字，弹出气泡菜单：

- **复制**：复制原文
- **划线**：波浪线 / 直线 / 背景色三种样式，五种颜色，点划线可随时改样式
- **写想法**：给这段话记一条笔记；同一段划线可以追加多条想法
- **书摘**：生成金句卡片，分享给朋友或朋友圈


点击已有的划线文字，会在右侧打开**详情浮窗**：查看/修改样式、编辑想法、删除划线，都在这里完成。

### 回顾笔记

- **单本书**：阅读页菜单进入本书的划线与想法列表
- **全部笔记**：书架进入「读书笔记」总览，所有书的划线与想法集中管理

## 读书印记

书架顶部有一条「读书印记」：今天读了多久、连续阅读天数、最近 7 天的阅读足迹。所有统计都在本机完成，不上传。


## 设置与数据管理

「我的 → 设置」中可以开启：

- **音量键翻页**（Android）：音量键直接翻页，不弹系统音量条
- **触感反馈**、**屏幕常亮**等偏好

「存储管理」可以查看书籍占用、删除不需要的书。
