# 联系我们

感谢你使用小牛说！如果有问题、建议或反馈，欢迎通过以下方式找到我。

## 反馈渠道

### 电子邮件

gudong.name@gmail.com

这是最直接的方式，我会在看到后尽快回复（节假日可能有延迟）。

### 问题反馈

如果你发现了 Bug 或有功能建议，反馈时尽量带上以下信息，能帮我更快定位：

- 设备型号和 Android 系统版本
- 小牛说的版本号（App 内右上角菜单 > 系统调试日志 顶部可看到）
- 问题发生的具体步骤
- 问题现象描述
- 系统调试日志（App 内「更多 > 系统调试日志」可以复制出来）
