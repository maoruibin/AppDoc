# 功能详解

小牛说不只是一个语音输入法，它是一套「录音 → 识别 → 润色 → 上屏」的完整语音写作系统。下面按模块逐一介绍。

## 语音输入

### 按住说话，松开即得

小牛说的核心交互是一个中央麦克风胶囊按钮，没有任何二级菜单：

- **按下**开始录音，按钮展开为声波动效，实时显示转写文字
- **松开**结束录音，按钮显示「斟字酌句中...」，AI 开始润色
- 润色完成后文字自动填入输入框，同时复制到剪贴板

录音采用 16kHz 单声道 PCM 采样，专为语音识别优化。

### 实时流式转写

录音过程中，音频以流式方式持续发送到云端 ASR 服务，识别结果逐句返回并实时显示在键盘上，让你在说话的同时就能看到内容正在被「接住」。每识别完一个完整句子就会触发一次回调，避免中间态文字的抖动。

## AI 润色

### 两阶段润色策略

小牛说默认采用「两阶段润色」，效果优于单次润色：

| 阶段 | 任务 | 做什么 |
|------|------|--------|
| 阶段一：清洗 | 只做减法 | 去口癖（嗯、啊、那个、就是说）、修同音字、丢掉不完整的半句 |
| 阶段二：结构化 | 只做加法 | 话题转换处分段，并列要点用编号列表，长句拆短 |

两阶段总耗时控制在 12 秒以内（清洗 4s + 结构化 8s），超时会自动降级为单次润色，保证输入法的响应速度。

### 短文快捷通道

文本不足 30 字时直接走单次润色，省掉两阶段的网络开销，做到「松手即出」的流畅体验。

### 多层降级保障

为了避免网络或服务异常导致输入法卡死，小牛说做了多层降级：

1. 阶段一（清洗）失败 → 跳过，用原文进入阶段二
2. 阶段二（结构化）失败 → 用清洗后的文本输出
3. 两阶段都失败 → 输出 ASR 原始转写文本

### 润色风格

支持五种预设风格，在设置里随时切换：

| 风格 | 适用场景 | 特点 |
|------|----------|------|
| 通用流畅 | 日常笔记、备忘（默认） | 自然流畅的书面文本 |
| 轻松口语 | 聊天、闲聊记录 | 保持口头聊天的随性语气 |
| 小红书活泼 | 社交分享 | 活力语气，自动加 emoji（✨💡📝🙌🥳） |
| 商务正式 | 邮件、公文 | 结构严谨、措辞得体 |
| 不优化 | 想要原始转写 | 直接输出 ASR 原文，不经过 AI |

此外还支持自定义核心系统提示词，进阶用户可以完全改写 AI 的润色行为。

## 输入法集成

### 四种键盘模式

小牛说不只有语音，它内置了一套完整的多模式键盘，通过 HorizontalPager 组织，点击切换：

| 模式 | 标识 | 默认 | 说明 |
|------|------|------|------|
| 语音输入 | `VOICE` | 否 | 大麦克风按钮，按住说话松开即得 |
| 中文九键 | `T9_PINYIN` | 是 | 3×3 T9 拼音布局 |
| 中文 26 键 | `QWERTY_CN` | 否 | 标准 QWERTY 拼音 |
| 英文 | `QWERTY_EN` | 否 | 标准 QWERTY 英文 |

默认进入九键拼音，可以在「键盘与通用设置」里改默认键盘类型。每种键盘底栏都保留麦克风入口，随时一键切回语音。

### 拼音引擎

拼音部分采用双引擎设计：

- **主引擎**：RimePinyinEngine，基于 librime 的 JNI 集成，词库全、识别准
- **兜底引擎**：MmapPinyinEngine，二进制词库 + MappedByteBuffer 内存映射，启动快

九键（T9）通过 RIME 的 algebra 系统实现数字到拼音的回溯分词。用户词库（Room）优先级高于系统词库，你常用的词会被优先推荐。

### 模糊音

开启模糊音后，以下容易混淆的拼音可以互换识别：

| 模糊项 | 默认 |
|--------|------|
| zh / z | 开 |
| ch / c | 开 |
| sh / s | 开 |
| an / ang | 开 |
| en / eng | 开 |
| in / ing | 开 |
| l / n | 关 |
| f / h | 关 |

模糊音可以在「键盘与通用设置」里整体开关。

### 按键反馈

- **按键声音** — 按下时播放音效（默认开）
- **按键震动** — 按下时震动反馈（默认开）

两者都可以在「键盘与通用设置」里独立开关。语音模式不触发按键反馈。

## 输入面板

除了四种键盘模式，小牛说还内置了一套「工具面板」，把日常输入最常用的几样东西（剪贴板、表情、符号、常用语）都收纳进来，不用切回系统键盘再切回来。点击键盘上的「工具」入口进入一个 2×4 的宫格首页，再点对应卡片进入各子面板。

### 剪贴板面板

剪贴板面板自动记录你最近的复制内容，在键盘里直接点一下就能粘贴上屏，省去切应用、长按粘贴的来回操作。

- **列表管理** — 每条剪贴板记录单行预览，点击即粘贴到当前输入框
- **智能实体识别** — 内容里的手机号（11 位）、网址（http/https）、英文单词（≥3 字母）会被自动抽成独立的小标签，点标签就能单独粘贴这一段，不用整段复制再删改
- **快捷操作** — 每条记录右侧的「更多」展开后可「转常用」（把这条存为常用语）、「删除」、「返回」
- **空状态** — 没有记录时显示「📋 剪贴板空空如也」

::: tip 剪贴板转常用语
复制的邮箱、地址、签名这种会反复用的内容，可以在剪贴板列表里直接点「转常用」沉淀为常用语，下次不用再去翻剪贴板历史。
:::

### 表情面板

内置一份分门别类的 emoji 表情库，7 列网格铺满，点一下即输入：

| 分类 | 图标 | 内容 |
|------|------|------|
| 表情 | 😊 | 笑哭、惊讶、爱心脸等常用表情 |
| 动物 | 🐱 | 猫狗、飞禽走兽、海洋生物 |
| 食物 | 🍔 | 水果、饮料、餐食 |
| 活动 | ⚽ | 运动、游戏、音乐、表演 |
| 出行 | 🚗 | 汽车、飞机、各类交通 |
| 物品 | 💡 | 文具、工具、办公用品 |
| 符号 | 🔣 | 心形、星座、警示标识 |

底部一排分类切换 Tab，选中项高亮显示，跨分类切换很顺手。

### 符号面板

键盘底栏的「符」入口进入符号键盘，覆盖标点和数字输入：

- **三档切换** — 「🕒 最近」（最近用过的符号，越用越顺手）、「中文」、「英文」三档底部 Tab 切换
- **中文符号** — 逗号、句号、问号、书名号、引号等 27 个常用中文标点
- **英文符号** — 下划线、连字符、`#`、`$`、`¥` 等编程与货币符号
- **快捷符号行** — 底栏「123」键一键切到数字键盘，旁边还有 6 个高频符号（中英文自动适配）和带长按连删的退格键
- **布局** — 3 行 × 9 列符号 + 1 行功能键 + 1 行导航，和主键盘节奏一致

### 常用语面板

把会反复打的话（邮箱、收货地址、固定回复、签名档等）存为常用语，在键盘里一键插入，不用反复口述或手敲：

- **列表插入** — 点任意条目直接插入到输入框，每条最多两行预览
- **管理入口** — 空列表会提示「暂无常用语，请点击右上角管理」，进入管理页可增删改
- **来源多样** — 常用语既可以手动添加，也可以从剪贴板面板「转常用」一键沉淀过来

### 自定义快捷工具

如果你只常用其中一两个面板，可以在「自定义」面板里勾选要常驻快捷入口的工具（剪贴板、常用语、键盘选择、表情、反馈日志、设置），勾中的会作为底栏快捷入口，把最高频的操作放到指尖。

## AI 引擎配置

小牛说不绑定任何单一服务商，所有 AI 能力都可以自由切换或自配 Key。

### 语音识别（ASR）

| 服务商 | 特点 | 需要的凭据 |
|--------|------|-----------|
| 火山引擎（豆包 Seed ASR 2.0） | 默认，流式识别，支持热词注入 | App ID + Access Key |
| 百炼（阿里云 NLS） | 兜底方案，文件识别 | AccessKey ID + AccessKey Secret + AppKey |

火山引擎的 ASR 支持把热词词典注入到识别请求里，专有名词识别更准。

### AI 润色

| 服务商 | 模型选项 | 说明 |
|--------|----------|------|
| 百炼通义千问 | turbo / plus / max | 推荐，语义润色效果好，各模型均有免费额度 |
| 火山方舟（豆包） | DeepSeek 兼容接口 | 高性价比 |
| 不优化 | — | 直接输出 ASR 原文，不调用 AI |

通义千问的三个模型在速度和效果上有差异：

- **qwen-turbo** — 最快，适合短消息
- **qwen-plus** — 推荐，速度和效果的平衡（默认）
- **qwen-max** — 最强，适合长文稿

所有 AI 接口都遵循 OpenAI 兼容协议，未来接入其他服务商也很方便。

### 双通道模式

- **共享通道**（默认）— 使用小牛说内置的服务端中转，开箱即用，无需配置
- **专属通道** — 用户自配 API Key，所有请求优先走自己的 Key，成本透明、数据不经过小牛说的服务器

两种通道功能完全相同，切换是无缝的。

## 标点与排版处理

润色阶段会自动处理标点和排版：

- **标点补全** — 自动补句号、问号、感叹号、逗号、冒号，专有名词和引述加引号
- **短句例外** — 只有一句话且不超过 15 个字时不加句号，保持自然口语感（例如「天气不错」不会变成「天气不错。」）
- **分段** — 逻辑转折或话题切换处插入空行
- **编号列表** — 2-4 个并列要点用「1. 2. 3.」列表，5 个以上先总结再列表
- **去 Markdown** — 输出纯文本，不使用代码块、标题语法或加粗

### 火山 ASR 标点

火山引擎 ASR 在识别阶段就开启了 `enable_punc`（标点）和 `enable_itn`（数字、日期等格式反转写），让原始转写就带有合理的标点和格式。

## 个性化能力

### 热词词典

针对专有名词（人名、产品名、行业术语），可以添加到热词词典：

- 支持**单条添加**（输入框回车）和**批量导入**
- 每条热词可设置**别名**（易误识别的近音词，逗号分隔）
- 可单独**启用 / 停用**
- 热词同时注入 ASR 识别和 AI 润色两个环节，确保拼写正确

### 用户背景记忆

你可以填写一段「说话人背景信息」，比如你的职业、常写的主题、偏好的措辞风格。这段记忆会拼接到每次润色的系统提示词里，让 AI 输出更贴合你的表达习惯。

### 常用语管理

把常用的话（邮箱、签名、固定回复等）存为常用语，在键盘的工具面板里一键插入，不用反复口述或手敲。

### 自定义系统提示词

进阶用户可以完全改写 AI 的核心系统提示词，在「AI 核心指令配置」里编辑。改写后会覆盖默认的润色指令，所有润色都按你的规则来。

## 数据与隐私

### 本地存储

- **历史记录**：Room 数据库，最多保留 50 条，含音频路径、转写原文、润色稿、状态
- **配置数据**：DataStore 存储，包括润色风格、API Key、键盘偏好、模糊音、按键反馈等
- **用户词典**：Room 管理，支持增删和批量导入

### 数据安全

- API Key 仅保存在设备本地，不上传小牛说服务器
- 共享通道下，音频和文本会经过小牛说的中转服务调用上游 AI
- 专属通道下，请求直接发往你配置的服务商，不经过小牛说
- 没有账号体系，不收集用户数据

### 历史记录回溯

历史记录页可以：

- 复制转写原文或润色稿
- 对历史记录**重新润色**，换风格再生成一遍
- 一键**清空**所有记录

## 交互设计原则

小牛说在交互上有几条死守的设计纪律：

1. **所见即所用** — 切换到输入法即看到录音按钮，无二级菜单
2. **零等待感** — 冷启动快，润色控制在 2 秒以内（短文更短）
3. **去噪音** — 无皮肤、无键盘音效、无词条联想，极简界面
4. **一触即走** — 润色完成自动复制，直接粘贴
5. **语音无处不在** — 每种键盘底栏都有麦克风入口
