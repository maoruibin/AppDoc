# 常见问题

## 基础问题

### 小牛说是什么？

小牛说（NiuTalk）是一款 AI 驱动的语音写作系统输入法。它作为系统输入法运行，在任何 App 里切换到它就能用，按住说话、松开即得到 AI 润色后的文稿。一句话：**打字不用敲，就用小牛说。**

### 小牛说是免费的吗？

小牛说采用付费模式，承诺不做广告、不卖数据、不限制核心功能：

- **买断版**（¥169）— 使用自己的 API Key，无次数限制，终身有效
- **订阅版**（¥40-50/月）— 使用内置服务端中转，开箱即用，无需配置

两种方案功能完全相同，差异只在 API 提供方式。

### 小牛说支持哪些系统？

目前 Android 版（Kotlin + Compose）是主力开发中版本，要求 Android 8.0（API 26）及以上。iOS、macOS 版本在开发中，Windows 版本在规划。

### 小牛说和 inVoice 语记有什么区别？

inVoice 是一个独立的录音转文字 App，适合录音之后集中整理；小牛说是系统输入法，目标是让你在「正在打字」的场景下直接用语音替代，松手即出稿，不用切换 App。

## 输入法启用相关

### 怎么启用小牛说输入法？

打开 App 后会进入引导页，按三步走：

1. 授予录音权限
2. 跳转系统设置，在输入法列表里启用「小牛说语音输入」
3. 切换默认输入法为「小牛说语音输入」

每步完成都可以点「验证激活状态」自动检测。三步全过后会提示「全部准备就绪」。

### 启用了还是用不了，怎么办？

常见原因：

- 没有设为**默认**输入法（只启用不够，必须切为当前默认）
- 没有授予录音权限（设置页顶部会显示红色警告条）
- 在某些 App 里系统禁止第三方输入法（如密码框、银行 App），这是系统限制，属正常现象

可以打开 App 点「查看系统调试日志」排查具体原因。

### 录音权限被拒了怎么办？

打开 App，主页顶部会有红色警告条「未获得录音权限」，点击即可重新申请。也可以去系统设置 > 应用 > 小牛说 > 权限，手动开启麦克风。

## 语音识别相关

### 为什么识别不准？

识别准确度受几个因素影响：

- **环境噪音** — 在嘈杂环境识别会变差，尽量靠近麦克风
- **方言口音** — 默认针对普通话优化，重口音会影响识别
- **专有名词** — 人名、产品名、行业术语容易识别错，建议加到[热词词典](features.md#热词词典)
- **说话方式** — 尽量整句说，不要一个字一个字蹦

热词词典会把专有名词同时注入到 ASR 识别和 AI 润色两个环节，对准确度提升明显。

### 支持哪些语言？

语音识别支持中文（默认）和英文等多种语言，可在服务商配置里切换识别语言（如火山引擎的 `language` 参数）。润色效果主要针对中文场景优化，其他语言效果取决于所选 AI 引擎的能力。

### 语音输入需要联网吗？

需要。识别和润色都依赖云端服务，所以必须联网。录音本身在本地完成，结束后才上传处理。

### 录音过程中可以停顿吗？

可以。流式识别会逐句返回结果，你说话的间隙不会有问题。但建议一次说完一个完整的句子或段落，识别效果最好。半句话或中途改口的内容会在润色阶段被清理掉。

## AI 润色相关

### 怎么配置自己的 AI 服务？

进入「输入偏好设置 > API Key 专属通道」，分别配置语音识别服务商（火山 / 阿里）和语音优化服务商（通义千问 / 豆包 / 不优化），填入对应凭据保存即可。详细字段见 [功能详解](features.md#ai-引擎配置)。

### 润色失败怎么办？

小牛说有多层降级保障，正常情况下即使润色失败也会输出 ASR 原始转写文本，不会卡住输入法。如果频繁失败，建议：

- 检查网络连接
- 在「系统调试日志」里查看具体错误
- 如果用专属通道，确认 API Key 有效、有余额

### 润色结果不满意，能重新生成吗？

可以。在历史记录页点击任意一条记录，可以对它重新润色，换一种风格再生成一遍。也可以在设置里切换默认润色风格（通用 / 口语 / 小红书 / 商务 / 不优化）。

### 润色会改变我的原意吗？

不会。润色的核心原则是「不添加原文中没有的信息、总结或补充」，只做清理（去口癖、修同音字）和结构化（分段、列表），不改说话人的原意和措辞风格。

## 数据与隐私相关

### 我的录音和文字会被上传到哪里？

取决于你用的通道：

- **共享通道**（默认）— 音频和文本经小牛说的中转服务调用上游 AI（火山 / 阿里 / 通义千问）
- **专属通道**（自配 Key）— 请求直接发往你配置的服务商，不经过小牛说的服务器

无论哪种通道，**API Key 和历史记录都只存在你的设备本地**，小牛说不存储你的数据。详见 [隐私政策](private.md)。

### 历史记录最多存多少条？

最多 50 条，超出后旧的会被清理。每条记录包含音频、转写原文、润色稿和状态，可以在历史记录页查看、复制、重新润色或清空。

### 卸载 App 数据会丢吗？

会。历史记录、用户词典、配置都存在设备本地，卸载后无法恢复。重要的内容建议提前复制出来保存。
