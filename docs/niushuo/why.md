# 缘起

## 一个被忽视的空白

在做小牛说之前，我已经开发过好几款个人效率工具，其中 inVoice 语记是一个录音转文字的独立 App，底层调用阿里云的实时语音识别，再通过一套精心设计的提示词驱动 DeepSeek，把口语稿快速润色成通顺、可读的书面文案。

但在用的过程中，我发现了一个明确的空白地带：**市场上缺少一款完全聚焦于「语音写作」的系统输入法工具。**

现有的语音输入法要么依附于大厂的通用键盘，体验臃肿、限制多；要么只做转写，缺乏智能润色，没法把语音直接变成能发布的成品文字。创作者想用语音写作，总是要在外部录音 App、输入法、编辑器之间来回切换，摩擦感很强。

## 想做的事

我想做一款只属于创作者的、极简到极致的语音输入法。它要取代笨重的键盘输入，成为内容生产者最快把脑子里的想法变成干净文字的通道。

它面向重视效率、愿意为工具买单、甚至乐意自己配置 API 的「极客创作者」。

一句话解释：**在所有需要打字的场景下，用它，你只需要说话。**

## 它应该是什么样

我对小牛说的形态有非常具体的想象：

打开它就是录音界面，没有任何二级菜单和引导页。按住那颗硕大的麦克风按钮开始说，松开就得到润色好的文稿，文字自动进入剪贴板，切回 App 直接粘贴就行。理想情况下，你甚至不需要看着输入法界面就能完成整个写作。

动画只用来安抚等待，不做无意义的炫技。冷启动要快，润色要控制在两秒以内。没有皮肤、没有键盘音效、没有词条联想，界面只有录音按钮、状态文字和结果区。

## 给谁用

- **自媒体创作者** — 要快速产出公众号、小红书、短视频口播稿的人
- **知识工作者** — 记录碎片灵感、会议总结、读书笔记，讨厌手机打字
- **极客和技术爱好者** — 愿意自己申请 API Key，享受可控、可定制的云端智能服务
- **效率工具重度用户** — 追求无摩擦、无广告、一步到位的纯粹体验

## 怎么活下去

小牛说承诺**不做广告、不卖数据、不限制核心功能访问**，收入完全依赖直接付费：

- **买断版**（169 元）— 用户自带 API Key，无次数限制，终身有效
- **订阅版**（40-50 元/月）— 内置服务端中转，开箱即用

两种方案功能完全一致，差异只在 API 提供方式。这样既照顾了愿意折腾的极客，也照顾了不想配置的普通创作者。

## 从语音到完整键盘

小牛说最早只有语音模式，但实际用下来发现，完全抛弃键盘并不现实——总有需要手动修改、补几个字、敲个英文的场景。所以在语音之外，又加上了九键拼音、26 键拼音和英文键盘，做成一套多模式键盘。但无论用哪种键盘，底栏永远保留麦克风入口，语音始终是一等公民。

这是小牛说和传统输入法最大的区别：传统输入法把语音藏得很深，小牛说把语音放在最显眼的位置。
