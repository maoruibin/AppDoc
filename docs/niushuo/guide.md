# 快速上手

本指南帮你从零开始，把小牛说跑起来。小牛说是一个**系统输入法**，所以第一次使用需要在系统里启用并设为默认，之后就能在任何 App 里直接调用。

## 安装与启用

小牛说作为系统输入法运行，需要完成三步激活。打开 App 后会进入引导页，按顺序操作即可：

1. **授予录音权限** — 点击「授予录音权限」，在系统弹窗中允许麦克风访问。没有录音权限输入法无法工作。
2. **去系统设置启用** — 点击「去系统设置启用」，跳转到系统的「语言和输入法」设置页，在输入法列表里找到「小牛说语音输入」并打开开关。
3. **切换为默认输入法** — 回到 App 点击「切换默认键盘」，在系统弹出的输入法选择菜单里选中「小牛说语音输入」。

每一步完成后都可以点击「验证激活状态」让 App 自动检测当前进度。三步全部通过后会提示「全部准备就绪，激活成功」，并自动进入主页。

如果暂时不想激活，也可以点击底部的「跳过引导，进入主页」直接查看设置页，但此时语音输入还无法使用。

## 界面概览

小牛说没有传统输入法那种复杂的菜单，切换到输入法后你会直接看到录音界面：

- **语音键盘** — 中央一颗硕大的麦克风胶囊按钮，按下即录，松开即转
- **工具栏** — 顶部一排入口，可切换到九键拼音、26 键拼音、英文键盘、符号面板等
- **候选词栏** — 使用拼音键盘时显示候选词
- **底栏** — 切换键盘模式、打开设置、回到语音模式，每种键盘底栏都有麦克风入口

切回 App 主页则是设置中心，顶部右上角是历史记录入口，主页内依次是输入偏好设置、API 配置、热词词典、常用语、用户记忆、键盘通用设置等卡片。

## 基础操作

### 用语音输入文字

1. 在任意 App（微信、备忘录、笔记软件等）中点击一个输入框，弹出键盘
2. 如果当前不是语音键盘，点击底栏的麦克风图标切回语音模式
3. 按住中央的麦克风按钮开始说话，按钮会展开成声波动效，边说边显示实时转写文字
4. 松开手指结束录音，按钮变成「斟字酌句中...」状态，AI 开始润色
5. 润色完成后文字会自动填入输入框，并同步复制到剪贴板

整个过程不需要点任何确认按钮，松手即出稿。短文本（30 字以内）走单次快速润色，长文本走「清洗 + 结构化」两阶段润色，效果更好。

### 切换输入法

如果你同时在用其他输入法，可以通过系统的方式切换：

- 在大多数 Android 机型上，从状态栏下拉，点击「切换键盘」图标
- 或者在系统设置 > 语言和输入法 > 当前输入法中切换
- 也可以打开小牛说 App，在引导页点击「切换默认键盘」调出系统选择器

### 切换键盘模式

小牛说内置了四种键盘模式，通过顶部工具栏或底栏切换：

| 模式 | 说明 |
|------|------|
| 语音输入 | 大麦克风按钮，按住说话松开即得润色稿 |
| 九键拼音 | 3×3 T9 布局，默认键盘 |
| 26 键拼音 | 标准 QWERTY 拼音布局 |
| 英文 | 标准 QWERTY 英文布局 |

默认进入九键拼音。每种键盘底栏都有麦克风入口，随时可以切回语音输入。

## 进阶操作

### 配置自己的 API Key

默认情况下小牛说使用内置的服务通道，开箱即用。如果你想用自己的 Key（更稳定、无次数限制），按以下步骤配置：

1. 打开 App，进入「输入偏好设置 > API Key 专属通道」
2. 选择**语音识别**服务商：火山引擎（豆包 Seed ASR 2.0，默认）或百炼（阿里）
3. 填入对应的 App ID / Access Key（火山）或 AccessKey ID、Secret、AppKey（阿里）
4. 选择**语音优化**服务商：百炼通义千问（默认）、火山方舟（豆包），或选择「不优化」直接输出 ASR 原文
5. 如果选通义千问，可进一步选择模型：turbo（最快）、plus（推荐）、max（最强）
6. 点击「保存」生效

API Key 仅保存在本地，不会上传到小牛说的服务器。

### 管理热词词典

如果你经常提到一些专有名词（人名、产品名、行业术语），可以加入热词词典，提升识别准确度：

1. 进入「热词词典管理」
2. 在输入框输入热词回车添加单条，或点击右上角「批量导入」一次添加多个
3. 每条热词可设置别名（易误识别的近音词）
4. 可以单独启用或停用某个热词

热词会同时注入到语音识别和 AI 润色两个环节，确保专有名词拼写正确。

### 查看和复用历史记录

小牛说会在本地保存最近 50 条录音记录，包含音频、转写原文、润色稿：

1. 点击主页右上角的历史图标进入历史记录页
2. 点击任意一条可以复制原文或润色稿
3. 对历史记录可以重新润色，换一种风格再生成

### 调整润色风格

在设置里可以切换润色风格，适配不同场景：

- **通用流畅** — 清理口语废话，输出自然书面文本（默认）
- **轻松口语** — 保持口头聊天的随性语气
- **小红书活泼** — 活力语气，自动加 emoji，适合社交分享
- **商务正式** — 结构严谨、措辞得体，适合邮件和公文
- **不优化** — 直接输出语音识别原文，不经过 AI
