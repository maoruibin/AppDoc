# 小牛说

<img src="https://gudong.s3.bitiful.net/icon/niu_shuo.png" width="13%" alt="">

> 按住说话，松开即得，AI 驱动的语音写作系统输入法工具

小牛说（NiuTalk）是一款 AI 驱动的语音写作系统输入法工具，通过输入法集成的方式，让你在任何应用中按住说话、松开即可得到 AI 润色后的文稿，让语音输入真正成为高效的写作方式。

## 核心功能

- **语音输入** — 按住说话松开即得，所见即所得的语音输入体验
- **AI 润色** — 自动对语音转写内容进行智能润色，输出更流畅的文稿
- **输入法集成** — 作为系统输入法运行，可在任意应用中直接调用
- **实时转写** — 边说边转，实时将语音转换为文字
- **多场景适用** — 适用于聊天、写作、笔记、办公等各类输入场景
