# 联系我们

感谢你使用听咚咚！如果有问题、建议或反馈，欢迎通过下面这些方式找我。

## 反馈渠道

### 电子邮件

📧 gudong.name@gmail.com

邮件是最直接的方式，描述清楚问题就行，我会尽快回复（节假日可能有延迟）。

### 问题反馈

反馈 Bug 或提功能建议时，最好带上这些信息，方便快速定位：

- 设备型号和系统版本
- 应用版本号（在 **关于** 里查看）
- 问题出现的具体操作步骤
- 问题现象描述
- 相关截图或录屏（如有）

排查扫描、播放等疑难问题时，可以在 **设置 → 支持与高级 → 导出日志** 把本地日志发出来。
