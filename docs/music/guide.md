# 快速上手

本指南帮你快速上手听咚咚，从导入音乐到日常播放，几分钟就能玩转。

听咚咚是一款纯本地音乐播放器，所有歌曲都存在你的设备上，不联网、不上传，装好就能用，不需要注册账号也能完整听歌。

## 界面概览

打开 App，主界面由这几部分组成：

1. **歌曲列表**：主页面就是一张完整的歌曲列表，按添加时间倒序排列，最新加入的歌排在最前面。
2. **顶部工具栏**：左上角是菜单入口，右上角是搜索。中间还有播放模式、排序、多选三个快捷操作。
3. **侧边菜单**：点左上角菜单展开，里面是收藏、历史、资料库、歌单、音乐来源、账号和设置。
4. **迷你播放器**：屏幕底部那一条。播放时显示封面、歌名歌手，左右滑动可切上一首/下一首，点中间空白展开成全屏播放页。
5. **播放页**：全屏的大封面、进度条、播放控制，左右滑动切歌，还能看歌词和最近播放。

听咚咚没有底部 Tab 栏，主页就是歌曲列表，专注听歌本身。

## 基础操作

### 第一步：导入音乐

听咚咚通过扫描设备本地的音乐文件来建立曲库，第一次使用需要给一个能扫到音乐的目录。

1. 打开 App，如果列表是空的，点击底部迷你播放器上的「还没有音乐，点击添加音乐目录」。
2. 在弹出的系统目录选择器里，选中你存放音乐的文件夹（比如 `Music`、`Download` 或某个专门的歌单文件夹），点「允许访问」。
3. App 会自动开始扫描，顶部出现一条进度线，扫完后歌曲就出现在列表里。
4. 如果想扫描多个目录，进侧边菜单的「音乐来源」，点「添加音乐目录」继续添加。

扫描是增量进行的——之后每次打开 App，只会拉取新增或修改过的文件，不会重复全量扫描，很快。

### 第二步：播放歌曲

1. 在歌曲列表里，**点击任意一首歌就开始播放**，同时它和整列歌一起进入播放队列。
2. 看一眼底部迷你播放器，封面、歌名、播放/暂停按钮都在这里，左右拖动可切歌。
3. 点迷你播放器的空白区域，展开成全屏播放页：大封面、进度条、上下曲切换、播放模式、定时、播放列表、收藏、详情一应俱全。
4. 想跳到某一段，直接拖动进度条；想换首歌，在播放页左右滑动即可。

如果想让点歌时直接跳进播放页（而不是只播放、留在列表），去 **设置 → 播放设置** 打开「点击歌曲直接打开播放页」。

### 第三步：建一个歌单

1. 从侧边菜单点「新建歌单」，或者进任意一首歌的「更多」菜单选「添加到歌单 → 新建歌单」。
2. 输入歌单名称，从内置的封面图标里挑一个，点「确定」。
3. 之后给歌单加歌有几种方式：单首歌的「更多 → 添加到歌单」；或在主页长按进入多选模式，勾选多首后点底部「加歌单」。
4. 歌单在侧边菜单直接列出，点进去能看到里面的歌和数量。想改名字或删除，进侧边菜单的「管理歌单」。

## 进阶操作

### 歌词

只要你的音乐文件里内嵌了歌词（ID3 的 USLT 字段，或 FLAC 的 LYRICS / UNSYNCEDLYRICS 等字段），播放页就会自动显示。

- 在播放页**左右滑动**封面区，可以切到完整歌词页，当前行高亮，逐字点亮跟唱。
- 点歌词里的某一行，可以跳到那一句开始的位置。
- 想给没有歌词的歌补歌词，用「音乐标签」之类的工具把歌词写进文件，再回 App 重扫一次即可。

### 搜索

点主页右上角的搜索图标，输入歌名、歌手或专辑就能搜本地曲库，专辑匹配结果会单独列在最上面。

### 定时关闭

睡前听歌很实用。在播放页点「定时」图标，选 15/30/45/60 分钟，或拖动滑块自定义 1–120 分钟。可以勾选「自动延长到整首歌播完」，避免定时到点时把一首歌拦腰截断。

### 喜欢和资料库

- 在歌曲列表或播放页都能一键「喜欢」，所有喜欢的歌集中在侧边菜单的「我的收藏」里。
- 侧边菜单的「资料库」可以按专辑、文件夹、媒体类型（音乐/播客/录音/学习）浏览，方便分门别类找歌。

### 主题与个性化

去 **设置** 调整外观和习惯：

- **主题**：跟随系统、浅色、深色三种。
- **封面形状**：圆角或圆形。
- **播放页背景**：纯色、渐变（免费），毛玻璃是 PRO 功能。
- **专辑视图**：网格或列表。
