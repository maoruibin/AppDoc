# 听咚咚

> 简洁优雅的本地音乐播放器

听咚咚是一款简洁优雅的本地音乐播放器 App，提供本地音乐播放、歌单管理、歌词显示、资料库浏览等常用功能，所有音乐文件均存储在设备本地，纯本地播放，无需联网上传。

## 核心功能

- **本地音乐播放** — 扫描并播放设备本地音乐，支持常见音频格式
- **歌单与收藏** — 自由创建歌单，收藏喜爱歌曲，保留听歌历史
- **媒体资料库** — 按专辑、文件夹、类型浏览设备音乐
- **歌词显示** — 同步显示歌词，边听边看
- **多端账号** — 咕咚账号登录，PRO 权益跨应用通用
