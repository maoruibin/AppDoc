# 听咚咚

> 简洁优雅的本地音乐播放器

听咚咚是一款简洁优雅的本地音乐播放器 App，提供本地音乐播放、歌单管理、均衡器、歌词显示等常用功能，所有音乐文件均存储在设备本地，纯本地播放，无需联网上传。

## 核心功能

- **本地音乐播放** — 扫描并播放设备本地音乐，支持常见音频格式
- **歌单管理** — 自由创建和管理个人歌单，分类收藏喜爱的歌曲
- **均衡器** — 内置均衡器调节，打造属于你的听感
- **歌词显示** — 同步显示歌词，边听边看
