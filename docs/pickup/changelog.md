# 取件咚 更新日志

## 1.0.5
> 更新时间：2026/10

- **新增：Android 原生 CameraX 60fps 流式扫码枪**——SurfaceTexture GPU 硬件直通取景，原生层直连 ML Kit 零跨桥识别，彻底消灭拍照物理冻屏与快门停顿；对准货架约 200ms 内浮起候选码呼吸框，命中目标瞬间停下并高亮
- **新增：命中底图 4000 万像素超高清抓拍**，放大镜可双指缩放核对条形码与喷码细节
- 优化：远排货架号码识别更准（原生分析分辨率 640→1080p，高于远距识别安全线）
- 优化：误报「继续找」后同码 10 秒内不再反复确认，避免误报循环
- 修复：旋转识别占用主线程导致扫描页整屏冻屏（10.7s→毫秒级，全部后台化）
- 修复：扫描中切换画面偶现闪退（缩略图纹理释放时序，Impeller GL 崩溃）
- 修复：拍照节奏改为背压调度（识别完成才拍下一张），稳态零丢帧
- 技术说明：流式帧数据不再跨 Dart 平台通道（真机实测通道带宽拖垮渲染），iOS 与异常场景回退 Dart 拍照管线
