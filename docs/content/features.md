# 功能详解

## 收藏入库

- **四路收集**：系统分享、剪贴板检测、手动粘贴、小红书应用内剪藏
- **正文解析在云端完成**：客户端零解析逻辑，链接发给解析服务后返回干净的正文结构
- **图片全部本地化**：正文配图下载到手机并改写为相对路径——图片不落地，存档就是假的，这是好内容的铁律
- **幂等去重**：同一篇文章重复分享不会重复入库

## 精读引擎

- 与书咚咚同源的阅读内核：版式、翻页、进度记忆一致
- **双锚划线**：划线同时记录文本引文与位置坐标，杀进程、正文微调后都能精准复原
- 三种线型（波浪线 / 直线 / 马克笔）× 五种颜色，想法批注随时追加
- 排版自定义：字号、行距、四套纸感皮肤（宣纸 / 纯白 / 竹青 / 暗夜）

## 笔记沉淀

- 「思考」Tab 按文章浏览全部划线与想法
- **往昔灵感漫游**：历史笔记积累到一定数量后，随机回顾一条旧划线或札记
- **阅读成长看板**：本周阅读时长、读完篇数、产出思考数、连续精读天数

## 多端云同步（PRO）

- 数据同步到你**自己配置的云存储**，凭据仅存本地，App 不托管你的文章
- 增量同步 + 防抖自动触发 + 回到前台自动同步，也可手动立即同步
- 「同步历史」页完整展示每次会话的触发方式、耗时与增量明细

## 数据导出与备份

- **第二大脑**：全库划线与思考导出 Markdown（YAML frontmatter 元数据，深度适配 Obsidian / Logseq / Notion）
- **全库带图 ZIP**：每篇文章独立 content.md / notes.md / images/，附 README 索引与结构化元数据
- **JSON / CSV**：含 W3C 双锚坐标的全量 JSON 备份；带 BOM 的 CSV 阅读清单，Excel 打开不乱码

## 账号与 PRO

- 邮箱注册登录，账号在咕咚全系应用间互通
- 免费版：全部本地功能永久免费，收藏上限 50 篇
- PRO：收藏不限量 + 多端云同步；支持年费与永久买断两种
- 数据导出与已收藏内容永不设限——「数据主权、本地优先」是品牌承诺
