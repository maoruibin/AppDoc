# 常见问题

## 数据存在哪里？会上传我的文章吗？

文章、划线、想法、图片全部存储在你手机本地（Markdown 文件 + 本地数据库）。除非你主动开启云同步（PRO），否则数据不会离开你的设备。

## 原文被删了还能读吗？

能。收藏时正文会转成 Markdown、配图全部下载到本地，删文、封号都不影响你已存下的内容。

## 免费版有什么限制？

本地功能（收藏、精读、划线、想法、导出）永久免费，仅收藏数量上限 50 篇；PRO 解锁收藏不限量与多端云同步。

## 云同步的数据存在哪？你们能看到吗？

云同步把数据同步到**你自己配置的云存储**（你自己的 bucket 与凭据），凭据只保存在你的设备上，我们不托管、不经手你的文章数据。

## 支持哪些网站？

微信公众号、即刻、微博、B 站专栏、知乎、普通博客与大部分内容页均可直接收藏；小红书请使用应用内剪藏。个别反爬严格的站点如遇失败，可尝试手动粘贴正文。

## 换手机怎么迁移数据？

两种方式：

- 开通 PRO 后用云同步，新设备登录同一账号配置同一云存储即可拉取
- 或用「数据导出」生成全库 ZIP 归档，导入新设备

## 免费版到 50 篇后，已收藏的文章会没吗？

不会。上限只限制新增收藏，已收藏内容的阅读、划线、导出不受任何影响。

## 如何退款 / 注销账号？

PRO 为虚拟商品，开通后通常不支持无理由退款，退款事宜以支付宝渠道政策为准。账号可在设置中注销，注销不影响本地数据。

## 遇到问题怎么反馈？

在 App「设置 → 意见反馈」联系我们，或参考[联系我们](/content/contact)。
