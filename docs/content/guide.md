# 快速上手

## 认识三个 Tab

- **文章**：你的收藏流，未读分组、标星、搜索都在这里
- **思考**：全部划线与想法按文章沉淀，支持往昔灵感漫游
- **我的印记**：阅读成长看板与数据导出

## 存一篇文章

三种方式，选最顺手的：

1. **系统分享**：在微信、即刻、微博、浏览器里看到好文章，点「分享 → 好内容」，自动抓取正文与图片入库
2. **复制链接**：复制文章链接后回到 App，顶部会弹出提示条，点击即存
3. **手动粘贴**：点首页「添加」按钮，粘贴链接即可；粘贴的转发文字会自动提取清洗出有效链接

> 小红书内容请在 App 内使用剪藏入口，按引导完成抓取。

## 精读与划线

- 进入文章即进入精读页，正文以舒适排版呈现，阅读进度自动记忆
- **长按正文**选中文字即可划线：三种线型（波浪线 / 直线 / 马克笔）× 五种颜色
- 划线后可随手写想法，想法会跟随划线一起沉淀
- 底栏可调字号、行距、皮肤（宣纸 / 纯白 / 竹青 / 暗夜），放大的笔记图标直达本文笔记页

## 管理你的收藏

- 文章库支持未读 / 已读分组、标星、关键词搜索
- 左滑或长按可对文章做状态管理与删除

## 导出与备份

「我的印记」→ 数据导出与备份：

- **第二大脑**：全库划线与思考导出为带 YAML frontmatter 的 Markdown，直接进 Obsidian / Logseq / Notion
- **全库归档 ZIP**：每篇文章独立的正文、笔记与高清配图，电脑解压即用
- **结构化备份**：JSON 全量备份（含划线坐标）/ CSV 阅读清单

## 云同步（PRO）

1. 在「我的」开通 PRO
2. 进入同步设置，配置你自己的云存储凭据（数据落到你自己的 bucket，App 不托管）
3. 之后改动会自动防抖同步，也可在「同步历史」手动触发并查看每次同步明细

## 更新

App 内「设置 → 检查更新」即可获取最新版本。
