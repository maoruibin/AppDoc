# 好内容 更新日志

> 倒序排列。

## 0.2.11
> 2026-10-13

- **新增：想法批注层——写在正文里**。划线的想法不再只是个小角标：写在哪句，批注卡就长在哪句后面（带划线色条），重读时思考原位复现；一条划线追了多条想法按时间排开，超过三条自动折叠
- **新增：文末「读后记」**——对整篇文章写下的想法，以「好」字朱砂印标集中在文章结尾呈现，读完顺路看见；没写过就还是干净正文
- 新增：排版面板「批注」显隐开关——纯读模式一键收起批注层，想法角标回归
- 优化：写想法输入框重做——「发布」按钮沉到键盘上方拇指区，空文本不可误发，修改想法时为「保存」；写完想法改顶部轻提示，不打断阅读

## 0.2.0
> 2026-10-04

- **新增：三 Tab 架构与典雅纸感主题**——文章 · 思考 · 我的印记，思考一级化，划线与想法随时回顾；暖宣纸底 + 朱砂红点睛，纸张背景可切换（宣纸 / 纯白 / 竹青 / 暗夜）
- 新增：往昔灵感漫游，随机回顾一条历史划线与札记
- 新增：阅读成长看板——本周阅读时长、读完篇数、产出思考数、连续精读天数
- 新增：首启预置划线与想法示例，长按即可回看、改样式、追想法
- 修复：正式包缺少联网权限导致收藏解析、图片下载、更新检查失败的问题

## 0.1.0
> 2026-10-04

- **首个版本：本地优先的稍后阅读**
- 收藏入库：微信公众号、即刻、博客文章一键保存，文字图片全部本地化，删文了也还在
- 系统分享：在微信、即刻、浏览器里直接「分享 → 存到好内容」
- 精读体验：长按划线（波浪线 / 直线 / 马克笔 × 5 色）、写想法、换肤调字号，像读书一样读文章
- 笔记沉淀：全部笔记按文章分组，一键导出 Markdown
- 本地优先：无账号无订阅，文章以 Markdown 文件存在你的手机里
