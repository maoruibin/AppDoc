# 好内容

本地优先的稍后阅读与文章精读工具。把微信公众号、博客、社区里的好文章一键存进手机本地——文字和图片都变成你自己的文件，删文了也还在，像读书一样精读划线。

**你看到的好文章，都应该存在自己的手机里。**

## 为什么做这个 App

好文章太容易消失：删文、封号、平台关停，你收藏过的东西其实从来不属于你。各大平台的「收藏」只是把链接存在别人手里。

好内容把每一篇值得读的文章变成你手机里的一个文件——文字和图片都在本地，删不掉、丢不了、随时带走。

## 核心特点

- **真存档**：正文转 Markdown、配图全部下载到本地，断网完整可读，原文删了也还在
- **一键收藏**：系统分享直达，复制链接自动识别，支持微信公众号、即刻、微博、B 站专栏、博客等；小红书可用应用内剪藏
- **真精读**：书咚咚同款阅读引擎，长按划线（波浪线 / 直线 / 马克笔 × 5 色）、随手写想法、纸感皮肤与字号行距调节、阅读进度自动恢复
- **笔记沉淀**：划线与想法按文章沉淀，「我的印记」随机漫游回顾，一键导出 Markdown（适配 Obsidian / Logseq / Notion）
- **多端云同步**（PRO）：文章与笔记增量同步到你自己配置的云存储，换手机无缝接力
- **数据主权**：全库带图 ZIP 归档、结构化 JSON / CSV 一键导出，不订阅、不绑架，本地功能永久免费可用
