# Scheme

好内容支持通过 scheme 链接被其他应用直接打开：在笔记、快捷指令、浏览器地址栏等任意位置写一条 `gucontent://` 链接，点击即可直达好内容。

> 典型用法：在 inBox 笔记里直接粘贴好内容文章的链接，点击就能打开这篇文章的精读页。

## 打开文章精读页

打开指定文章的精读页面（含划线、想法、听内容等完整能力），格式为：

**gucontent://article?id=[文章id]**
> id 为文章 id。在好内容中打开这篇文章 → 底部「详情」面板 → 「复制文章链接」，即可获得这条链接。

可选追加 `url` 参数作为兜底定位（需 URL 编码），文章 id 在本机未命中时按原文链接查找：

**gucontent://article?id=[文章id]&url=[原文链接]**

## 快速收藏网页

把一个网页链接直接交给好内容收藏（后台解析入库，与系统分享同一链路），格式为：

**gucontent://add?url=[网页链接]**
> url 为要收藏的文章链接，**必须 URL 编码**（如 `https%3A%2F%2Fmp.weixin.qq.com%2Fs%2Fabc`）。

可选参数 `open=1`：收藏成功后直接打开这篇文章的精读页。

**gucontent://add?url=[网页链接]&open=1**

## 搜索文章

打开好内容的搜索页面并预填关键词，格式为：

**gucontent://search?keyword=[关键词]**
> keyword 为搜索内容，中文需 URL 编码。

## 打开文章库

回到好内容的文章库（收藏流）：

**gucontent://home**

## 注意事项

- 链接参数一律建议 **URL 编码**（`Uri.encodeComponent` / `encodeURIComponent`），未编码的含 `&` 参数会被截断；
- 自定义 scheme 在微信等应用的内置浏览器里不可点击，网页场景请使用系统分享到好内容（Android）或复制链接后打开好内容；
- 打开的文章如已删除或未同步到本机，会提示「文章不存在或已删除」；带 `url` 兜底参数时按原文链接查找。
