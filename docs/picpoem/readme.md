# 诗图

<img src="../public/img/picpoem_icon.png" width="13%" alt="诗图">

> 取一景，成一句诗

诗图是一款把照片写进诗里的应用。拍一张照片，AI 看懂画面里的色彩、情绪与意境，从古今中外的诗词中挑出那一句最贴切的，落成一张可分享的诗图卡片。整个过程像一场小小的仪式——观图、寻诗、落款，不急不躁。

不用再对着一张好看的风景照苦想文案。诗图替你读图、替你选诗，一键落成带着东方美学的卡片。

## 核心功能

- **AI 看图配诗** — 识别画面的主体、色彩、季节与意境，匹配一首意境相通的真实诗作（含标题、作者、朝代、诗句与注解）
- **仪式感动效** — 取景 → 观图 → 寻诗 → 落款，墨点扩散、印章落下，配诗过程本身就是体验
- **卡片模板** — 提供多种版式（融合 · 图底文字、书札 · 上图下文），照片与诗文各有姿态
- **换一首 / 换风格** — 一首不满意就上下滑动换一首；可在古体、现代之间切换风格，同一张图配出不同味道
- **自带 AI Key，开箱即用** — 内置共享体验配置，零门槛上手；也支持 BYOK，换成自己的 AI 服务
- **保存与分享** — 高清诗图卡片一键存相册、一键分享到朋友圈或小红书
