# 常见问题

## 配诗相关

### AI 配不出诗 / 报错了怎么办？

配诗失败时会显示「诗未寻得」和具体原因，对照排查即可：

| 提示 | 原因 | 处理 |
|------|------|------|
| 网络慢，请重试 | 请求超时或无网络 | 换个网络环境，点「重试」 |
| API Key 无效，请检查设置（401） | Key 填错或已失效 | 进「设置 > AI 服务」核对或更换 Key |
| 请求过于频繁，请稍后重试（429） | 触发了服务商限速 | 等几秒再试；频繁出现建议换自己的 Key |
| API 地址或模型名不存在（404） | 地址或模型名填错 | 核对地址和模型名是否正确 |
| 请先在设置中配置 AI API Key | 内置 Key 已失效或被清空 | 进「设置 > AI 服务」点「恢复内置」，或填自己的 Key |

如果还排查不了，报错对话框里有「诊断信息」（请求 URL、模型、状态码、服务端返回），可以复制发给开发者。

### 生成的诗不满意怎么办？

- 点底部的 **换一首**，或直接在预览页 **上下滑动**，用同一张图重新配一首
- 点底部的 **风格** 切换诗风：古体偏古典诗词，现代偏现代诗，自动由 AI 判断
- AI 每次生成的诗会有随机性（温度参数 0.8），多换几次往往能遇到更喜欢的

### AI 会编造不存在的诗吗？

不会。提示词里明确要求「必须是真实存在的诗，不要编造」，并要求返回结构化数据（标题、作者、朝代、体裁、诗句、注解）。绝大多数情况下返回的是经典名作或知名现代诗。

## AI Key 配置

### 怎么配置自己的 AI Key？

进「设置 > AI 服务」，填三项后保存：

1. **API 地址** — 兼容 OpenAI 协议的服务地址，如 `https://api.siliconflow.cn/v1/chat/completions`
2. **API Key** — 服务商提供的密钥
3. **模型** — 一个支持看图的视觉模型名

地址带不带 `/chat/completions` 后缀都行，应用会自动补全。想换回内置配置，点「恢复内置」即可。

### 支持哪些 AI 服务？

任何兼容 OpenAI Chat Completions 协议、且支持视觉（看图）的服务都可以，比如硅基流动、智谱 GLM、OpenAI 等。填好对应的地址、Key 和视觉模型名即可。

### 内置的 Key 能用多久？

内置的是共享体验 Key，配额有限，多人共用容易触发限速（429）。长期或频繁使用建议换成自己的 Key。

## 图片与数据

### 我选的图片上传到哪了？

为了让 AI 能看到图，应用会把压缩图（800px、质量 80）上传到一个临时图床（`upload.gudong.site`），换成一个公开 URL 再发给 AI。原图始终留在你手机本地，不会上传。图床上的压缩图 **15 天后自动删除**。

### 我的作品数据存在哪？

所有诗作和图片都存在你手机的本地存储里：

- 诗作文字 → 本地 SQLite 数据库（`shitu.db`）
- 图片文件 → 应用文档目录下的 `shitu/` 文件夹
- 设置项 → 应用的 `shared_preferences`

应用不要求注册账号，数据不离开你的设备（除了 AI 配诗那一步必要的上传）。

### 删除一张诗图会把图也删了吗？

会。删除诗作时会一并清理它对应的原图、压缩图和诗图卡文件，不会留下无用文件。

## 使用限制

### 每天能配多少次诗？

当前版本直接走你配置的 AI 服务（默认走内置共享 Key），应用本身不限次数，限制来自 AI 服务商的配额。后续计划在应用层加入「每天 3 次免费」的额度管理。

### 需要联网吗？

配诗必须联网（要上传压缩图、调 AI）。浏览历史作品、查看详情、保存分享已生成的诗图都不需要联网。

## 其他

### 为什么只有两种卡片模板？

当前版本先实现了「融合」和「书札」两种版式，完整规划的 5 款（墨韵 / 素笺 / 留白 / 月下 / 剪影）会在后续版本陆续加上。模板在设计上是可扩展的，新增不会影响已有数据。

### 可以不拍照、只输入一句话生成诗图吗？

这是规划中的「心中诗」无图模式，当前版本暂未实现，后续迭代会加上。
