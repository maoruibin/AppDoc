# 快速上手

本指南将帮助你快速了解并开始使用诗图。

## 界面概览

诗图的应用界面极简，只有三个主要场景：

1. **诗廊首页** — 打开应用看到的页面，单列大卡片瀑布流展示所有作品，像翻一本诗集；底部中央有「取景」按钮进入创作；右上角是设置入口
2. **创作流程** — 从取景开始的全屏沉浸流程，依次经历取景、观图、寻诗、落款，最后停在诗图预览
3. **诗图详情** — 在首页点开任意一张历史作品，可查看大图、诗文与 AI 注解，并能保存、分享或删除

## 基础操作

### 取景配诗（核心流程）

1. 在首页点击底部的 **取景** 按钮（黑底方形按钮）
2. 系统相册被唤起，从相册中选一张照片（也可在确认页改用「拍照」当场拍一张）
3. 选好图后照片铺满全屏，底部出现操作条：「重新选」「拍照」「寻诗」
4. 点击 **寻诗** 进入成诗过程，整个过程无需操作，依次呈现三个阶段：
   - **观图** —「正在看这幅画…」，AI 正在识别画面
   - **寻诗** —「千首诗中，寻那一句…」，AI 正在挑诗
   - **落款** —「落笔成章…」，朱砂印章逐渐盖上
5. 完成后自动进入全屏预览，看到成稿：图片 + 诗文 + 标题作者 + 印章
6. 此时这张诗图已经自动保存到本地「诗廊」，回到首页就能看到它

### 保存与分享

1. 在生成完成的预览页，或从首页点开任意一张历史诗图
2. 点击 **保存**，诗图卡（高清 PNG）会存入系统相册，提示「已存到相册」
3. 点击 **分享**，调出系统分享面板，可发到微信、朋友圈、小红书等任意应用

## 进阶操作

### 换一首

- 在生成预览页点击底部的 **换一首**，会用同一张图重新配诗
- 也可以直接在预览页 **上下滑动**（类似翻书），就能换一首新诗，旧诗淡出、新诗浮现

### 换风格

配诗支持三种风格，影响 AI 挑诗的偏好：

| 风格 | 说明 |
|------|------|
| 自动 | 优先古典诗词，画面气质更契合时也可选现代诗或译作 |
| 古体 | 优先从唐诗、宋词、《诗经》等中国古典诗词中选取 |
| 现代 | 优先选取现代诗（北岛、顾城、海子等）或古诗词的现代演绎 |

- 在生成预览页点击底部的 **风格**（显示当前风格名），底部弹出面板选择
- 也可在「设置 > 默认诗风」里改默认偏好，新生成的诗会沿用

### 切换卡片模板

诗图提供不同的卡片版式，照片与诗文的排布各有姿态：

- 进入「设置 > 卡片版式」
- 当前可选：
  - **融合 · 图底文字** — 图片铺底，诗文浮于其上，照片是主角
  - **书札 · 上图下文** — 上半照片、下半宣纸竖排诗文，像展开的书信
- 切换后新生成的诗图会采用新模板

### 配置自己的 AI Key（BYOK）

诗图内置了共享体验配置，开箱即用。如果想用自己的 AI 服务（更稳定、不限速、可选模型），可以自行配置：

1. 进入「设置 > AI 服务」
2. 填写三项：
   - **API 地址** — 兼容 OpenAI 协议的服务地址，如 `https://api.siliconflow.cn/v1/chat/completions`
   - **API Key** — 服务商提供的密钥
   - **模型** — 一个支持看图的视觉模型，如 `Qwen/Qwen3-Omni-30B-A3B-Captioner`
3. 点击 **保存**；想恢复内置配置随时点「恢复内置」

详细的配置说明和常见报错排查见 [功能详解](features.md) 和 [常见问题](qa.md)。
