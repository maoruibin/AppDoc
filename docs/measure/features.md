# 功能详解

量咚咚目前内置 7 个测量工具，全部本地运行。以下是各工具的功能参数。

## 工具一览

| 工具 | 测量对象 | 模式 | 特色能力 |
|---|---|---|---|
| 尺子 | 长度 | 全屏刻度 | 银行卡一键校准（85.60 毫米）、厘米/英寸切换 |
| 水平仪 | 水平度 / 坡度 | 气泡水平、坡度测角 | 水平震动提醒、支持置零 |
| 指南针 | 方位角 | 罗盘 | 倾角补偿、任意握持姿态读数一致、磁场异常提醒 |
| 量角器 | 角度 | 屏幕量角、贴面测角 | 双模式覆盖平面与空间角度 |
| 分贝仪 | 环境噪音 | 实时检测 | 最大/最小/平均统计、参考刻度 |
| 取色器 | 颜色 | 相机取色、相册导入 | 放大镜像素级选点、一键复制 HEX |
| 挂画水平 | 墙面水平 | 相机取景 | 参考线可上下拖动、横竖屏、屏幕常亮 |

## 通用特性

| 特性 | 说明 |
|---|---|
| 免费 | 完全免费，无广告、无内购 |
| 无账号 | 没有账号体系，打开即用 |
| 本地测量 | 传感器数据仅用于实时显示，不落盘、不上传 |
| 深色模式 | 全面适配，跟随系统 |
| 竖屏锁定 | 测量页面布局稳定，全面屏沉浸显示 |

## 校准说明

- **尺子**：不同设备屏幕密度有差异，首次使用建议用银行卡长边（85.60 毫米）校准一次，校准值保存在本地
- **指南针**：指南针依赖设备磁力计，出现读数异常时按提示画 8 字校准
- **水平仪**：使用「置零」功能后，后续读数为相对当前面的角度
