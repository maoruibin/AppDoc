# 量咚咚

> 尺子、水平仪、指南针、量角器、分贝仪、取色器，一 App 全搞定。

量咚咚是一款免费的本地测量工具箱，把日常会用到的测量工具装进同一个 App：量长度、测水平、辨方向、测角度、测噪音、取颜色，打开即测。没有广告、没有账号，所有测量都在本地完成。

## 核心功能

- **尺子** — 全屏刻度直接量，银行卡一键校准（85.60 毫米长边对齐即可），厘米/英寸自由切换
- **水平仪** — 气泡水平 + 坡度测角双模式，水平时震动提醒，支持置零
- **指南针** — 倾角补偿方位角，平放、竖持等任意握持姿态读数都准确，磁场异常及时提醒
- **量角器** — 屏幕量角 + 贴面测角双模式，角度一目了然
- **分贝仪** — 环境噪音检测，最大/最小/平均统计，附参考刻度
- **取色器** — 相机拍照取色 + 相册导入，放大镜像素级选点，一键复制 HEX
- **挂画水平** — 相机对准墙面，参考线辅助挂画找平，横竖屏都支持
- **本地优先** — 无广告、无账号、不联网，测量数据只留在你的设备上
