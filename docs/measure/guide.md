# 快速上手

下载安装量咚咚后，首页会以卡片形式列出所有工具，点哪个进哪个，打开即测，无需任何注册或配置。

## 尺子

1. 把手机贴在被测物体表面
2. 首次使用时用一张银行卡校准：卡片长边（85.60 毫米）对齐刻度，拖动校准条即可
3. 厘米/英寸可随时切换

## 水平仪

1. 把手机平放在被测面上
2. 气泡居中即水平，此时会有震动提醒
3. 「置零」可以把当前角度作为零点，测相对坡度
4. 贴墙面测坡度时切换到坡度测角模式

## 指南针

1. 远离磁场干扰（磁铁、电器）
2. 平放或竖持都可以，量咚咚会做倾角补偿，读数一致
3. 出现磁场异常提醒时，画 8 字校准或换个位置

## 量角器

1. 屏幕量角：把被测角的两边与屏幕刻度线对齐读数
2. 贴面测角：把手机沿一个边贴平，再转向另一条边

## 分贝仪

1. 进入后自动开始检测环境噪音
2. 查看当前读数与最大/最小/平均值
3. 参考刻度可以帮你判断噪音环境是否安静

## 取色器

1. 「拍照取色」对准目标；「相册导入」选择已有图片
2. 拖动放大镜做像素级选点
3. 点击读数即可复制 HEX 色值

## 挂画水平

1. 选择要挂画（或已挂画）的墙面
2. 相机对准墙面，屏幕上出现参考线
3. 上下拖动参考线到目标高度，按提示找平后标记钉位
