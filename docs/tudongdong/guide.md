# 快速上手

本指南帮你几分钟内上手图咚咚，把图片处理成想要的样子。

图咚咚的所有操作都在你的设备本地完成，不需要联网，图片也不会上传到任何服务器。

## 界面概览

打开应用后，底部导航分两个标签：

- **工具箱**：图咚咚的主页，所有功能从这里进入。
  - 顶部右上角是 **设置** 入口（账号、PRO 权益、关于）。
  - **核心创作** 区：以大卡片形式展示三个主力工具——截图美化、多图转 PDF、长图拼接。
  - **便捷处理** 区：九宫格列出其余工具——图片格式转换、智能大小压缩、脱敏与防盗水印、图片阴影、文字卡片。
  - **最近保存** 区：横向滚动展示最近导出的作品，点开即可预览或分享。
- **作品集**：按时间顺序列出你导出过的所有作品，支持预览、分享、删除。

## 基础操作

不论用哪个工具，流程基本一致：**选图 → 选功能 → 调参数 → 保存**。

### 通用流程

1. 在工具箱点击某个工具卡片。
2. 在弹出的底部面板里选择「立即选取一张图片」（多图工具则是「批量选择并导入图片」），也可以选择「暂不导入，直接进入工具」后再选图。
3. 进入工具后调整参数，实时预览效果。
4. 点击底部的保存按钮，等待本地处理完成。
5. 弹出导出成功对话框后，可分享、保存，或前往作品集查看。

下面是几个常用工具的具体走法。

### 截图美化

1. 工具箱 → 核心创作 → **截图美化**。
2. 选择一张截图（手机截屏、App 界面截图都可以）。
3. 在配置面板里挑选**背景渐变色预设**（莫兰迪纯色、淡彩渐变、活力渐变三类共 26 种）。
4. 视需要选择**输出画布尺寸比例**（如推特 16:9、小红书 3:4、朋友圈 1:1 等）。
5. 选择**窗口外壳装饰**（macOS 浅色/深色红绿灯、或无外壳直角裸图）。
6. 用滑块微调内边距、截图圆角、阴影模糊、缩放占比。
7. 点击「保存与导出高画质图片」，结果会写入作品库和系统相册。

### 长图拼接

1. 工具箱 → 核心创作 → **长图拼接**。
2. 批量选择多张截图（单次最多 20 张，超过 3 张需 PRO）。
3. 按上下顺序排列图片，可以用上移/下移调整位置。
4. 对单张图设置顶部/底部裁剪像素，去掉接缝处的多余内容。
5. 点击「生成长图」，本地纵向合成为一张 PNG。

### 多图转 PDF

1. 工具箱 → 核心创作 → **多图转 PDF**。
2. 选择多张图片（可继续追加）。
3. 在缩略图列表里调整页码顺序（左移/右移）、删除某页。
4. 选择是否「合并多图为一个 PDF 文件」（合并为 PRO 功能），并调节导出画质。
5. 点击生成，得到一个或多个 PDF 文件。

### 图片压缩

1. 工具箱 → 便捷处理 → **智能大小压缩**。
2. 选一张原图。
3. 拖动质量滑块（10%–95%），界面会实时显示预计压缩后大小。
4. 点击「立即开始压缩并保存」，输出 JPG 文件。

## 进阶操作

### 作品管理

所有导出的文件都会自动登记到「作品集」，并保留文件名、格式、大小和导出时间。在作品集里可以：

- 点击作品进入全屏预览，左右切换查看。
- 一键分享到其他应用。
- 删除作品（同时会删除本地物理文件，操作不可恢复）。

首页「最近保存」的右上角有「清空」按钮，可以一键清空最近记录。

### 透明背景导出

当你只想给图片加投影、不想加任何背景时（比如做设计素材），用 **图片阴影** 工具而不是截图美化。图片阴影导出的是透明背景 PNG，只有图片本身和它的投影。

### 防盗水印

发送作品前，用 **脱敏与防盗水印** 给图片铺一层倾斜的平铺文字水印。可以自定义文字内容（比如你的名字、社交账号）、不透明度和字号，3.5x 高清光栅化导出。

### 高清导出

截图美化支持 **3.5x 高清光栅化导出**，是 PRO 专属功能；免费版会以 2x 标准清晰度导出。如果对画质有要求，可在 设置 → 账号与权益 中升级。
