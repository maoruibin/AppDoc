# 图咚咚

<img src="https://gudong.s3.bitiful.net/icon/tu_dong_dong.png" width="13%" alt="">

> 让图片随心所欲，简单易用、高颜值的全能本地图片处理工具箱

图咚咚是一款本地优先的图片处理工具箱 App，内置 17 个图片工具，覆盖截图美化、3D 套壳、拼图排版、打码、智能消除、抠图换背景、文字识别、视频转 GIF、PDF 处理等高频场景。**所有图片处理均在本地完成，不上传云端，隐私是核心承诺。**

## 核心工具

- **截图美化** — 渐变背景、羽化阴影、圆角，一键做出社交媒体配图
- **3D 套壳** — 截图秒变展示级效果图：七种角度、多种材质与棚拍背景
- **图片转 PDF** — 多张图片合并或逐张导出 PDF
- **长图拼接** — 聊天记录、教程步骤纵向无缝拼接
- **裁剪旋转** — 精确裁剪与旋转
- **文字识别（OCR）** — 本地识别图中文字，识别后可 AI 润色

## 更多工具

- **拼图排版** — 2~9 张多图自适应排版，横排/竖排/宫格/主次布局
- **视频转 GIF** — 截取视频片段本地生成动图，不上传不联网
- **打码** — 拖框/涂抹 × 模糊/马赛克/纹理/表情
- **智能消除** — 涂一涂去除路人、水印等多余元素，端侧 AI 推理
- **抠图换背景** — 端侧人像分割，换底色、背景图、背景虚化
- **小红书配图** — 截图笔记/风景卡片/纯色留白，一键出 3:4 配图
- **文字卡片** — 大字报/便签/金句卡，多文字层级排版
- **格式转换** — JPG、PNG、WEBP 等格式自由转换
- **图片压缩** — 带预览与真实体积反馈的智能压缩
- **水印标注** — 文字/图片水印保护版权
- **PDF 工具** — PDF 转图片，提取文字 + AI 润色

## AI 能力（免费）

- **AI 图片助手** — 对话式多步图片处理，压缩/转格式/缩放/旋转一句话完成
- **AI 润色** — OCR 识别与 PDF 提取文字后自动纠错、整理、翻译、总结
- BYOK 模式：在设置页配置你自己的 AI 服务商 Key（智谱 / DeepSeek / Kimi / 通义 / 自定义），App 直连服务商，图咚咚不经手、不存储任何数据

## 作品集

所有工具导出的结果统一进入本地作品集：自动登记、全屏预览、一键保存相册或分享。
