# 图咚咚

<img src="https://gudong.s3.bitiful.net/icon/tu_dong_dong.png" width="13%" alt="">

> 让图片随心所欲，简单易用、高颜值的全能本地图片处理工具箱

图咚咚是一款全能本地图片处理工具箱 App，提供图片压缩、格式转换、图片裁剪、拼接、水印、PDF 导出、EXIF 查看等常用图片处理功能，所有操作均在本地完成，无需上传云端。

## 核心功能

- **图片压缩** — 智能压缩图片体积，支持自定义质量与尺寸
- **格式转换** — 在 JPG、PNG、WEBP 等格式之间自由转换
- **图片裁剪** — 精确裁剪图片，支持自定义比例与自由裁剪
- **图片拼接** — 多张图片横向或纵向无缝拼接
- **水印工具** — 为图片添加文字或图片水印，保护版权
- **PDF 导出** — 将多张图片一键导出为 PDF 文档
- **EXIF 查看** — 查看图片的完整拍摄信息与元数据

## 即将推出

- **批量处理** — 一次性处理大量图片，提升效率
- **AI 抠图** — 智能识别主体，一键去除背景
- **图片美化** — 滤镜、调色、增强等一键美化
- **长图制作** — 智能拼接长图，支持模板排版
