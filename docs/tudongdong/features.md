# 功能详解

图咚咚目前内置 17 个图片工具，按核心创作和常规处理两块介绍。所有处理都在本地完成，断网也能用（AI 相关能力除外）。

## 核心创作

### 截图美化

为截图套上高颜值渐变背景、羽化阴影和圆角，一键做出适合社交媒体或产品展示的配图。

**特性**

- 丰富的背景配色预设，覆盖纯色、渐变、撞色多种风格，也支持从原图取色生成配色。
- 可叠加 macOS 风格的窗口外壳（红绿灯按钮），让截图更像 App 真实界面。
- 多种社交平台画布比例预设，省去后期裁剪。
- 高清光栅化导出，全员 3.5x（此前的高清导出付费门槛已取消）。

### 3D 套壳

截图专用：把平面截图变成带厚实机身的展示级效果图。

**特性**

- 七种展示角度，角度支持拖拽微调，构图随手调。
- 多种机身材质与棚拍背景，全部可实时预览，导出时统一校验权益。
- 前四个背景与从截图取色免费；支持加一句文案，位置可拖动，浅色/深色/自动三态配色。
- 角标（水印）免费可关闭。
- 编辑器记住上次配置。

### 图片转 PDF

把多张图片转换成 PDF 文档，支持合并成单份或批量导出多份。

**特性**

- 缩略图列表实时显示页码，可调整顺序、删除单页，支持继续追加。
- 合并为单个 PDF 需 PRO；关闭合并时每张图单独导出。
- 画质可调，降低画质能显著缩小 PDF 体积。

### 长图拼接

把多张截图纵向拼接成一张长图，适合聊天记录、教程步骤、订单流水等连续内容。

**特性**

- 每张图可单独设置顶部/底部裁剪，去掉接缝处的重复内容。
- 顺序可自由调整，可随时追加或删除单张。
- 单次超过 3 张需 PRO。

### 裁剪旋转

精确裁剪图片，支持自由裁剪与旋转，基础编辑的可靠默认选择。

### 文字识别（OCR）

本地识别图片中的文字，全程离线。

**特性**

- 基于 ML Kit 中文识别模型，识别质量好、速度快。
- 结果页图/文分区展示，支持行内复制与清空。
- 识别完成后可自动 AI 润色：修正错字、整理断行、中英互译、提炼总结（免费，需在设置中配置自己的 AI Key）。
- 整工具为 PRO 功能，进入工具即有说明。

## 常规处理

### 拼图排版

多张图片自适应排版，公众号与社交全比例拼图。

**特性**

- 支持 2~9 张多图。
- 横排 / 竖排 / 宫格 / 主次等多种布局。
- 自适应比例，带圆角与悬浮阴影。

### 视频转 GIF

截取视频片段本地生成动图，不上传不联网。

**特性**

- 时间轴修剪，预览循环播放。
- 免费档：≤5 秒、480P、10fps。
- 长片段、720P、15fps、倒放/反弹为 PRO 能力。

### 打码

给图片敏感区域上遮罩，移植自独立打码工具的拖框交互。

**特性**

- 拖框即打码，框可移动、缩放、删除；也支持涂抹。
- 效果：模糊 / 马赛克 / 纹理 / 表情。
- 矩形 / 圆形两种形状，多档强度。

### 智能消除

端侧 AI 消除笔：涂一涂或框选即可去除路人、水印等多余元素。

**特性**

- 涂抹 + 框选双标记方式，支持多轮消除。
- MI-GAN 端侧推理，模型首次使用时自动下载，之后完全离线。

### 抠图换背景

端侧人像分割，一键抠出人像换背景。

**特性**

- 换纯色/渐变底色免费。
- 换背景图与背景虚化为 PRO 能力。
- 边缘羽化处理，过渡自然。

### 小红书配图

纯粹的图片包装工具：不做花哨编辑，快速出社交平台配图。

**特性**

- 三种模式：截图笔记 / 风景卡片 / 纯色留白（文字独立排版）。
- 3:4 / 1:1 / 9:16 主流比例。
- 从原图取色生成双色渐变背景，配色和图片天然协调。

### 文字卡片

多文字层级排版的文字海报工具，免选图直入。

**特性**

- 大字报 / 干货便签 / 金句卡三大预设。
- 主标题 + 标签 + 多行清单 + 作者的层级排版。
- 纯色或渐变背景，导出高分辨率 PNG。

### 格式转换

在 JPG、PNG、WEBP 之间互转，编辑器式界面带处理前预览。

- 支持 HEIC、LivePhoto 等 iOS 图片的读取。
- WEBP 通过原生压缩引擎转换，质量保持高水准。

### 图片压缩

控制图片体积，编辑器式界面实时预览压缩效果与真实输出体积。

- 质量滑块自由权衡体积和画质，所见即所得。
- 后台 isolate 压缩，不卡界面。

> 经验值：质量在 70%–80% 之间，肉眼几乎无差别，但体积通常能缩减 60%–80%。

### 水印标注

给图片添加文字或图片水印，保护版权或标注信息。

- 自定义水印内容，平铺或单点摆放。
- 可调不透明度与字号。

### PDF 工具

- **PDF 转图片**：免费，系统级栅格化。
- **提取文字**：PRO 功能，提取后支持 AI 润色。

## AI 能力（免费）

图咚咚的 AI 能力全部免费，采用 BYOK（自带 Key）模式：在设置页配置你自己的 AI 服务商 Key（智谱 / DeepSeek / Kimi / 通义 / 自定义 OpenAI 兼容服务），App 直连服务商，**图咚咚不经手、不存储任何对话数据**。不配置 AI 不影响任何本地功能。

- **AI 图片助手**：对话式多步图片处理，压缩/转格式/缩放/旋转/查信息/保存一句话完成。
- **AI 润色**：文字识别、PDF 提取文字后自动润色，可随时停止或撤回。

## 作品集

所有工具导出的结果会统一进入作品集管理。

- **自动登记**：每次导出都会写入本地数据库，记录文件名、格式、大小、时间、所属工具。
- **本地存储**：文件保存在设备文档目录下的 `ImageLab/{工具名}/` 子目录中，命名带时间戳，不会覆盖。
- **预览与分享**：支持全屏预览、一键保存系统相册和分享；支持单选/多选删除。
- **删除即清理**：删除一条记录会同时删掉对应物理文件，释放空间。

## PRO 权益

图咚咚的基础功能完全免费，以下能力需要升级 PRO：

| 功能 | 免费版 | PRO 版 |
|------|--------|--------|
| 文字识别（OCR） | 不支持 | 全功能 |
| PDF 提取文字 | 不支持 | 支持 |
| 多图合并为单个 PDF | 不支持 | 支持 |
| 长图拼接超过 3 张 | 最多 3 张 | 不限 |
| 抠图换背景图 / 背景虚化 | 换底色免费 | 解锁 |
| 3D 套壳导出 | 部分背景免费 | 全部解锁 |
| 视频转 GIF 进阶 | ≤5s / 480P / 10fps | 长片段 / 720P / 15fps / 倒放反弹 |

升级入口在 设置 → 账号与权益，支付通过支付宝完成。
