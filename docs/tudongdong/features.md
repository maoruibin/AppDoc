# 功能详解

图咚咚把日常图片处理拆成 8 个独立工具，各自专注一件事。所有处理都在本地完成，断网也能用。下面按核心创作和便捷处理两块逐一介绍。

## 截图美化

为截图套上高颜值渐变背景、羽化阴影和圆角，一键做出适合社交媒体或产品展示的配图。

**特性**

- 提供 26 种背景配色预设，覆盖莫兰迪纯色、淡彩渐变、活力撞色三类风格。
- 可叠加 macOS 风格的窗口外壳（红绿灯按钮），让截图更像 App 真实界面。
- 多种社交平台画布比例预设，省去后期裁剪。
- 光栅化导出，免费版 2x、PRO 版 3.5x 高清。

**输出画布尺寸预设**

| 预设 | 比例 | 适用场景 |
|------|------|----------|
| Auto | 自适应贴合原图 | 通用 |
| Twitter 推特 | 16:9 | 推特发帖 |
| Chrome 开发者商店 | 16:10 | 浏览器扩展展示 |
| Product Hunt | 127:76 | 产品发布展示 |
| 小红书高图 | 3:4 | 小红书图文 |
| 微信公众号封面 | 2.35:1 | 公众号头图 |
| 朋友圈/正方形 | 1:1 | 朋友圈配图 |

**窗口外壳样式**

| 样式 | 说明 |
|------|------|
| macOS 经典浅色红绿灯 | 浅色窗口顶栏，左侧红黄绿圆点 |
| macOS 磨砂深色红绿灯 | 深色窗口顶栏，质感更强 |
| 无窗口外壳 | 直角裸图，不加任何装饰 |

**滑块参数**

| 参数 | 范围 | 默认 |
|------|------|------|
| 画布内边距 | 10–80 | 32 |
| 截图圆角大小 | 0–30 | 12 |
| 精致阴影模糊 | 0–40 | 20 |
| 截图缩放占比 | 0.6–1.1 | 0.9 |

## 长图拼接

把多张截图纵向拼接成一张长图，适合聊天记录、教程步骤、订单流水等连续内容。

**特性**

- 单次最多拼接 20 张图片。
- 每张图可单独设置顶部/底部裁剪像素（步进 10px），去掉接缝处的重复内容。
- 顺序可自由调整（上移/下移），可随时追加或删除单张。
- 本地解码并纵向合成，导出 PNG。

**限制**

| 项目 | 免费版 | PRO 版 |
|------|--------|--------|
| 单次拼接张数 | 最多 3 张 | 最多 20 张 |

## 多图转 PDF

把多张图片转换成 PDF 文档，支持合并成单份或批量导出多份。

**特性**

- 缩略图列表实时显示页码，可左移/右移调整顺序，可删除单页。
- 支持继续追加图片，不必一次性选完。
- 两种导出模式：合并为单个 PDF，或每张图各生成一个 PDF。
- 画质可调（20%–100%），降低画质能显著缩小 PDF 体积。

**导出设置**

| 设置 | 可选项 | 说明 |
|------|--------|------|
| 合并多图为一个 PDF | 开 / 关 | 开启时多图合成单份 PDF（PRO 功能）；关闭时每张图单独导出 |
| PDF 导出画质 | 20%–100%（步进 10%） | 数值越低文件越小 |

## 智能大小压缩

通过降低 JPG 编码质量来压缩图片体积，适合需要控制文件大小的场景（比如上传有大小限制的平台）。

**特性**

- 实时显示原图体积和预计压缩后体积，所见即所得。
- 质量滑块 10%–95%，自由权衡体积和画质。
- 后台 isolate 压缩，不卡界面。
- 输出 JPG 格式。

**参数**

| 参数 | 范围 | 默认 |
|------|------|------|
| 输出图片质量比例 | 10%–95%（步进 5%） | 70% |

> 经验值：质量在 70%–80% 之间，肉眼几乎无差别，但体积通常能缩减 60%–80%。

## 图片格式转换

在 JPG、PNG、WEBP 之间互转，应对不同平台对格式的限制。

**特性**

- 支持 JPG、PNG、WEBP 三种主流格式互转。
- JPG/PNG 走纯 Dart 编解码，跨平台一致。
- WEBP 通过原生压缩引擎转换，质量保持 100%。
- 处理 HEIC、LivePhoto 等 iOS 图片时也能正常读取（系统层面支持）。

**目标输出格式**

| 格式 | 特点 | 典型用途 |
|------|------|----------|
| JPG | 体积小，不支持透明 | 照片、需要压缩的图 |
| PNG | 无损，支持透明 | 截图、带透明通道的设计素材 |
| WEBP | 高压缩比，现代格式 | 网页、追求极致体积 |

## 脱敏与防盗水印

给图片铺一层倾斜的平铺文字水印，保护版权或遮挡敏感区域。

**特性**

- 自定义水印文字（默认「图咚咚防盗水印」），可改成你的名字或社交账号。
- 水印以 -30° 倾角全图平铺，难以简单裁掉。
- 可调不透明度和字号，兼顾美观与防盗效果。
- 3.5x 高清光栅化导出 PNG。

**参数**

| 参数 | 范围 | 默认 |
|------|------|------|
| 水印不透明度 | 0.05–0.80 | 0.25 |
| 水印字体大小 | 10–24 | 14 |

## 图片阴影

只给图片本身添加投影，不加任何背景，导出透明背景 PNG，适合设计素材和层次增强。

**特性**

- 八个维度精细调节阴影：透明度、模糊、水平/垂直偏移、扩散、图片圆角、画布留白。
- 3.0x 光栅化导出，透明背景 PNG。
- 默认值即为常见柔和投影，开箱即用。

**滑块参数**

| 参数 | 范围 | 默认 |
|------|------|------|
| 阴影透明度 | 0.05–0.80 | 0.28 |
| 阴影模糊半径 | 0–60 | 24 |
| 阴影水平偏移 | -30–30 | 0 |
| 阴影垂直偏移 | -30–40 | 12 |
| 阴影扩散 | -10–20 | 0 |
| 图片圆角 | 0–40 | 16 |
| 画布留白 | 16–80 | 48 |

## 文字卡片

简单快速的文字海报制作，纯色或渐变背景配上一段文字，导出高分辨率 PNG。

**特性**

- 画布尺寸预设覆盖主流社交场景，也支持自定义宽高。
- 纯色（12 种预设 + 自定义取色器）或渐变（26 种预设）背景自由切换。
- 支持多段文字，每段独立编辑：内容、字号、颜色、透明度、最大宽度、对齐、粗细。
- 文字可在画布上随意拖动摆放。
- 导出可加圆角和阴影。

**画布尺寸预设**

| 预设 | 尺寸 | 适用场景 |
|------|------|----------|
| 1:1 方形 | 1080×1080 | 朋友圈、Instagram |
| 16:9 宽屏 | 1920×1080 | 横版配图 |
| 3:4 小红书 | 1080×1440 | 小红书图文 |
| 9:16 故事 | 1080×1920 | Stories、手机壁纸 |
| 公众号封面 | 900×383 | 公众号头图 |
| 自定义 | 任意（≥100px） | 特殊尺寸 |

**文字属性**

| 属性 | 可选项 |
|------|--------|
| 字号 | 16–160 |
| 透明度 | 0.1–1.0 |
| 最大宽度 | 100–画布宽度 |
| 对齐 | 左 / 中 / 右 |
| 粗细 | 常规 / 加粗 |
| 颜色 | 取色器任意色 |

## 作品集

所有工具导出的结果会统一进入作品集管理。

- **自动登记**：每次导出都会写入本地 SQLite 数据库，记录文件名、格式、大小、时间、所属工具和参数元数据。
- **本地存储**：文件保存在设备文档目录下的 `ImageLab/{工具名}/` 子目录中，命名带时间戳，不会覆盖。
- **预览与分享**：作品集和首页「最近保存」都支持全屏预览和一键分享。
- **删除即清理**：在作品集删除一条记录，会同时删掉对应的物理文件，释放空间。
