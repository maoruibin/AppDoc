# 写下

> 打开就是今天，写下就有过去。

写下（WriteDown）是一本本地优先、一天一页的私人日记：打开就能写，一天多条仍是同一页，日历翻回去，多年后还能被自己的时间击中。它不是带日历的通用笔记，没有收件箱、没有待办、没有红点，只有今天这一页。

## 核心功能

- **打开即写** — 首屏就是今天，底部输入胶囊永远在，冷启动到落笔最多一次点击
- **一天一页** — 一天写多条，按时间落在同一页，数据按日期聚合，不建复杂目录
- **日历回看** — 月视图翻日子，年视图热力图看全年墨迹，一眼看到坚持了多久
- **Markdown 存储** — 正文即 Markdown，本地保存不丢，随时导出带走
- **图片日记** — 给每篇日记配图，图片原色全出血展示
- **本地优先** — 数据先存本机，云同步可选（WebDAV / S3）、手动触发
- **多端一套** — Android 与 macOS 同一套体验，换设备还是熟悉的纸

## 平台

- Android
- macOS
