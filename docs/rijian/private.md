# 隐私政策

更新日期：2026 年 9 月 3 日

北京小茅屋科技有限公司（以下简称"我们"）深知个人信息对您的重要性，《写下》将按照法律法规的要求，采用相应安全保护措施来保护您的个人信息安全可控。

本《隐私政策》主要向您说明我们如何收集和使用您的个人信息、如何存储和保护、如何共享以及您如何管理您的个人信息等内容。请您认真阅读本政策，在确认充分理解并同意后使用我们的产品和服务。

##  1.我们会收集什么信息？

《写下》是一款本地优先的私人日记应用，非常重视用户的隐私保护。你的日记内容（含文字与图片）默认仅存储在你的设备本地，我们不会上传、也不会阅读你的日记。

### 使用数据

- 你的全部日记内容（文字、图片）保存在你的设备本地存储中
- 皮肤、外观等偏好设置存储在本地
- 云同步仅在你**主动配置并手动触发**时进行，且同步目标是你自行选择配置的第三方存储服务（WebDAV / S3 兼容服务），日记数据不经过我们的服务器

### 账号相关信息（可选）

登录咕咚账号时，用于账号注册、登录、权益校验与支付订单处理的必要信息（如账号标识、订单号）会与咕咚账号服务通信。不登录也可完整使用写下的全部核心功能。

### 我们不会收集

- 不会收集你的通讯录、位置信息
- 不会收集你的设备标识符用于追踪
- 不会在后台偷偷上传你的任何数据
- 不会将你的日记内容上传至我们的服务器
- 不登录账号也能完整使用核心功能，无强制注册

##  2.权限申请说明

- 照片/存储权限：仅用于选择图片插入日记，以及导出备份和 Markdown 文件
- 网络权限：仅用于你主动配置的云同步、账号登录与权益校验、检查更新
- 《写下》不会私自访问或修改你存储中的其他无关文件

##  3.数据的存储与安全

- 你的日记数据始终保存在你的设备本地，应用内可随时导出备份（zip）或导出为 Markdown 文件
- 云同步由你自主配置第三方 WebDAV / S3 服务并手动触发，数据传输与存储的安全性取决于你所选服务
- 《写下》不会将你的数据分享给任何第三方

##  4.信息的披露

《写下》不会向他人分享你的日记内容和个人隐私信息，亦不会将其出售、出租或以其他方式分发给他人。法律法规要求披露的除外。

##  5.未成年人信息及使用

《写下》非常重视对未成年人个人信息的保护，我们希望未成年人仅在接受其父母或法定监护人指导、监督并经其同意的前提下使用。

##  6.隐私政策更新

我们可能会不时更新本隐私政策，更新后的政策将在应用内或官方文档站点公布。继续使用即视为您同意更新后的政策。
