# 功能指南

点亮习惯除了 App 内打卡，还提供桌面小组件和提醒通知，帮你「不打开 App 也能坚持」。这篇指南介绍这两个功能的用法和配置。

## 桌面小组件

桌面小组件把「今日待打卡习惯」直接放到桌面上，不用进 App 就能一眼看到今天还有哪些没完成，点一下就跳进对应习惯打卡。

### 能看到什么

- **今日打卡进度** — 顶部一行显示「今日打卡 已完成/总数」（例如「今日打卡 2/5」）
- **待打卡列表** — 列出今天还没打卡的习惯，每条带「待打卡」提示
- **已打卡隐藏** — 打过卡的习惯会自动从列表里消失，列表只留待办，减少干扰
- **归档习惯排除** — 已归档的习惯不会出现在小组件里

### 怎么添加

1. 在手机桌面长按空白处，进入桌面编辑
2. 选择「小组件 / Widget」
3. 找到「点亮」并长按拖到桌面
4. 松手后小组件即显示今日习惯

::: tip 小组件尺寸
小组件最小尺寸 250×110dp，支持横向和纵向拖拽缩放，你可以按桌面布局调整到合适大小。
:::

### 怎么用

| 操作 | 效果 |
|------|------|
| 点列表里的某个习惯 | 跳进 App 对应习惯的打卡页 |
| 点右上角刷新按钮 | 立即重新拉取最新打卡状态 |
| 点标题区 | 打开 App 主页 |
| 打卡 / 修改习惯后 | 下次刷新自动同步，列表随之更新 |

::: tip 刷新时机
小组件每 30 分钟由系统自动刷新一次。手动点刷新按钮可以立刻看到最新状态，打卡后无需等待。
:::

**路径**：相关实现 `app/src/main/java/name/gudong/habit/widget/`（`HabitWidgetProvider` 负责刷新与点击跳转，`HabitWidgetFactory` 负责组装列表数据）。

## 提醒通知

给每个习惯单独设置「每天/指定星期」的打卡提醒，到点收到一条系统通知，点通知直接跳进对应习惯。提醒完全按你的作息来，不是一刀切的固定时间。

### 设置提醒

在习惯的编辑页底部「提醒设置」区域配置：

1. 进入某个习惯 → 编辑
2. 找到「**提醒设置**」一栏，分两项：
   - **提醒时间** — 点开系统时间选择器，选具体时刻（24 小时制，例如 `20:00`），默认显示「未设置」
   - **提醒星期** — 点开多选对话框，勾选周一到周日中要提醒的日子，全选显示「每天」，不选显示「未设置」
3. 保存后提醒立即生效

::: tip 新建习惯默认提醒
新建习惯时默认会带上 `20:00`、每天提醒的预设，你可以保留或清空。把「提醒星期」清空（不勾任何一天）即可关掉这个习惯的提醒。
:::

### 提醒怎么工作

- **按星期精确触发** — 提醒只在你勾选的星期几到点响起，其余日子安静。例如只勾「周一、三、五」，就只在这三天提醒
- **每日自动续期** — 每次提醒触发后会自动调度下一次，不用每天重新设置
- **通知样式** — 高优先级通知，带震动和提示音，标题是习惯名，内容是「该打卡啦，坚持就是胜利 💪」
- **点击跳转** — 点通知直接进入对应习惯，不用从列表里再找

::: tip 通知渠道
提醒走独立的「习惯提醒」通知渠道，你可以在系统设置里单独调整这个渠道的震动、声音、重要级别，不影响 App 的其他通知。
:::

### 重启后自动恢复

手机重启后，点亮会自动重新登记所有习惯的提醒，保证提醒不丢失。

**路径**：相关实现 `app/src/main/java/name/gudong/habit/reminder/`（`ReminderManager` 负责调度与发通知，`ReminderReceiver` 负责到点触发，`BootCompletedReceiver` 负责重启后重建提醒）。

### Android 12+ 精确闹钟

Android 12 及以上系统对「精确闹钟」做了限制，需要授权才能保证提醒准时。

- 有权限时：使用精确闹钟，提醒准点触发
- 无权限时：自动降级为非精确闹钟，提醒可能略有偏差但不会失效

::: tip 提醒不准时？
如果提醒明显提前或延后，到系统「设置 → 应用 → 点亮习惯 → 闹钟和提醒」里，开启「闹钟和提醒」权限，即可恢复精确提醒。
:::
