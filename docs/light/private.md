# 隐私政策

更新日期：2026 年 7 月 30 日

北京小茅屋科技有限公司（以下简称"我们"）深知个人信息对您的重要性，《点亮习惯》将按照法律法规的要求，采用相应安全保护措施来保护您的个人信息安全可控。

本《隐私政策》主要向您说明我们如何收集和使用您的个人信息、如何存储和保护、如何共享以及您如何管理您的个人信息等内容。请您认真阅读本政策，在确认充分理解并同意后使用我们的产品和服务。

##  1.我们会收集什么信息？

《点亮习惯》非常重视用户的隐私保护，仅收集提供服务所必需的最少信息。

### 账号信息

当您注册账号时，我们会收集：
- 邮箱地址：用于账号注册和登录
- 昵称：用于个人展示
- 头像：仅在您主动上传时收集

### 设备信息

为了诊断线上崩溃、定位网络相关问题（如用户反馈无法同步时辅助排查），我们会通过第三方崩溃统计 SDK 采集必要的设备与网络信息：
- 设备信息：包括设备制造商、型号、操作系统版本、设备 MAC 地址、本地 IP 地址等网络接口信息；
- 应用安装信息：第三方 SDK 为进行运行环境检测可能读取设备上已安装应用的列表，用于异常环境识别和防作弊，我们不会主动获取或上传完整的软件安装列表。

上述信息仅用于崩溃诊断、网络问题定位与稳定性统计，不用于识别您的个人身份，亦不会与您的账号信息关联。

### 使用数据

- 习惯打卡记录、打卡日志（含文字和图片）均存储在您的手机本地数据库中
- 积分和愿望数据均存储在本地

### 我们不会收集

- 不会收集您的通讯录、位置信息
- 不会收集您的设备标识符用于追踪
- 不会在后台偷偷上传您的任何数据

### 1.2 第三方 SDK 信息收集

为保障产品功能的正常运行和稳定性监控，我们的应用中集成了以下第三方 SDK。我们在此按监管要求明示各 SDK 的基本信息（SDK 名称、开发者、业务功能、收集信息范围与目的、SDK 隐私政策链接）：

- **腾讯 Bugly SDK**（`com.tencent.bugly`）
  - 开发者：深圳市腾讯计算机系统有限公司
  - 业务功能：崩溃上报与异常监控，帮助我们发现和修复 App 崩溃问题
  - 收集的个人信息范围与目的：可能采集设备信息（设备型号、系统版本、设备 MAC 地址等）与网络信息（IP 地址、网络类型），用于崩溃诊断、网络相关问题定位与稳定性统计
  - SDK 隐私政策链接：https://privacy.qq.com/document/preview/fc7c83338e9c4720b589f6bf4ed4d4ad

- **微软 AppCenter SDK**（`com.microsoft.appcenter`）
  - 开发者：Microsoft Corporation
  - 业务功能：应用分析与崩溃统计，辅助排查线上问题
  - 收集的个人信息范围与目的：可能采集设备信息（设备型号、系统版本、设备 MAC 地址、应用版本等）与网络信息（IP 地址、网络类型），用于崩溃诊断与应用稳定性分析
  - SDK 隐私政策链接：https://learn.microsoft.com/en-us/appcenter/gdpr

##  2.权限申请说明

- 存储权限：仅用于备份和导出功能，除此之外《点亮习惯》不会私自访问或修改您外置存储中的任何文件。
- 网络权限：仅用于账号登录、数据同步（WebDAV）和应用更新检查。

##  3.数据的存储与安全

- 所有习惯打卡数据均保存在手机本地数据库中
- 本地备份数据采用 AES 加密存储
- 云端同步数据通过 HTTPS 加密传输
- 《点亮习惯》不会将您的数据分享给任何第三方

##  4.支付信息安全

- 《点亮习惯》支持通过支付宝购买 PRO 功能
- 支付过程由支付宝 SDK 处理，《点亮习惯》不接触也不存储您的银行卡、支付密码等敏感信息
- 我们仅保留必要的订单信息用于权益核验

##  5.信息的披露

《点亮习惯》不会收集您的个人信息，不会向他人分享这些信息，亦不会将其出售、出租以及其他方式分发给他人。

##  6.账号注销

您可以随时在 App 的「关于」页面点击「账号与注销」进行账号注销操作。注销后：
- 账号信息将被删除
- 本地习惯打卡数据不受影响，仍保留在您的设备上

##  7.未成年人信息及使用

《点亮习惯》非常重视对未成年人个人信息的保护，我们希望未成年人仅在接受其父母或法定监护人指导、监督并经其同意的前提下使用。

##  8.隐私政策更新

我们可能会不时更新本隐私政策，更新后的政策将在应用内或官方文档站点公布。继续使用即视为您同意更新后的政策。
