# 使用指南

## 音频裁剪

精确裁剪音频的指定片段。

1. 在首页点击「音频裁剪」
2. 选择需要裁剪的音频文件
3. 通过波形可视化界面，拖动选择起始和结束位置
4. 预览选中片段，确认无误后导出

## 提取音频

从视频中提取音频内容。

1. 在首页点击「提取音频」
2. 选择视频文件（支持 MP4、MOV 等常见格式）
3. 等待提取完成，音频文件自动保存

## 格式转换

在不同音频格式之间自由转换。

1. 在首页点击「格式转换」
2. 选择源音频文件
3. 选择目标格式（支持 MP3、AAC、WAV、FLAC 等）
4. 点击转换，完成后自动保存

## 变速工具

调整音频的播放速度。

1. 在首页点击「变速工具」
2. 选择音频文件
3. 拖动速度滑块，调整到目标速度
4. 预览效果后导出

## 语音合成

将文字转换为自然语音，使用离线 AI 模型，无需联网。

1. 在首页点击「语音合成」
2. 首次使用需下载离线语音模型（约 50MB），下载完成后即可离线使用
3. 输入需要转换的文字内容
4. 选择音色和语速
5. 点击生成，等待合成完成

## 录音工具

使用设备麦克风录制音频。

1. 在首页点击「录音工具」
2. 点击录音按钮开始录制
3. 录制过程中可暂停
4. 点击停止，录音文件自动保存

## 作品管理

所有导出的音频文件都可以在「作品」页面查看和管理：

- 按时间排列所有已处理的音频
- 点击可查看详情、播放或分享
- 支持导出到其他应用

## 多轨录音室（STUDIO）

声咚咚的旗舰功能，提供专业级多轨音频混音体验：

- 支持 4 轨同时混音
- 可视化时间轴和波形显示
- 每条轨道独立的音量和声像控制
- Solo/Mute 静音控制
- 支持项目保存和加载
- 导出混音后的完整音频
