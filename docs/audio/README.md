# 声咚咚

<img src="https://gudong.s3.bitiful.net/icon/sheng_dong_dong.png" width="13%" alt="">

> 让声音随心所欲，简单易用的全能音频工具箱

声咚咚是一款全能音频工具箱 App，提供音频裁剪、格式转换、视频提取音频、变速、语音合成、录音等常用音频处理功能，所有操作均在本地完成，无需上传云端。

## 核心功能

- **音频裁剪** — 精确裁剪音频片段，支持波形可视化预览
- **提取音频** — 从视频文件中提取音频，支持常见视频格式
- **格式转换** — 在不同音频格式之间自由转换
- **变速工具** — 调整音频播放速度，快慢随心
- **语音合成** — 文字转语音，多种音色可选
- **录音工具** — 高质量录音，支持 44.1kHz 采样率

## 即将推出

- **音频合并** — 无缝拼接多段音频
- **人声分离** — AI 驱动的人声与伴奏分离
- **智能降噪** — 去除环境噪音，还原清晰人声
- **多轨混音** — 专业级多轨音频混音
