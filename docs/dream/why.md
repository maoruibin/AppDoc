# 缘起

很多人都有这样的时刻：躺在床上，脑子里嗡嗡转，怎么也停不下来。数羊没用，听白噪音又单调，听播客反而越听越精神。需要的其实是一段专门为你写、节奏足够慢、能把你慢慢带进睡眠的声音。

梦咚咚想做的就是这件事——给它一个念头，还你一夜好梦。

它的逻辑很简单：你丢进去一个画面、一个心情、一句诗、一段回忆，AI 把它编成一段舒缓的内容，再用自然的人声念给你听。夜晚的念头会变成伴睡的故事，午后的念头会变成一段悠闲的散文，给孩子的话会变成他熟悉的小猫、积木和星空。

我特别在意几件事：

**内容要适配入睡。** 梦咚咚的 prompt 里写死了伴睡基调的五条铁律——严禁强悬念、节奏要慢、情感必须安全、结尾必须渐弱、不要把人唤醒现实。它不讲精彩的故事，而是讲让人沉下来的故事。

**字数要诚实。** AI 经常自报「五分钟」却只写了几百字。梦咚咚按字数硬换时长，写不够就自动重试补足，确认弹窗里把建议时长和实际时长都摆出来。

**它是本地优先的。** 你的画像、梦馆、音频都存在你的设备上，不会偷偷上传。只有造梦那一刻，念头会发给 AI 服务用来生成，仅此而已。

最后，它叫「梦咚咚」，是希望它像睡前一个轻柔的回应——你抛出一个念头，它轻轻「咚」地接住，再变成一段声音陪你入眠。
