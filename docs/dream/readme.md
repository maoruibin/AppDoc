# 梦咚咚

<img src="https://gudong.s3.bitiful.net/icon/dream_icon_1024.png?no-wait=on" width="13%" alt="梦咚咚">

> 给它一个念头，还你一夜好梦。

梦咚咚是一款 AI 伴睡叙事应用——睡前把你的念头、一个画面、一段心情、一句诗丢进去，AI 会把它编成一段舒缓的内容，再用自然的人声朗读出来，伴你慢慢入睡。

不只是伴睡。它也适合午后放松、给孩子讲故事、听一段温柔的散文或科普。AI 会根据你的念头和当前时段，自动判断基调：夜晚倾向伴睡，白天倾向休闲。你只需要一个念头，剩下的交给它。

## 核心功能

- **AI 造梦** — 输入一个念头，AI 自动判断听众、基调、风格和时长，生成专属的睡前内容
- **直接朗读** — 跳过 AI，把你写的诗、日记、一段话直接朗读出来
- **多音色朗读** — 云端 CosyVoice 自然人声，可试听挑选最适合自己的音色
- **给孩子讲故事** — 记下孩子的昵称、年龄、喜好，AI 用孩子熟悉的元素编专属故事
- **梦馆藏档** — 每生成一条内容都自动存档，可反复聆听、重命名、移入回收站恢复
- **定时停止** — 播放页可选 15 / 30 / 45 分钟定时关闭，伴你入睡后自动停下
