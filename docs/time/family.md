# 家庭组

宝宝的成长，爸爸妈妈都想参与记录。家庭组让多个人共同维护同一份成长记录：一个人创建家庭组并配置好云存储，其他人通过邀请码加入，大家就能看到同一套时光。

## 什么是家庭组

家庭组是咚时光提供的「多人共享」能力。它把一个云存储配置和一组人绑定在一起：

- **管理员**（创建者）负责配置云存储、记录和编辑时光、管理成员
- **成员**（通过邀请码加入的人）可以查看所有时光、照片和视频

所有数据存在管理员配置的云存储里，大家通过同步看到同一份内容。

::: tip 适合谁用
- 爸爸妈妈一起记录宝宝成长
- 想让爷爷奶奶也能看到宝宝日常
- 二胎家庭多人共同维护
:::

## 创建家庭组

创建家庭组需要先满足两个条件：

1. **已登录咕咚账号**（在 **设置 → 账号与权益** 登录）
2. **已配置云同步**（在 **设置 → 云同步** 配置好 S3 存储）

::: warning 必须先配好云同步
家庭组会绑定管理员的云存储配置——所有共享数据都存在这里。如果还没配置云同步，创建页面会提示你先去配置。配置方法见 [云同步指南](sync-guide.md)。
:::

### 创建步骤

1. 进入 **设置 → 家庭 → 创建家庭组**
2. 填写：
   - **家庭名称**：如「咚咚的家」
   - **你的称呼**：如「妈妈」（默认是「管理员」）
3. 点击 **创建家庭组**
4. 创建成功后会弹出一个 **6 位邀请码**，把它发给家人

::: tip 记得把邀请码发出去
创建成功弹出的邀请码窗口里就有「复制」按钮，可以直接复制发给家人。家人用这个码就能加入。
:::

## 加入家庭组

家人收到邀请码后，在自己手机的咚时光里加入：

1. 进入 **设置 → 家庭 → 加入家庭组**
2. 依次输入 6 位邀请码
3. 填写自己的称呼（如「爸爸」「奶奶」）
4. 点击 **加入家庭组**

加入成功后，App 会自动用管理员的云存储配置开始同步，把已有的时光全部拉到本地。之后管理员有新记录，同步一下就能看到。

::: tip 加入后立即可见
加入家庭组后 App 会自动触发一次同步，把家庭里所有的时光下载下来。第一次同步可能要花点时间（取决于记录和照片数量），耐心等一会儿。
:::

## 成员角色

家庭组里有两种角色，权限不同：

| 角色 | 称呼 | 能做什么 |
|------|------|---------|
| 管理员（owner） | 创建者 | 记录、编辑、删除时光；添加宝宝；管理成员；管理邀请码；解散家庭组 |
| 成员（member） | 通过邀请码加入 | 查看所有时光、照片、视频；手动同步拉取新数据 |

### 管理员能做的

- 在时间线和回忆页正常记录、编辑、删除时光
- 添加和管理宝宝档案
- 在家庭组管理页面查看邀请码、复制、重新生成
- 查看所有成员
- 解散家庭组

### 成员能做的

- 查看所有家庭共享的时光、照片、视频
- 使用搜索、收藏、回忆统计等查看功能
- 手动点「同步」拉取最新数据

成员 **不能** 做的：

- 新增、编辑、删除时光
- 添加或修改宝宝档案
- 看到或重置邀请码
- 解散家庭组

::: tip 成员想写入怎么办
家庭组的成员权限是「仅查看」。如果家人也想记录时光，可以让他自己配置一份云同步（用同一个云存储的另一个目录，或另开一个 bucket），或者请管理员把数据导出给他单独管理。
:::

## 邀请码

邀请码是加入家庭组的凭证，是一串 **6 位数字**。

- 只有管理员能看到邀请码（在家庭组管理页面）
- 管理员可以 **复制** 邀请码发给家人
- 管理员可以 **重新生成** 邀请码——旧码立即失效，适合邀请码不小心泄露时重置

::: warning 重新生成后旧码失效
重新生成邀请码后，之前发出去的旧码就作废了，家人需要用新码才能加入。已经在家庭组里的成员不受影响。
:::

## 管理家庭组

进入 **设置 → 家庭** （已加入家庭组后这里会显示家庭名称），点击进入家庭组管理页面。

### 管理员视角

- 顶部显示家庭名称、自己的角色（管理员）、成员人数
- **邀请码区**：显示当前邀请码，可复制、可重新生成
- **成员列表**：列出所有成员，显示昵称和角色
- 底部 **解散家庭组** 按钮（红色，不可撤销）

### 成员视角

- 顶部显示家庭名称、自己的角色（成员·仅查看）、成员人数
- **成员列表**：列出所有成员
- 底部 **退出家庭组** 按钮

## 退出与解散

| 操作 | 谁能做 | 影响 |
|------|--------|------|
| 退出家庭组 | 成员 | 退出后无法再查看家庭共享的时光；本地之前下载的数据会清除配置 |
| 解散家庭组 | 管理员 | 所有成员被移除，家庭组消失；此操作不可撤销 |

::: warning 退出/解散前请三思
退出家庭组后，你就看不到家庭里的时光了。如果是管理员解散家庭组，所有成员都会被移除。云端存储里的数据本身不会立刻删除，但大家都不再能通过家庭组访问。
:::

## 隐私说明

- 家庭组的数据存在 **管理员配置的云存储** 里，不是我们的服务器
- 管理员的存储密钥只在管理员手机本地保存；成员加入时会拿到一份云存储配置用于读取数据
- 成员只能查看，不能导出或转发给家庭组以外的人（除非管理员额外分享）
- 创建家庭组、邀请码、成员信息会经过咕咚账号后端做身份验证，但时光内容（照片、文字）不经过我们的服务器

## PRO 权益

家庭组是 **PRO 专属** 功能：

| 项目 | 免费版 | PRO 版 |
|------|--------|--------|
| 创建家庭组 | 不支持 | 支持 |
| 家庭组人数上限 | — | 免费版 2 人，PRO 最多 10 人 |

::: tip 先升级再创建
点击「创建家庭组」时，如果不是 PRO 会弹出升级提示。升级后即可创建并邀请家人。
:::

升级入口在 **设置 → 账号与权益**。
