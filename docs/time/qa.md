# 常见问题

## 数据存在哪里？

所有数据默认存储在你设备的本地，包括文字、图片、视频和音频文件。

- **本地优先**：不开启云同步时，所有数据只存在你的设备上，不会上传到任何服务器。
- **云同步可选**：如果你开启了云同步（PRO 功能），数据会加密后同步到你**自己配置**的 S3 兼容存储（如阿里云 OSS、腾讯云 COS、AWS S3、Bitiful 等），咕咚的服务器不经手你的数据。
- **家庭组可选**：如果你创建了家庭组，被邀请的成员可以看到共享的记录，这些数据会经过咕咚的家庭组服务进行同步。

::: tip 你掌控自己的数据
除非你主动开启云同步或家庭组，否则你的数据永远只存在本地。即使开启云同步，数据也是直连你自己的云存储，咕咚不保存你的笔记内容。
:::

## 换手机数据怎么办？

你可以使用应用内的「数据管理」功能：

1. 在旧手机上：进入「设置」→「数据管理」→「导出数据」
2. 将导出的备份文件传输到新手机
3. 在新手机上：进入「设置」→「数据管理」→「导入数据」

## 支持哪些媒体类型？

咕咚时光支持以下类型的记录：

- **文字**：任意长度的文本
- **图片**：拍照或从相册选择，支持多图
- **视频**：录制或从相册选择
- **音频**：内置录音功能，记录宝宝的声音

## 支持多宝宝吗？

支持。你可以在设置页面添加多个宝宝档案，在不同宝宝的记录间自由切换。

## 支持哪些平台？

目前支持以下平台：

- Android
- iOS
- macOS

## 数据安全吗？

咕咚时光遵循「本地优先」原则，你对自己的数据有完全的控制权：

- **默认纯本地**：不开启云同步时，所有数据只存于设备，不上传任何服务器
- **云同步你自己掌控**：开启云同步后，数据直连你自己的 S3 兼容存储，咕咚服务器不保存笔记内容
- **设备标识仅用于同步**：仅在你开启云同步或家庭组时，会使用设备标识区分多设备，不会用于追踪
- **媒体文件加密**：开启云同步时，图片、视频等媒体文件会加密后传输
- **不包含第三方数据分析 SDK**

## 如何切换时间线布局？

在时间线页面顶部，你可以切换「卡片」和「轨道」两种布局模式，选择你喜欢的浏览方式。
