# 常见问题

## 数据存在哪里？

所有数据都存储在你设备的本地 SQLite 数据库中，包括文字、图片、视频和音频文件。我们不收集也不上传你的任何数据到服务器。

## 换手机数据怎么办？

你可以使用应用内的「数据管理」功能：

1. 在旧手机上：进入「设置」→「数据管理」→「导出数据」
2. 将导出的备份文件传输到新手机
3. 在新手机上：进入「设置」→「数据管理」→「导入数据」

## 支持哪些媒体类型？

咕咚时光支持以下类型的记录：

- **文字**：任意长度的文本
- **图片**：拍照或从相册选择，支持多图
- **视频**：录制或从相册选择
- **音频**：内置录音功能，记录宝宝的声音

## 支持多宝宝吗？

支持。你可以在设置页面添加多个宝宝档案，在不同宝宝的记录间自由切换。

## 支持哪些平台？

目前支持以下平台：

- Android
- iOS
- macOS

## 数据安全吗？

咕咚时光是纯本地应用，所有数据都存储在你的设备上：

- 不上传任何数据到服务器
- 不收集设备唯一标识
- 不包含任何第三方数据分析 SDK
- 图片、视频等媒体文件存储在应用私有目录

## 如何切换时间线布局？

在时间线页面顶部，你可以切换「卡片」和「轨道」两种布局模式，选择你喜欢的浏览方式。
