# 云同步指南

宝宝的成长只有一次，记录丢失会很心疼。云同步把你的时光备份到云端，既能防止换手机、丢手机导致数据丢失，也能让你在多台设备上看到同一份记录。

本篇介绍云同步的作用、支持的云服务、配置方法、同步机制和常见问题。

## 云同步能做什么

| 场景 | 没有云同步 | 有云同步 |
|------|-----------|---------|
| 换手机 | 记录只留在旧手机，要手动导出导入 | 新手机登录后自动拉取全部记录 |
| 多设备（手机 + 平板） | 两边各记各的，互不相通 | 在哪台设备记都会同步过去 |
| 手机丢失/损坏 | 记录可能永久丢失 | 云端有完整备份，换机即恢复 |
| 家庭共享 | 只能一个人记 | 配合家庭组，多人共看甚至共记 |

::: tip 数据始终在你手里
咚时光使用的是「你自己的」云存储账号（不是我们的服务器）。你的照片、视频、文字都存在你配置的对象存储里，密钥也只有你知道。我们既看不到也动不了。
:::

## 支持的云服务

咚时光支持所有 **S3 兼容**的对象存储服务。常见的有以下几种：

| 云服务 | 特点 | Path-Style 开关 |
|--------|------|----------------|
| 阿里云 OSS | 国内速度快，适合国内用户 | 关闭 |
| 腾讯云 COS | 国内速度快，适合国内用户 | 开启 |
| AWS S3 | 国际通用，海外用户首选 | 关闭 |
| 缤纷云 S4 | 国内新晋 S3 服务，性价比高 | 关闭 |
| MinIO | 自建对象存储，技术用户适用 | 开启 |

::: tip 不确定选哪个
国内用户首推 **阿里云 OSS** 或 **腾讯云 COS**，速度快、价格便宜（宝宝记录这类用量通常一年几块钱）。海外用户选 **AWS S3**。
:::

## 如何配置

### 第一步：准备云存储

去对应云服务的控制台创建一个 **Bucket（存储桶）**，并拿到访问密钥。你需要准备这些信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 服务端点（Endpoint） | 存储服务的访问地址 | `oss-cn-hangzhou.aliyuncs.com` |
| Access Key | 访问密钥 ID | `LTAI5t...` |
| Secret Key | 访问密钥秘钥（注意保密） | `xxxxxxxxxxxx` |
| Bucket 名称 | 你创建的存储桶名 | `my-baby-photos` |
| Region | 区域 | `us-east-1`（OSS/COS 可填对应区域） |
| Path-Style 地址 | 地址风格开关 | 见上表 |

::: warning Secret Key 要保密
Secret Key 相当于你的存储密码，请不要截图分享或发到公开场合。咚时光只会把它保存在你的手机本地，不会上传到我们的服务器。
:::

### 第二步：在 App 里配置

1. 打开 **设置 → 云同步**
2. 填入上面准备好的各项信息
3. 点击 **测试连接**，App 会尝试上传并下载一个测试文件，验证配置是否正确
4. 显示「连接成功」后，点击 **启用云同步**（或「保存配置」）

::: tip 先测试再保存
强烈建议先点「测试连接」。连接成功说明配置无误，再保存启用，避免存了一堆数据后发现同步不上去。
:::

### 第三步：自动同步

配置保存后，云同步会自动开启：

- **新增/修改记录后**：1.5 秒内自动触发同步（连续操作会自动合并，不会频繁打扰）
- **打开 App 时**：会拉取远端最新的变更

你也可以在云同步页面点 **立即同步** 手动触发一次。

## 同步状态怎么看

云同步页面顶部有一张状态卡片，会显示当前同步状态：

| 状态 | 含义 |
|------|------|
| 同步中… | 正在上传或下载数据 |
| 已同步 | 上次同步成功，显示上次同步时间 |
| 同步失败 | 出错了，会显示错误原因 |

设置页的「云同步」一行也会用副标题显示状态（未配置 / 同步中 / 已同步 / 同步失败），并配上对应颜色的图标，一眼就能看出健康状况。

## 同步历史

想看每次同步到底传了多少、下了多少？进入 **设置 → 云同步 → 同步历史**（页面右上角齿轮入口）。

每条记录是一次同步会话，包含：

- 同步时间和触发来源（手动 / 自动数据变更）
- 本次上传、下载、删除的条数
- 点击展开可看耗时和错误详情

::: tip 排查同步问题的好帮手
如果觉得「明明记了怎么没同步过去」，先来同步历史看看。这里会诚实记录每次同步做了什么、有没有出错。
:::

## 同步机制

### 上传和下载

每次同步会做这几件事：

1. **下载宝宝档案**：从云端拉取最新的宝宝信息
2. **上传宝宝档案**（管理员）：把本地宝宝信息和头像传到云端
3. **下载时光变更**：拉取云端新增或修改的时光
4. **上传时光变更**（管理员）：把本地新增或修改的时光传到云端
5. **删除检测**：云端已删除的记录，本地也对应清理

### 增量同步

咚时光不是每次都全量传一遍，而是用 ETag（文件指纹）做增量：

- 云端文件没变（ETag 相同）→ 跳过，不重复下载
- 只有变化的时光才传输，速度快、省流量

### 冲突处理（LWW）

如果两台设备同时修改了同一条时光，同步时会用 **LWW（Last Write Wins，最后写入胜出）** 策略：

- 比较 updatedAt 时间，保留较新的版本
- 如果你本地有未同步的修改，而云端也更新了 → **保留本地**，下次上传覆盖云端，绝不丢用户数据
- 时间完全相同 → 视为已同步，跳过

::: tip 不会丢数据
咚时光的冲突策略优先保护用户数据：宁可重复同步，也不会用旧版本覆盖你的新改动。
:::

### 空云端保护

如果云端是空的（比如刚配置好还没传过东西），App **不会**删掉本地的记录。这是为了防止配置错误或意外情况导致本地数据被清空。只有云端明确有数据、且某条记录在云端消失了，本地才会同步删除。

### 媒体文件

图片、视频、音频也会一起同步到云端，按类型分目录存放（images / videos / audios）。下载时会自动放到本地的正确位置，详情页里就能正常播放和查看。

## 家庭组成员的同步

如果你是通过 **邀请码加入** 家庭组的（而不是自己配置的云存储），你的同步行为会有所不同：

- 你 **能** 下载并查看所有家庭共享的时光
- 你 **不能** 上传、修改或删除时光（这些权限只给管理员）
- 云同步页面会显示「家庭组共享」提示，只提供「手动同步」按钮拉取最新数据

详见 [家庭组说明](family.md)。

## 关闭云同步

如果想停止云同步，进入 **设置 → 云同步 → 关闭云同步**。

::: warning 关闭后本地数据不会丢
关闭云同步只会停止自动上传，手机里已经记录的时光都不会被删除。但之后的新记录不会再备份到云端。
:::

## PRO 权益说明

云同步是 **PRO 专属** 功能。免费用户可以打开云同步页面查看介绍，但启用前会提示升级 PRO。

| 项目 | 免费版 | PRO 版 |
|------|--------|--------|
| 云同步 | 不支持 | 支持 |
| 家庭组 | 不支持 | 支持（最多 10 人） |

升级入口在 **设置 → 账号与权益**。PRO 权益接入咕咚账号体系，一次升级，旗下支持的 App 都能通用。
