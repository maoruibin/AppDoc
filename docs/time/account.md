# 账号与登录

## 为什么需要登录

咚时光是一个本地优先的应用，你无需登录即可使用所有核心记录功能。登录账号后可以享受以下额外服务：

- **云端备份**：将宝宝的成长记录安全备份到云端
- **多设备同步**：在手机、平板、电脑间同步查看记录
- **数据恢复**：设备丢失或更换时，可从云端恢复数据

## 登录方式

- 支持邮箱登录

## 账号管理

- 可在设置页面查看和管理账号信息
- 支持修改昵称、头像等个人资料
- 支持注销账号：在"关于"页面底部点击"注销账号"即可发起

### 注销说明

- 注销后，服务端存储的账号数据将被删除
- 本地数据不受影响，仍保留在您的设备上
- 注销操作不可恢复，如需再次使用云端功能需重新注册

## 数据与账号的关系

- **不登录**：所有数据存储在本地设备，功能完整可用
- **登录后**：可选择开启云端备份，本地数据不会丢失

登录是可选的，我们始终尊重你选择只使用本地存储的权利。
