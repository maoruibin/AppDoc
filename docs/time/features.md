# 功能详解

咚时光是一款专为记录宝宝成长而生的 App。所有记录都先保存在你的手机本地，断网也能用；配上云同步，还能在多台设备间同步、和家人共享。

下面把各项功能逐一介绍，按「记录 → 浏览 → 回顾 → 管理」的顺序展开。

## 成长时刻

成长时刻（简称「时光」）是咚时光的基本记录单位，一条时光可以同时包含文字、图片、视频和音频。

### 支持的内容

进入首页后点击右下角的 **+** 按钮即可新建一条时光。一条时光里可以混合以下内容：

| 类型 | 说明 |
|------|------|
| 文字 | 标题 + 正文，记录今天的故事、趣事或「第一次」 |
| 图片 | 拍照或从相册选择，单条最多 9 张 |
| 视频 | 从相册选择视频片段 |
| 音频 | 现场录制宝宝的声音、笑声、咿呀学语 |

::: tip 一条时光可以混合多种内容
不用纠结「照片该单独存还是写进日记」，你可以给一段文字配上几张照片、再来一段录音，把它们存成一条完整的回忆。
:::

### 记录时间

新建时光时，默认记录时间是「现在」。如果你加进了照片，App 会自动用照片的拍摄时间来填，方便你补记前几天的事。你也可以手动改时间——一旦自己改过，再加照片就不会再覆盖你的设置。

### 里程碑

有些时刻值得特别标记，比如第一次微笑、第一次翻身、第一次叫妈妈。新建时光时打开「里程碑」开关并选择类型，这条记录就会出现在回忆页的「里程碑」专区里。

| 里程碑类型 | 图标 |
|-----------|------|
| 第一次微笑 | 😊 |
| 第一次翻身 | 🔄 |
| 第一次坐起 | 🪑 |
| 第一次爬行 | — |
| 第一次站立 | 🧍 |
| 第一次走路 | 🚶 |
| 第一次说话 | 🗣️ |
| 第一颗牙 | — |
| 第一次笑出声 | 😄 |
| 第一次理发 | ✂️ |
| 里程碑（通用） | ⭐ |

## 时间线

所有时光按时间顺序排列在时间线上。时间线顶部提供两种布局，一键切换。

### 卡片布局

以精美卡片形式展示每条记录，文字、图片一目了然，适合慢慢翻看。每张卡片可以直接收藏、点进去看详情。

### 轨道布局

以紧凑的竖向轨道串联所有时刻，一条线串起所有记录，适合快速浏览大量内容、找到某一天。

::: tip 布局偏好会被记住
你选好的布局会自动记住，下次打开还是上次的样式。在时间线页面顶部即可切换。
:::

## 回忆

回忆页是咚时光的「回顾中心」，把零散的记录整理成可以回看的成长故事。打开底部「回忆」标签即可进入。页面顶部还有 **搜索** 和 **收藏** 两个入口。

### 成长概览

页面最上方是一张概览卡片，显示宝宝当前月龄/年龄，以及三项统计：

- 记录总数
- 照片总数
- 录音总数

如果本月有新增记录，卡片底部还会出现「本月 +N 条记录」的小标签，一眼看到自己这个月的勤快程度。

### 去年今日

宝宝出生满一个月后，回忆页会自动出现「去年今天」卡片。它会找出去年同期（前后几天）的时光，让你每年都能重温「一年前的这个时候，宝宝在做什么」。

::: tip 需要积累一段时间
去年今日卡片只在宝宝满月之后才会出现，且需要有一年前的记录可回看。耐心记录，明年的今天就有惊喜。
:::

### 本月回顾

「本月回顾」汇总当前月份的记录情况：本月记录了几条、其中包含多少照片、多少视频、多少录音，并展示最近一张照片作为封面。

### 里程碑

所有被标记为里程碑的时光会横向滚动展示在这里，每张小卡片显示对应的图标、名称和日期。点击任意一张可进入详情。这是回顾宝宝所有「第一次」最直观的方式。

### 月度相册

按月份整理的相册墙，每个月取代表图片拼成缩略图。点击某个月份进入「月度详情页」，可以看到这个月所有的时光记录，按时间线排列，方便按月翻看。

## 搜索

回忆页右上角的 **搜索** 图标进入搜索。输入关键词（如「走路」「生日」「第一次」），App 会在当前宝宝的全部时光里检索标题和正文，列出匹配的记录。

- 边输入边搜索，无需点确认
- 结果显示标题、内容摘要和时间
- 点击结果直接跳转到时光详情

## 收藏

回忆页右上角的 **爱心** 图标进入收藏列表。在时光详情页或卡片上点一下爱心，就能把它收藏起来；收藏的记录会集中出现在这里，方便随时找回那些最珍贵的瞬间。再次点击爱心即可取消收藏。

## 回收站

删除的时光不会立刻消失，而是先进回收站，保留 **30 天**。在此期间你可以随时恢复，误删也不怕。

在 **设置 → 回收站** 里可以：

- **恢复**：把误删的时光还原回时间线
- **彻底删除**：永久删除单条（本地和云端的文件都会清除，不可恢复）
- **清空**：一次性清空整个回收站

::: warning 30 天后自动清理
回收站里的时光保留 30 天后会自动彻底删除，释放空间。如果有想留下的记录，记得在到期前恢复。
:::

## 海报分享

想把某条时光分享给亲友或发到朋友圈？咚时光内置了海报功能，可以把一条时光渲染成一张精美的图片。

### 如何使用

1. 打开任意一条时光详情
2. 点击右上角的 **分享** 图标
3. 进入海报预览页

海报会自动包含这些元素：

- 时光里的第一张照片（如有）
- 宝宝名字 + 当时月龄/年龄
- 时光正文
- 记录日期
- 「咚时光 时光印记」水印

### 保存与分享

海报页面底部提供两个按钮：

| 操作 | 说明 |
|------|------|
| 保存到相册 | 以 3 倍高清导出 PNG，存入相册的「咚时光」相簿 |
| 分享 | 调起系统分享面板，直接发给微信、朋友圈等 |

## 家庭组

家庭组让爸爸妈妈（甚至爷爷奶奶）一起记录和查看同一个宝宝的成长。一个人创建家庭组并配置好云存储，其他人用邀请码加入，就能共享所有时光。

::: tip 详细说明
家庭组的创建、邀请码、成员权限等内容较多，请参考单独的 [家庭组说明](family.md)。
:::

简单来说：

- **管理员（owner）**：创建家庭组的人，可以新增、编辑、删除时光，管理成员和邀请码
- **成员（member）**：通过邀请码加入，可以查看所有时光和照片视频，但不能修改

家庭组功能需要升级 PRO。入口在 **设置 → 家庭**。

## 云同步

云同步把你的记录备份到云端，实现多设备同步和意外防护。咚时光支持所有 S3 兼容的对象存储服务，包括阿里云 OSS、腾讯云 COS、AWS S3、缤纷云、MinIO 等。

::: tip 详细说明
云同步的配置步骤、各服务商参数、同步机制和同步历史查看，请参考单独的 [云同步指南](sync-guide.md)。
:::

云同步的核心能力：

- **多设备同步**：换手机、装在平板上，都能拉到同一份记录
- **自动备份**：每次新增或修改记录后会自动同步，不用手动操作
- **家庭共享**：配合家庭组，多人共享同一份数据
- **LWW 冲突处理**：多端同时修改时，自动保留较新的版本，不丢数据

云同步是 PRO 专属功能。入口在 **设置 → 云同步**。

## 多宝宝档案

一个 App 可以记录多个宝宝的成长，适合二胎/多胎家庭。

- 在 **设置 → 宝宝管理** 添加、编辑宝宝档案
- 每个宝宝有独立的姓名、生日、性别和头像
- 时间线顶部可以快速切换当前查看的宝宝
- 头像支持三种形式：照片、emoji 表情、预设图标

::: tip 家庭组成员的添加权限
通过家庭组加入的成员只能查看，无法添加或编辑宝宝档案。只有管理员（owner）才能添加。
:::

## 深色模式

咚时光提供浅色和深色两套主题。浅色模式是温暖的燕麦色背景，看着舒服；深色模式护眼，适合夜里哄睡后记录。

在 **设置 → 外观 → 深色模式** 里可以选择：

| 选项 | 说明 |
|------|------|
| 跟随系统 | 自动适配手机的深浅色设置 |
| 浅色 | 始终使用温暖的浅色主题 |
| 深色 | 始终使用护眼深色主题 |

## 账号与权益

咚时光的基础功能完全免费：记录时光、时间线浏览、回忆统计、搜索收藏、海报分享、多宝宝档案都可以免费用。

升级 PRO 可解锁以下能力：

| 功能 | 免费版 | PRO 版 |
|------|--------|--------|
| 云同步（多设备/备份） | 不支持 | 支持 |
| 家庭组（共享记录） | 不支持 | 支持（最多 10 人） |
| 家庭组人数 | — | 免费版 2 人，PRO 最多 10 人 |

升级入口在 **设置 → 账号与权益**。PRO 权益接入咕咚账号体系，跨应用通用。
