# 存咚咚

> 把看到的好视频，存进自己的手机里。

存咚咚是一个面向个人留存的媒体存档工具：复制链接，切回 App，选择清晰度，视频或音频就会保存到本机相册。它不做站点广场、不堆功能宫格，只专注把“你能看到的内容”可靠地留下来。

## 核心能力

- **链接识别**：支持抖音、B站、YouTube 等常见分享口令，自动清洗出真实链接
- **清晰度选择**：展示视频档位、纯音频档位与预估体积，大小未知时显示 `--`
- **本地下载**：单流视频直接保存，B站 DASH 双流自动无损合成
- **媒体库**：只展示已落盘文件，支持搜索与平台筛选
- **内建播放器**：支持倍速、进度拖动和续播，异常时自动降级系统播放器
- **本地优先**：文件保存到你的手机，不上传云端媒体库
