# 快速上手

## 1. 复制链接

在抖音、B站、YouTube 等平台找到你想保存的视频，使用系统分享或复制链接。

## 2. 切回存咚咚

App 回到前台后会自动识别剪贴板里的链接。识别成功后，首页会出现当前链接的来源平台。

如果自动识别没有命中，点击首页的「粘贴链接开始下载」，手动粘贴或确认链接。

## 3. 解析并选择格式

点击「一键存档至本地」。解析成功后会弹出清晰度选择：

- **完整视频**：按可用清晰度下载，DASH 平台会自动合成有画有声的 MP4
- **纯音频提取**：下载音频文件，适合课程、访谈和播客内容

预估体积拿不到时显示 `--`，不会猜测。

## 4. 查看任务和媒体库

下载过程显示在首页「正在存档」：

- 排队中：等待下载槽
- 下载中：显示百分比、速度和预计剩余时间
- 已暂停：可继续
- 失败：保留在任务列表，可重试

任务完成后会自动离开任务队列，进入媒体库。媒体库只展示已落盘文件。

## 5. 播放

在首页「最近归档」或媒体库中点击文件进入内建播放器：

- 点按画面可隐藏或显示控制条
- 支持倍速切换
- 拖动进度条调整播放位置
- 再次打开会从上次位置继续播放

如果内建播放器无法处理某个编码，会自动尝试拉起系统播放器。
