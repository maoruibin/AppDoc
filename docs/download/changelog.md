# 更新日志

## 1.2.0
> 更新时间：2026/11

- **新增：相册扫描收录——重装或换机后，把系统相册「下载咚」目录里的视频一键收编回媒体库**
- **新增：数据快照备份——媒体库、合集、播放进度可导出分享，新手机导入即恢复**
- **新增：断点续传——下载中断自动接着下，大文件不再一断作废**
- **新增：失败任务一键复制链接，换个时间再下不用回原 App 重新分享**
- **新增：播放页屏幕常亮，点画面中央即可暂停/继续**
- 优化：底部导航改为居中玻璃胶囊样式，界面更轻盈
- 优化：本次升级为全新包体，需卸载重装；此前下载的视频都还在系统相册「下载咚」目录，「我的 → 备份与收录 → 扫描相册收录」一键找回
- 修复：抖音解析弹层偶发白屏灰板
- 修复：视频刚下载完就加入合集或播放时，合集归属与播放进度可能丢失

## 1.1.3
