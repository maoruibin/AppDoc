# Sparrow MD 更新日志

## 1.9.0
> 更新时间：2026/08

- **新增：关于页接入咕咚账号体系**——应用内检查更新、意见反馈、咕咚的作品集，与咕咚全家桶体验统一
- **优化：突出阅读器定位**——「新建笔记」入口从悬浮按钮移入右上角更多菜单，首页专注于你的阅读列表

## 1.8.0
> 更新时间：2026/08

- **编辑器重设计**——语法工具栏移到键盘正上方（拇指易达），自动保存，编辑/预览一键切换
- 新增「麻雀手记」示例文档，首次打开即可体验表格、代码高亮与流程图渲染
