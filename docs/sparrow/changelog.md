# Sparrow MD 更新日志

## 1.10.0
> 更新时间：2026/09

- **新增：深色模式**——跟随系统切换，夜间读文档、看日志不再刺眼
- **新增：目录大纲**——长文按标题快速跳转，阅读页右上角新增目录入口
- **新增：阅读进度记忆**——重开文件回到上次读到的位置，编辑保存后也留在原处
- **新增：代码高亮**——深浅双配色，日志和代码一眼看清结构（兑现了介绍页的承诺）
- **新增：GBK 编码识别**——微信传来的 Windows 记事本老文档（ANSI/GBK）不再乱码
- 优化：外部打开进阅读页更快，大文件的类型识别与字数统计不再卡顿
- 优化：删除文件后短时间内可一键撤销，防误删
- 修复：文件大小显示不准的问题（中文内容按字符数统计导致偏小）
- 隐私：移除无用的存储权限，现在只保留网络权限（渲染文档内的远程图片）

## 1.9.0
> 更新时间：2026/08

- **新增：关于页接入咕咚账号体系**——应用内检查更新、意见反馈、咕咚的作品集，与咕咚全家桶体验统一
- **优化：突出阅读器定位**——「新建笔记」入口从悬浮按钮移入右上角更多菜单，首页专注于你的阅读列表
- 修复：华为等自研 WebView 内核上打开文件显示源码的问题（随本版一并发布）

## 1.8.1
> 更新时间：2026/08

- **修复：打开文件后正文显示成代码源码**——WebView 对 file:// 的 MIME 判断不可靠，已改用显式 text/html 加载

## 1.8.0
> 更新时间：2026/08

- **修复：热启动打开文件失效**——已在后台时再从微信等入口打开新文件，现在会正确跳转到新内容
- **编辑器重设计**——语法工具栏移到键盘正上方（拇指易达），自动保存，编辑/预览一键切换
- 新增「麻雀手记」示例文档，首次打开即可体验表格、代码高亮与流程图渲染
