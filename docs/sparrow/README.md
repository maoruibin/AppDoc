# Sparrow MD 麻雀

> 手机上的轻量 Markdown 阅读器。免费无广告、无账号，文件只留在你的手机里。

## 它解决什么问题

在微信、文件管理器或其他应用里收到 `.md`、`.txt`、`.log`、`.json` 这些文本文件时，手机往往没有合适的打开方式——要么预览乱码，要么挤成一团。

麻雀只做一件事：**把这些文件读舒服**。

## 怎么用

1. 在微信或文件管理器里点开一个文本文件
2. 选「打开方式」或「分享」
3. 选 **Sparrow MD**

就这样，没有第二步。最近读过的文件会留在首页列表里，随时继续。

## 特性

- **任意文本文件点开即读**：Markdown、TXT、日志、JSON、代码
- **舒适排版**：表格、代码高亮、Mermaid 流程图
- **顺手记**：想到什么写一笔，自动保存
- **本地优先**：免费无广告、无账号，文件只存在你的手机里
