# 功能详解

咕咚订阅是一个简洁实用的 RSS 阅读器，围绕「订阅 → 阅读 → 沉淀 → 备份」四个环节组织功能。所有数据本地存储，可选 WebDAV 云备份。下面逐一介绍各核心功能。

## 订阅源管理

订阅源是咕咚订阅的基础单位，支持添加、分组、修改、退订全流程管理。

**特性**

- 通过粘贴 RSS / Atom 地址添加订阅源，App 自动解析标题、图标和文章列表。
- 支持自定义分组（如「技术」「设计」「朋友」），订阅源可移动到不同分组。
- 每个订阅源可单独编辑属性，包括名称、**自动加载全文** 开关等。
- 支持长按订阅源快速 **标记已读** 或 **取消订阅**。

**订阅源属性**

| 属性 | 说明 |
|------|------|
| 名称 | 显示在侧滑菜单和文章列表的订阅源名 |
| RSS 地址 | 订阅地址，一般以 `.xml` / `.atom` / `/feed` 结尾 |
| 自动加载全文 | 开启后，该源的新文章会自动抓取原文正文 |

::: tip 免费版限制
免费版最多可添加 50 个订阅源（`maxFreeSourceCount`）。PRO 用户无此限制。订阅源数量达到上限时，再添加或通过 OPML 导入会提示升级。
:::

## 文章阅读

阅读页面提供三种内容获取方式，适应不同 RSS 源的抓取情况。

| 方式 | 触发方式 | 说明 |
|------|----------|------|
| 摘要阅读 | 默认 | 直接展示 RSS 提供的摘要内容 |
| 手动加载全文 | 阅读页面**下拉刷新** | 抓取原文网页并提取正文，补全摘要源的内容 |
| 自动加载全文 | 订阅源属性开关 | 新文章自动抓取正文，无需每次手动下拉 |
| 直接打开网页 | 工具栏「打开」/ 阅读设置 | 跳过 RSS 内容，直接打开原文网页 |

**阅读设置（我的 → 阅读设置）**

- **直接打开网页**：开启后点击文章直接打开原始网页，跳过 App 内 RSS 内容展示。
- **自动刷新**：开启后，App 打开时如果距离上次同步超过 30 分钟，会自动开始同步新文章（界面上标注为「1 小时自动刷新」）。

::: tip
双击首页或阅读页面顶部的标题栏，可以快速回到顶部。
:::

## 批注

批注功能让你在阅读时对原文片段写评论，类似读书时在书页边做笔记。

**工作原理**

每条批注由两部分组成，保存在本地数据库（`XNote`）：

| 字段 | 含义 |
|------|------|
| `annotation` | 批注原文，即你在正文中选中并标注的文字 |
| `note` | 你的评论内容 |
| `anchorId` | 关联的文章 ID，用于定位回原文 |

**操作流程**

1. 在阅读页面**长按正文**进入文本选择（由 `SelectableTextHelper` 实现）。
2. 拖动游标选定文字，浮动菜单提供 **复制** 和 **批注** 两个操作。
3. 选择「批注」弹出输入框，顶部展示选中的原文，下方输入评论。
4. 发送后，批注会显示在阅读页面底部的批注列表中。

**批注管理**

- **本文批注**：阅读页面底部按顺序展示当前文章的全部批注。
- **全部批注**：底部导航的「批注」标签页集中查看所有批注，点击可跳回原文，支持复制 / 分享 / 删除。

::: warning 免费版限制
免费版每篇文章最多记录若干条批注（`maxFreeNoteCount`，受版本调整影响，以 App 内提示为准）。PRO 用户批注数量不受限。
:::

## 收藏

收藏用于标记值得反复阅读或稍后读的文章。

| 字段 | 说明 |
|------|------|
| `favorite` | 是否收藏 |
| `favoriteAt` | 收藏时间，用于排序 |

- **收藏/取消**：在阅读页面工具栏点击心形 **收藏** 图标切换收藏状态。
- **查看收藏**：首页顶部分类切换到 **收藏**，按收藏时间倒序展示所有收藏文章。
- 收藏数据保存在本地，配合 WebDAV 备份可跨设备保留。

## OPML 导入导出

OPML（Outline Processor Markup Language）是订阅源列表的通用交换格式，几乎所有 RSS 阅读器都支持。咕咚订阅用它来迁移订阅源。

**支持的操作**

| 操作 | 入口 | 说明 |
|------|------|------|
| 导出 OPML | **我的 → 数据 → 导出 Opml** | 把全部订阅源（含分组）导出为 `RssPlus.opml` 文件，可分享/保存 |
| 导入 OPML | **我的 → 数据 → 导入 Opml** | 从 `.opml` 文件导入订阅源到本机 |

**导出内容**

- OPML 2.0 格式，包含所有订阅源的标题、RSS 地址。
- **保留分组结构**：导出时会按分组嵌套 outline，导入到支持分组的阅读器时能还原分组。
- OPML 只包含订阅源列表，**不包含** 文章正文和批注（那些由下方的数据备份负责）。

::: tip
OPML 适合在不同 RSS 阅读器之间迁移订阅源。如果你要完整备份（含文章和批注），请用「数据导出」或 WebDAV 备份。
:::

**导入规则**

- 解析 OPML 文件中的 outline，自动识别分组（父级 outline 作为分组）。
- 导入完成后会自动开始一次同步，拉取新订阅源的文章。
- 免费版订阅源数量达到上限（50）时会拦截并提示升级 PRO。

## 数据备份与 WebDAV

除了 OPML，咕咚订阅还支持完整的本地数据备份和 WebDAV 云备份。

**完整数据备份（数据导出/导入）**

数据备份导出的 JSON 文件（`RssPlus.json`）包含：

| 内容 | 字段 |
|------|------|
| 订阅源列表 | `mSourceList` |
| 文章内容 | `mContentList` |
| 批注数据 | `mAnnotationList` |
| 应用设置 | `mSpConfig`（含分组、阅读偏好等） |

- **导出**：**我的 → 数据 → 导出数据**，生成 JSON 文件并分享保存。
- **导入**：**我的 → 数据 → 导入数据**，从 JSON 文件恢复，支持按源合并。

**WebDAV 云备份**

把备份文件推送到 WebDAV 云盘（如坚果云），实现跨设备同步和防丢失。详细配置见 [WebDAV 备份教程](lesson-webdav.md)。

| 操作 | 入口 | 说明 |
|------|------|------|
| WebDAV 配置 | **我的 → 数据备份 → WebDAV 配置** | 填写服务器地址、账号、应用密码 |
| 手动备份至云盘 | **我的 → 数据备份 → 备份至云盘** | 上传 OPML 和本地配置到云盘 `RssPlus/` 目录 |
| 自动备份 | **我的 → 数据备份 → 自动备份** | 开关，开启后定期自动备份 |

::: warning PRO 功能
WebDAV 配置、手动备份至云盘、自动备份均为 **PRO 专属功能**。免费用户可使用本地数据导出/导入和 OPML 导入导出。
:::

## 图片分享（PRO）

把文章生成一张长图分享到社交平台，保留订阅源图标、标题和正文，排版美观。

- **入口**：阅读页面工具栏点击 **图片分享**。
- **校验**：调用前会检查 PRO 状态，非 PRO 用户会提示升级。
- **分享**：生成长图后可分享到微信等应用。

::: tip
图片分享是 PRO 功能（`tip_img_pro`），免费用户点击会弹出升级引导。
:::

## 自动刷新

App 内置自动同步机制，避免每次都手动刷新：

- **触发条件**：App 打开时，如果距离上次同步时间超过 30 分钟，自动开始一次同步。
- **同步内容**：拉取所有订阅源的最新文章。
- **开关位置**：**我的 → 阅读设置 → 自动刷新**（界面标注为「1 小时自动刷新」）。

## PRO 权益

咕咚订阅的基础功能免费，以下能力需要升级 PRO：

| 功能 | 免费版 | PRO 版 |
|------|--------|--------|
| 订阅源数量 | 最多 50 个 | 无限制 |
| 文章批注 | 每篇有限条数 | 不受限 |
| WebDAV 配置 / 云备份 | 不支持 | 支持 |
| 自动备份到 WebDAV | 不支持 | 支持 |
| 图片分享（长图） | 不支持 | 支持 |
| 后台自动同步订阅数据 | 不支持 | 支持 |

升级入口在 **我的 → 账号**。
