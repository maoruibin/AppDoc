# WebDAV 云备份教程

咕咚订阅支持把订阅源、文章和批注数据备份到 WebDAV 云盘，实现防丢失和跨设备同步。本文以坚果云为例，手把手教你完成配置。

::: warning PRO 功能
WebDAV 配置、备份至云盘、自动备份都是 **PRO 专属功能**，需在 **我的 → 账号** 升级 PRO 后使用。免费用户可使用 [OPML 导入导出](features.md#opml-导入导出) 或本地数据导出。
:::

## 为什么需要 WebDAV 备份

咕咚订阅是 Local-first 应用，所有订阅源、文章和批注都存在手机本地。这保证了隐私和离线可用，但也意味着换机、卸载或手机丢失会造成数据丢失。

配置 WebDAV 云备份后：

- **防丢失**：订阅源和本地数据自动/手动上传到你的个人云盘，丢了手机也不怕。
- **跨设备迁移**：新手机上登录同一个 WebDAV 账号，恢复备份即可拿到所有订阅源和设置。
- **数据自主**：数据存到你自己的云盘，不经过任何第三方服务器。

备份内容会上传到云盘的 `RssPlus/` 目录下，包含 OPML 订阅源列表和本地配置数据。

## 支持的 WebDAV 服务

只要是实现了 WebDAV 协议的云盘都可以用，常见选择：

| 服务 | 说明 |
|------|------|
| **坚果云** | 国内最稳定、口碑最好，推荐首选，免费额度够日常使用 |
| **Nextcloud** | 自建 NAS / 私有云常用，填服务器地址即可 |
| **群晖 / 威联通等 NAS** | 开启 WebDAV 服务后填入地址 |
| **123 云盘** | 支持 WebDAV，需 VIP |

下面的步骤以坚果云为例，其他云盘流程类似，只是服务器地址和密码获取方式不同。

## 配置坚果云

整个过程分三步：注册坚果云 → 添加应用拿到密码 → 在咕咚订阅里填入配置。

### 第 1 步：注册坚果云

在电脑打开 [https://www.jianguoyun.com](https://www.jianguoyun.com)，或手机安装 **坚果云 App**，注册并登录账号（已有账号可跳过）。

### 第 2 步：添加第三方应用，获取密码

坚果云为每个应用单独发一串「应用密码」，避免暴露主密码。

::: tip 为什么用应用密码
应用密码是访问授权的钥匙，比主密码安全——可随时单独撤销，且只能访问 WebDAV，不影响你正常登录坚果云。
:::

**方式 A：网页操作（推荐）**

1. 登录坚果云网页，**点击右上角昵称 → 账户信息**。
2. 选择 **安全选项**，滑到页面底部「第三方应用管理」。
3. 点击 **添加应用**，输入应用名称，如 `咕咚订阅` 或 `RssPlus`。
4. 点击 **生成密码**，复制这串密码备用。

也可以直接访问 [https://www.jianguoyun.com/#/safety](https://www.jianguoyun.com/#/safety) 直达安全选项页。

**方式 B：坚果云 App 操作**

1. 打开坚果云 App，进入 **设置 → 第三方应用管理**。
2. 点击 **添加应用密码**，输入名称（如 `咕咚订阅`）。
3. 生成后复制密码备用。

此时你需要记下三样信息：

| 信息 | 内容 |
|------|------|
| 服务器地址 | `https://dav.jianguoyun.com/dav/` |
| 账号 | 你的坚果云注册邮箱（**主账号，不是刚才填的应用名**） |
| 应用密码 | 刚才生成的那串密码（**不是坚果云登录密码**） |

### 第 3 步：在咕咚订阅中配置

1. 打开咕咚订阅，进入 **我的 → 数据备份**。
2. 点击 **WebDAV 配置**。
3. 依次填入：
   - **服务器地址**：`https://dav.jianguoyun.com/dav/`（坚果云默认，其他云盘自行修改）
   - **账户名称**：坚果云注册邮箱
   - **三方应用密码**：第 2 步生成的密码
4. 点击右上角 **测试**，验证配置是否成功。

::: warning 常见填错点
- 账户名称填的是**注册邮箱**，不是应用名，也不是你的昵称。
- 密码填的是**应用密码**，不是坚果云登录密码。两者填错都会测试失败。
:::

测试通过后，`WebDAV 配置` 项会显示「已配置」，保存即可。

## 备份与恢复

配置成功后，就可以备份和恢复了。

### 手动备份

在 **我的 → 数据备份** 点击 **备份至云盘**：

- 弹窗会提示「OPML、本地配置文件将会被上传至您的云盘目录 `RssPlus/` 下」。
- 确认后开始上传，会提示「备份可能需要点时间，请稍等...」。
- 完成后可在坚果云的 `RssPlus/` 目录看到备份文件。

### 自动备份

打开 **我的 → 数据备份 → 自动备份** 开关：

- 开启后 App 会定期自动把数据上传到云盘。
- 前提是已经配置好 WebDAV，且为 PRO 用户。

### 恢复数据

在新设备或重装后恢复：

1. 先按上面步骤配置好同一个 WebDAV 账号。
2. 进入 **我的 → 数据备份** 的备份管理页面，会列出云端 `RssPlus/` 目录下的备份文件。
3. 选择需要恢复的备份，点击恢复。
4. App 会把云端文件拉取到本地并导入，订阅源、文章、批注和设置都会还原。

::: tip
恢复是按订阅源合并导入的，已存在的订阅源不会重复添加，所以不用担心覆盖或重复。
:::

## 多设备同步说明

WebDAV 备份本质上是「备份 / 恢复」模型，不是实时双向同步，使用时注意：

- **换机迁移**：旧手机备份一次 → 新手机配置同一 WebDAV → 恢复，即可拿到全部数据。
- **两台设备长期并用**：建议固定一台为主设备，另一台定期从云端恢复，避免两边各自改数据产生冲突。
- **批注和收藏**：备份文件包含批注和收藏数据，恢复时会一并带过去。
- **频率注意**：坚果云免费用户访问频率限制为每 30 分钟不超过 600 次请求，日常备份完全够用。

::: tip 也可以用本地导出
如果你暂时不用 WebDAV，可以用 **我的 → 数据 → 导出数据** 生成 JSON 文件，手动保存到网盘或发给自己；换机时用 **导入数据** 恢复。效果类似，只是需要手动操作。
:::
