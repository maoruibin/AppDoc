# 常见问题

## 阅读相关

### 如何加载全文

在阅读页面下拉刷新，App 会抓取原文网页并提取正文。

### 如何设置自动加载全文

点击订阅源头像，编辑订阅源属性，开启「自动加载全文」。或者在每次手动加载完毕后，会提示你开启自动加载。

### 如何直接打开网页而不是看 RSS 内容

在阅读页面工具栏点击「打开」即可跳转原文网页；或在 **我的 → 阅读设置 → 直接打开网页** 开启，之后点击列表项会直接打开原文网页，跳过 App 内展示。

### 如何快速回到顶部

双击 title 回到顶部，首页与阅读页面均支持。

### 有些图片加载不出来怎么办

部分原文图片做了防盗链，或源站本身图片就缺失，属于网站限制，App 无法绕过。可以点击「打开」跳到原网页查看。

## 订阅源管理

### 如何退订订阅源？

在侧滑菜单中，点击订阅源菜单，选择取消订阅。

::: warning
退订后该源下的本地文章和批注也会一并清理，操作不可恢复。如只是临时不想看，建议用「移动到分组」归档。
:::

### 如何修改订阅源属性（名称、自动加载全文）？

在侧滑菜单点击订阅源头像，或在阅读页面工具栏选择「编辑订阅源」，即可修改名称和「自动加载全文」开关。

### 免费版可以添加多少个订阅源？

免费版最多 50 个订阅源。达到上限后再添加或导入会提示升级 PRO，PRO 不限数量。

### 如何给订阅源分组？

在侧滑菜单点击「添加分组」新建分组，然后长按订阅源选择「移动到分组」即可归类。

### 为什么刷新后说「没有刷新到新信息」？

说明所有订阅源当前都没有新文章。RSS 源更新频率取决于作者发文速度，可以稍后再试，或检查订阅地址是否还有效。

## 批注

### 怎么给文章做批注？

在阅读页面**长按**正文文字，拖动游标选中要标注的内容，在弹出菜单里点「批注」，输入你的评论后发送即可。详见 [使用指南 - 批注文章](guide.md#批注文章)。

### 批注保存在哪里？

批注保存在本机数据库，一条批注包含「选中的原文」和「你的评论」，和对应文章绑定。不会自动上传到任何服务器，但可以通过 [WebDAV 备份](lesson-webdav.md) 或数据导出归档。

### 在哪里查看所有批注？

- 本文批注：阅读页面底部列出当前文章的全部批注。
- 全部批注：底部导航切到「批注」标签页，集中查看所有文章的批注，点击可跳回原文。

### 批注提示超出数量限制？

免费版每篇文章可记录的批注数量有限，超出会提示升级 PRO，PRO 批注数量不受限。

### 怎么把批注同步到笔记平台？

咕咚订阅本身不强制绑定某个笔记平台。你可以在批注列表里长按选择「复制」或「分享」，把批注文字分享到 inBox 笔记、微信、邮件等任意应用；或用 OPML / 数据导出整体归档。

## 收藏

### 怎么收藏文章？

在阅读页面工具栏点心形「收藏」图标即可收藏，再次点击取消。

### 收藏的文章在哪里看？

回到首页，顶部分类切换到「收藏」，按收藏时间倒序展示所有收藏文章。

## OPML 导入导出

### OPML 导入导出在哪里？

进入 **我的 → 数据**，里面有「导出 Opml」和「导入 Opml」两项。

### OPML 包含分组信息吗？

包含。导出的 OPML 是 2.0 格式，会按分组嵌套 outline，导入到支持分组的阅读器（包括咕咚订阅自己）时能还原分组。

### OPML 和「数据导出」有什么区别？

- **OPML**：只包含订阅源列表（含分组），是跨阅读器通用的格式，适合迁移订阅源。
- **数据导出**（JSON）：包含订阅源 + 文章内容 + 批注 + 设置，是完整备份，适合换机 / 防丢失，但只能被咕咚订阅识别。

### 导入 OPML 后多久能看到文章？

导入完成会自动开始一次同步，拉取新订阅源的文章，需要一点时间，耐心等待即可。

## WebDAV 备份

### WebDAV 备份是免费的吗？

不是。WebDAV 配置、备份至云盘、自动备份都是 PRO 功能。免费用户可用 OPML 导入导出和本地数据导出。详见 [WebDAV 备份教程](lesson-webdav.md)。

### 配置 WebDAV 时测试失败怎么办？

常见原因：

- **账号填错**：账户名称应为坚果云**注册邮箱**，不是应用名或昵称。
- **密码填错**：要填坚果云后台生成的**应用密码**，不是登录密码。
- **地址填错**：坚果云地址固定为 `https://dav.jianguoyun.com/dav/`。
- 其他云盘请确认服务器地址正确、WebDAV 服务已开启。

### 备份文件存在云盘哪里？

存在云盘的 `RssPlus/` 目录下，包含 OPML 订阅源文件和本地配置数据。

### 换新手机怎么恢复数据？

新手机装好咕咚订阅 → 用同一个 WebDAV 账号完成配置 → 进入数据备份页面，从云端备份列表选择恢复即可。订阅源、文章、批注、收藏和设置都会还原。

### WebDAV 是实时同步吗？

不是。WebDAV 备份是「备份 / 恢复」模型，可以手动备份或开启自动备份定期上传。两台设备长期并用时，建议固定一台为主设备，另一台定期从云端恢复，避免两边各自改数据产生冲突。

## 其他

### 文章删除后能找回吗？

能。删除的文章会进入侧滑菜单底部的「回收站」，可以在回收站里恢复或彻底删除。
