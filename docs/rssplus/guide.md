# 使用指南

本指南帮你快速上手咕咚订阅，从添加第一个订阅源到批注、收藏、备份，覆盖日常使用的全部流程。

咕咚订阅的所有订阅数据都保存在本地，文章全文由 App 端直接抓取，不需要第三方服务器中转。

## 界面概览

打开 App 后，主要界面分三块：

- **文章列表（首页）**：展示所有订阅源的最新文章。顶部可按 **全部 / 未读 / 收藏** 切换查看。
- **侧滑菜单**：从左侧滑出，列出所有订阅源和分组，底部有 **回收站** 入口，顶部可进入 **添加订阅源 / 添加分组**。
- **阅读页面**：点开任一篇文章进入，顶部工具栏提供批注、收藏、图片分享、复制链接、打开网页、删除等操作。
- **我的（设置）**：右上角进入，包含数据备份（OPML 导入导出、WebDAV）、阅读设置、PRO 权益等。

::: tip
在首页或阅读页面，**双击顶部标题**可以快速回到顶部并刷新。
:::

## 添加订阅源

1. 打开 App，从首页**左上角**点开侧滑菜单。
2. 点击 **添加订阅源**（或在首页空状态时直接点击提示）。
3. 在输入框中粘贴 RSS 订阅地址，例如 `https://example.com/atom.xml`。
4. 点击确认，App 会自动解析订阅源名称和图标。
5. 解析成功后，该源会出现在侧滑菜单中，刷新即可看到最新文章。

::: tip 不知道地址？
先在目标博客首页找「RSS」「订阅」或橙色的广播图标，点开得到的 `.xml` / `.atom` / `/feed` 链接就是订阅地址。也可以直接看 [什么是 RSS](whatrss.html)。
:::

### 分组管理

订阅源多了以后，可以用分组来整理：

- 在侧滑菜单点击 **添加分组**，新建一个分组（如「技术」「设计」）。
- 长按某个订阅源，选择 **移动到分组**，把它归入对应分组。
- 分组支持折叠展开，方便按主题浏览。

## 阅读文章

### 基础阅读

在首页文章列表点击任一标题，进入阅读页面。App 默认展示 RSS 提供的摘要内容。

### 加载全文

部分 RSS 源只返回文章摘要，这时可以通过以下方式获取完整正文：

- **手动下拉刷新**：在阅读页面**向下滑动**触发刷新，App 会抓取原文网页并提取正文（最常用）。
- **自动加载全文**：点开订阅源头像进入 **编辑订阅源**，打开 **自动加载全文** 开关，之后该源的新文章会自动抓取正文。

::: tip
每次手动加载全文成功后，App 也会弹窗提示「是否开启自动加载」，方便你顺手打开。
:::

- **直接打开网页**：如果你更习惯在浏览器里看原文，在阅读页面工具栏点击 **打开**，会跳转打开原始网页。

完整的「直接打开网页」行为也可以全局设置：进入 **我的 → 阅读设置 → 直接打开网页**，开启后点击列表项直接打开原文网页，跳过 RSS 内容展示。

### 快速回到顶部

双击阅读页面顶部的标题栏，即可回到文章顶部。

## 批注文章

批注是咕咚订阅的特色功能，让你像读纸质书一样在文章里划线、写心得。

### 怎么划线批注

1. 在阅读页面，**长按**正文中的某段文字，进入文本选择模式。
2. 拖动两端的游标选中你要标注的内容。
3. 在弹出的浮动菜单中选择：
   - **复制**：把选中文字复制到剪贴板。
   - **批注**：为选中文字写一段评论。
4. 点击「批注」后会弹出输入框，顶部展示你选中的原文（作为批注的锚点），在下方输入你的评论。
5. 点击发送，这条批注会**保存在本地**，并关联到当前文章。

::: tip 批注存在哪
批注保存在本机数据库中，一条批注包含两部分：**原文引用**（你选中的文字）和 **你的评论**（你写的感想）。它和文章绑定，可在阅读页面底部的批注列表里随时回看。
:::

### 查看与删除批注

- **当前文章的批注**：在阅读页面底部会列出本文已有的全部批注，点击可快速定位。
- **全部批注**：在底部导航切换到 **批注** 标签页，可以集中查看所有文章下的批注，点击任一条可跳回原文。长按或点开菜单支持**复制、分享文字、删除**。

::: warning 免费版限制
免费版每篇文章最多可记录若干条批注（受版本调整影响，以 App 内提示为准）。如需无限制批注，可在 **我的 → 账号** 升级 PRO。
:::

### 把批注/文章同步到笔记平台

如果你想把摘录和评论沉淀到自己的笔记系统，可以这样做：

- 在阅读页面或批注列表的菜单中选择 **复制** 或 **分享**，把批注文字分享到 inBox 笔记、微信、邮件等任意支持的应用。
- 使用 [OPML 导出](features.md#opml-导入导出) 或 [WebDAV 备份](lesson-webdav.md)，把包含批注的完整数据导出归档。

## 收藏文章

遇到想反复看或稍后读的文章，可以收藏起来。

- **收藏**：在阅读页面工具栏点击 **收藏** 图标（心形），该文章会被标记为收藏，并记录收藏时间。
- **查看收藏**：回到首页，在顶部分类切换到 **收藏**，即可看到所有收藏过的文章，按收藏时间倒序排列。
- **取消收藏**：再次在阅读页面点击收藏图标即可取消。

收藏和文章都保存在本地，配合 WebDAV 备份可以在换机时保留。

## 标记已读

- **单篇已读**：点开阅读一篇文章即自动标记为已读。
- **整个订阅源标记已读**：在首页文章列表或侧滑菜单中，长按某个订阅源，选择 **标记已读**，确认后该源下所有文章会被标记为已读。
- **全部标记已读**：在侧滑菜单的「全部」分类上操作，可以把所有订阅源的文章一次性标记为已读。

## 文章回收站

删除文章并不会立刻彻底消失，而是先进回收站，方便误删找回。

- **删除文章**：在阅读页面工具栏点击 **删除**，或在文章列表长按选择删除。
- **找回/清理**：打开侧滑菜单，进入底部的 **回收站**，可以查看所有被删除的文章，需要的话可以恢复，或彻底删除。

## 退订 / 修改订阅源

- **修改订阅源**：在侧滑菜单中点击订阅源头像，或在阅读页面工具栏选择 **编辑订阅源**，可修改名称、调整 **自动加载全文** 等属性。
- **退订**：在侧滑菜单中长按订阅源，选择 **取消订阅**，确认后即可退订。

::: warning
退订后该订阅源下的本地文章与批注也会一并清理，操作不可恢复。如只是临时不想看，建议用「移动到分组」归档，而不是退订。
:::
