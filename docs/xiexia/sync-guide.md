# 云同步配置

写下的云同步不经过我们的服务器：日记以一条一个 JSON 文件的形式，同步到**你自己配置的** WebDAV 网盘或 S3 兼容对象存储。日记永远在你的盘上，我们能做的只有帮你把文件搬过去。

> 云同步是 PRO 权益。登录咕咚账号开通 PRO（买断制）后即可配置。

## 同步是怎么工作的

| 项 | 说明 |
|------|------|
| 存什么 | 每条日记一个 JSON（`entries/*.json`），图片在 `assets/images/*` |
| 怎么传 | 手动触发上传 / 下载，不做后台静默同步 |
| 冲突怎么办 | 不同条目互不覆盖；同一条在多端都改过，以修改时间新的一方为准 |
| 怎么省流量 | 内容没变的条目自动跳过；同名同大小的图片不重复上传 |
| 历史可查 | 每次同步的来源、条目数与明细都记在「同步历史」，可回看 |
| 反悔通道 | 可随时清空云配置——只清配置，不动本地任何日记 |

对坚果云这类有流量限制的服务，写下内置了请求节流与限流熔断，同步节奏会自动放缓，不会硬撞限流。

## 配置 WebDAV（以坚果云为例）

坚果云是国内最省心的 WebDAV 网盘，免费额度对日记同步完全够用：

1. 登录[坚果云网页版](https://www.jianguoyun.com)，进入「账户信息 → 安全选项」。
2. 在「第三方应用管理」里点「添加应用」，生成一个**应用密码**——注意这不是你的登录密码。
3. 打开写下，进 **我的 → 云同步**，选择 WebDAV，填入：
   - 服务器地址：`https://dav.jianguoyun.com/dav/`
   - 账号：坚果云登录邮箱
   - 密码：刚生成的应用密码
4. 点「测试连接」，通过后手动触发首次同步即可。

其他带 WebDAV 的网盘同理：填对应的服务器地址、账号、密码就行。

## 配置 S3 兼容对象存储

如果你更熟悉对象存储（阿里云 OSS、腾讯云 COS、Cloudflare R2、七牛云等都兼容 S3 协议）：

1. 在服务商控制台创建一个 Bucket，权限选私有读写。
2. 备好四样东西：**Endpoint**（如 `https://s3.cn-north-1.amazonaws.com.cn`）、**Region**、**Bucket 名称**、**Access Key / Secret Key**。
3. 打开写下，进 **我的 → 云同步**，选择 S3，把四样填进去。
4. 测试连接通过后开始同步。

> 建议专桶专用：给写下一个独立的 Bucket，备份、迁移、管理授权都干净。

## 换设备怎么迁

两种路都通：

- **云同步**：新设备登录同一咕咚账号并开通 PRO，配置同一个网盘 / Bucket，手动触发一次下载，全部日记落到本地。
- **备份文件**：旧设备在「我的 → 数据与备份」导出 zip，新设备导入恢复。三端备份互通，图片都在。

## 安全须知

- 云盘凭据只保存在你的设备本地，用于直连你选择的服务。我们不经手、不存储。
- 内测包与正式包的云端目录相互隔离、数据不互通；长期使用请以正式包为准。
- 「AI Agent 接入」生成的提示词里包含你的云盘凭据——它由本机生成、供你自己的 AI 助手使用，请只发给你信任的助手，不要粘贴到公开场合。
