# 快速上手

本指南帮你快速上手写下，从写下第一句话到多年后翻回今天，几分钟就能用顺。

写下是一本一天一页的私人日记：打开就是今天这一页，写完就落下，不用建文档、不用想标题。所有数据先存在你的设备本地，云同步是可选项。

## 界面概览

打开 App，主界面由这几部分组成：

1. **今天页**：打开 App 看到的就是今天这一页，这一天的所有日记按时间从上到下排成一页。
2. **顶部日期栏**：显示今天或你正在翻看的日期，展开是七日周条，可以左右翻到附近的日子，也可以呼出月历跳到任意一天。
3. **底部输入胶囊**：屏幕底部常驻的输入区，点开就能写，写完发送落页。它永远在那里，想写就写。
4. **日历页**：按月翻看每一天，也可以切到年视图，用热力图看一年的墨迹密度。
5. **我的页**：账号、外观皮肤、云同步、备份导出、回收站和关于，都收在这里。

手机端没有底部 Tab 栏，主页就是今天这一页，专注写字本身；桌面端（macOS）左侧是导航栏，最小窗口 760×560，适合放在手边随时记。

## 基础操作

### 第一步：写下第一条日记

1. 打开 App，点底部的输入胶囊展开输入区。
2. 直接开始写。支持 Markdown 语法：`**加粗**`、`# 标题`、`- 列表` 都会被渲染成排版好的正文。
3. 写完点发送，这一条就落在今天这一页上，键盘自动收起。

一天可以写多条——早上写一句、中午贴张图、睡前补一段，它们都落在同一页里，按时间排好。

### 第二步：给日记配图

1. 在输入区点图片按钮，从相册选一张图。
2. 图片以原色全出血展示，不套卡片，保持纸面干净。
3. 免费版每条日记可配 3 张图，PRO 解锁 9 张。

### 第三步：翻回过去

- **翻附近的日子**：顶部周条左右滑动，或点日期呼出月历。
- **按月回看**：进日历页，月视图里每天的格子显示当天的记录密度，有记录的日子一眼可辨。
- **看全年**：日历页切到年视图，热力图用墨色深浅展示一年 365 天的记录密度，坚持了多久一目了然。
- **找特定内容**：搜索页输入关键词搜全部日记，按月分组展示，也可以当「全部笔记」翻着看。

### 第四步：修改与删除

- 点任意一条日记可以进入编辑，改正文、改日期都行。
- 删除的日记先进回收站，可以从回收站恢复或彻底删除，手滑也不怕。

## 进阶操作

### 云同步（可选）

写下本地优先，不配置任何云也能完整使用。想多设备备份的话：

1. 进 **我的 → 云同步**，选 WebDAV 或 S3 兼容服务（坚果云、各类网盘、对象存储都行）。
2. 填好地址和凭据，手动触发上传或下载。
3. 同步协议是一条日记一个 JSON 文件（`entries/*.json` + `assets/images/*`），不同条目互不覆盖，安全可控。

### 备份与导出

- **导出备份**：一键导出完整数据的 zip 备份，换机、归档都用得上。
- **导出 Markdown**：把日记导出为 Markdown 文件，数据永远是你的，随时带走。
- **导入数据**：从备份 zip 恢复全部数据。

### 皮肤外观

进 **我的 → 外观** 换皮肤。写下有八套皮肤：免费的宣纸、暖米、樱粉、竹青，PRO 的黛青、紫檀、鎏金、天青。照片和图片永远原色，不参与换肤。
