# 更新日志

> 以下均为内测版本记录，正式公开发布将从 1.0 开始。

**0.2.4**

> 更新时间：2026/09/05

- 新增：主页折叠式日历——七日周条常驻，点一下原地展开成整月月历，翻近处、跳任意一天都在顶上完成
- 修复：坚果云同步大面积失败的问题（请求节流 + 限流熔断）
- 优化：回收站「彻底删除」增加进行中提示，网络慢时不再像没反应

**0.2.3**

> 更新时间：2026/09/05

- 新增：随机回顾「翻一条」——随机翻一条过去的日记，或翻「那年今日」
- 新增：同步历史——每次同步的触发来源、条目数与明细都可回看
- 改版：日历页——月视图点某天当页直看当天记录；月份/年份网格选择卡，跳月跳年一步到位；年视图新增年度统计卡（写作天数、记录次数、累计字数、最长连续）
- 新增：Agent 接入——按你的云同步配置生成 AI 助手一键接入提示词
- 优化：同步增量加速，内容没变的条目不再重复下载

**0.2.2**

> 更新时间：2026/09/04

- 新增：全新应用图标——宣纸白底 + 朱砂方点，图标即一页纸
- 优化：登录链路加固

**0.2.1**

> 更新时间：2026/09/03

- 新增：条目分享卡片——把一条日记做成一张图，保存或分享出去
- 改版：编辑器保存——顶栏保存按钮 + 「更多」动作面板（复制 / 分享卡片 / 分享 / 删除）
- 修复：登录、注册页崩溃

**0.2.0**

> 更新时间：2026/09/03

- Android 内测首发（蒲公英）：一天一页今天页、Markdown 写作、图片日记、日历月/年视图、搜索与全部笔记、回收站、云同步（WebDAV / S3）、备份导出与导入、八套皮肤、咕咚账号与 PRO 买断、macOS 桌面端

**0.1.0**
