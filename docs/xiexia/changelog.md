# 更新日志

> 以下均为内测版本记录，正式公开发布将从 1.0 开始。

**0.6.8**

> 更新时间：2026/10/13

- 新增：编辑器光标跟随——长文写作时页面自动滚到光标所在行，落笔处永远可见；打开旧长文回看不受影响
- 修复：正式签名包登录报「网络异常，请重试」的问题（构建优化误伤了登录链路）

**0.6.7**

> 更新时间：2026/10/11

- 新增：全部笔记筛选条——按年份、按是否带图筛选，翻多年的时间书更快找到想看的段落
- 新增：照片先行——拍过的好照片常驻提示「写进那一天」，照片日记落笔更快
- 优化：数据与备份加固——备份导出更稳，大备份不再中断；恢复改为合并语义，不覆盖你已有的日记

**0.6.6**

> 更新时间：2026/09/29

- 新增：我的页「洞察」卡——累计字数、最常落笔的时段、当前连续天数，坚持有了回声
- 优化：沉浸输入——更大的书写画布、启动即抬键盘、键盘上方直接换行，长文一气呵成
- 优化：安装包大幅瘦身（约 16MB → 3.3MB），下载与启动更轻快
- 优化：图片解码更省内存，多图翻页更流畅
- 修复：手机端与桌面端行为不一致的问题（PRO 权益提示等）
