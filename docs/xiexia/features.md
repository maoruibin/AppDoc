# 功能详解

写下把"一天一页地写"这件事做扎实。下面按功能模块详细介绍每个能力。

## 今天页与写作

### 打开即写

打开 App 首屏就是今天这一页，底部输入胶囊常驻：

- **输入胶囊**：收起时只占底部一条，点开即进入输入，写完发送落页并收起键盘。
- **多条同页**：一天写多少条都行，每条按写入时间落在今天这一页，页面顶部是这一天的时间轴。
- **自动滚动**：保存新记录后页面自动滚到最新一条，永远停在刚写完的地方。

### 折叠式日历

主页顶部常驻一条七日周条，左右滑动就能翻到附近的日子；点一下周条，原地展开成整月月历，翻月跳年去任意一天，再点收起。翻近处、跳远处都在页面顶上完成，不打断写作。

### Markdown

正文以 Markdown 存储和渲染：

| 能力 | 说明 |
|------|------|
| 标题 / 加粗 / 斜体 | 常用 Markdown 语法直接渲染 |
| 列表 / 引用 | 排版即写即得 |
| 编辑辅助 | 输入区提供 Markdown 快捷操作，不用记语法也能排 |
| 原文保留 | 存的是 Markdown 原文，导出即为标准 Markdown 文件 |

### 图片附件

- 每条日记可配图，图片按宽高比自适应高度，竖图不被裁切，原色全出血展示。
- 配额：免费版每条日记可配 3 张，PRO 可配 9 张。

## 日历与回看

### 月视图

- 按月翻看，日期格子显示当天记录情况，有记录的日子一眼可辨。
- 点某一天，那天的记录直接列在页面下方，不用跳走，点记录即可编辑。
- 点标题呼出月份网格，切月一步到位；再点年份钻入年份网格，一路能翻回 1990 年。
- 往年今日这样翻：翻到那年那月，点开那一天。

### 年视图热力图

- 一年 365 天缩成一面热力墙（按星期对齐），颜色深浅代表当天记录量。
- 顶部年度统计卡：写作天数、记录次数、累计字数、最长连续，坚持了多久一目了然。

### 搜索与全部笔记

- 搜索页按关键词搜全部日记正文。
- 空着不搜时就是「全部笔记」：按月吸顶分组、分页加载，可以当一本时间书从头翻到尾。

### 随机回顾「翻一条」

- 搜索页点「随机翻一条」，从你的日记里随机翻出一条重读；也可以按「那年今日」翻，看看去年的今天你在写什么。
- 翻卡样式与分享卡片一致：纸页、墨夜免费，照片、信笺 PRO。

### 回收站

- 删除的日记先进回收站（软删除），支持恢复和彻底删除。
- 误删不慌，重要内容有后悔药。

## 分享卡片

长按一条日记（或在编辑器点「更多」），可以把它做成一张可分享的图片卡片：

- 四套模板：**纸页、墨夜**免费，**照片、信笺** PRO，颜色跟随当前皮肤。
- 多图只取一张，长文自动渐隐，卡片永远干净。
- 导出即得图片，保存或分享到任何地方。

## 数据与同步

### 本地存储

- 所有日记存在设备本地的数据库中，断网、无账号都完整可用。
- 一条日记一条记录，按日期聚合为一天一页。

### 云同步（可选，手动触发）

| 项 | 说明 |
|------|------|
| 后端类型 | WebDAV 或 S3 兼容服务（坚果云、网盘、对象存储均可） |
| 同步协议 | 一条日记一个 JSON：`entries/*.json` + `assets/images/*` |
| 覆盖策略 | 不同条目互不覆盖，多端修改以条目为单位合并 |
| 触发方式 | 手动触发上传 / 下载，不做后台静默同步 |
| 配置清除 | 可随时清空云配置，只清配置、不动本地日记 |
| 同步历史 | 每次同步记录触发来源、后端、条目数与明细，可在云同步页回看 |

### 备份与导出

| 操作 | 说明 |
|------|------|
| 导出备份 | 完整数据的 zip 备份，归档、换机两相宜 |
| 导出 Markdown | 日记导出为 Markdown 文件，数据随时带走 |
| 导入数据 | 从备份 zip 一键恢复 |

## 外观皮肤

写下内置八套皮肤，颜色随皮肤整体切换，照片永远原色：

| 档位 | 皮肤 |
|------|------|
| 免费 | 宣纸 · 暖米 · 樱粉 · 竹青 |
| PRO | 黛青 · 紫檀 · 鎏金 · 天青 |

入口在 **我的 → 外观**，选中即生效。

## 账号与 PRO

写下不登录也能完整写日记，数据始终在本地。登录咕咚账号可以开通 PRO：

- **PRO 皮肤**：黛青、紫檀、鎏金、天青四套高级皮肤。
- **更多图片配额**：单条日记配图从 3 张提升到 9 张。
- **PRO 分享卡片**：照片、信笺两套高级卡片模板（纸页、墨夜免费）。
- **买断制**：一次买断，早鸟价 ¥25（划线价 ¥39），不是订阅。
- 咕咚账号 PRO 权益跨咕咚系应用通用。

## 多端

- **Android**：手机主界面为今天页 + 底部输入胶囊，无底部 Tab。
- **macOS**：桌面端左侧导航栏，最小窗口 760×560，适合挂着随手记。
- 双端一套代码一套交互，数据可通过云同步互通。
