# 为什么做写下

## 一本想写就写的日记本

市面上的笔记软件越来越强：文件夹、标签、双链、数据库、AI。可对"今天过得怎么样"这种记录来说，它们太重了——打开先选分类，写完还要整理，热闹得像在办公。而多数日记 App 又在另一头：模板、打卡、社区分享，写个日记像在发朋友圈。

我一直想要的是一本安静的纸：打开是今天，写完就放下，翻回去是从前。一天一页，多年之后，被某一天的自己击中。找不到合适的，就自己写一个。

这就是写下——名字即动作，「打开就是今天，写下就有过去」。

## 几条不变的原则

- **本地优先**。日记是私密的东西，数据先存在你的设备上，永远可以完整导出带走。云同步是可选项，同步到你自己的网盘（WebDAV / S3），不是我们的服务器。

- **打开即写**。首屏就是今天，输入胶囊常驻底部，冷启动到落笔最多一次点击。没有收件箱、没有待办、没有红点，只有今天这一页。

- **一天一页**。一天写多条，仍是同一页。不建目录、不打标签，日期就是唯一的结构——就像纸日记本，翻页即翻日子。

- **正文不锁**。文字记录和本地数据永远免费，Markdown 存储，导出即走。付费只围绕皮肤、图片配额这些锦上添花的部分，不锁日记本身。

## 把"一天一页"做扎实

写下不追求功能堆砌，只想把日记的主路径做顺：

- **写得快**：Markdown 输入带排版辅助，发送落页，键盘自动收起，新记录自动滚到眼前。
- **翻得动**：月历翻日子、年视图热力图看全年墨迹、搜索按月翻全部笔记——多年日记不是负担，是一本越读越厚的时间书。
- **丢不了**：本地数据库 + zip 备份 + Markdown 导出 + 可选云同步（一条日记一个 JSON，条目之间互不覆盖），四重保险。
- **耐看**：八套皮肤（宣纸、暖米、樱粉、竹青……）随心情换，照片永远原色，纸面干净。

## 一点点私心

作为个人开发者，写下也是做给自己的工具——我已经在自己的手机和 Mac 上用它记每一天了。Android 和 macOS 一套代码，桌面端挂在手边，想写的时候它就在。

如果你也想持续记录生活，但不想要重型笔记软件，希望写下合你心意。有想法或建议，欢迎到 [联系我们](contact.md) 找我。
