# 常见问题

## 基础问题

### 写下是什么？

写下是一本本地优先、一天一页的私人日记。打开就是今天这一页，写完落下；日历可以翻回任意一天，年视图热力图能看到一年的记录密度。它不是通用笔记，没有收件箱、待办和红点。

### 写下是免费的吗？

核心的写作能力完全免费：写日记、一天多条、日历回看、搜索、本地导出、WebDAV 同步、单设备图片日记都不收费。登录咕咚账号可开通 PRO（买断制），解锁四套 PRO 皮肤、每条日记 9 张图片配额，以及照片、信笺两套高级分享卡片模板。不登录、不付费也能完整使用。

### 写下支持哪些平台？

Android 和 macOS，双端一套体验，数据可通过云同步互通。

### 「一天一页」是什么意思？

一天之内写多少条都行，它们按时间落在同一页上，就像一本纸质日记的一天。写下不做文件夹、标签和目录，日期就是唯一的组织方式——翻回去的方式和你翻一本日记本一模一样。

## 写作相关

### 支持 Markdown 吗？

支持。正文以 Markdown 存储和渲染，输入区有快捷排版操作，不熟语法也能用；导出得到的就是标准 Markdown 文件。

### 日记可以修改日期吗？

可以。编辑一条日记时可以改它的日期，改完会落到新的那一天页里。

### 删除的日记还能找回吗？

能。删除先进回收站，可随时恢复或彻底删除。

## 数据与隐私

### 我的日记存在哪里？

默认全部存在你的设备本地（本地数据库），不登录、不配置云也能完整使用。数据首先是你的。

### 云同步会上传我的日记吗？

只有你主动配置并手动触发时才会。写下支持 WebDAV / S3 兼容服务，同步到的是**你自己配置的网盘或对象存储**，不是写下的服务器。一条日记一个 JSON 文件，不同条目互不覆盖。

### 怎么把数据带走？

- **导出备份**：完整数据 zip，可导回恢复。
- **导出 Markdown**：正文导出为 Markdown 文件。
换机、搬家、永久归档都可以，数据不锁在 App 里。

### 清除应用数据会怎样？

本地的日记、图片附件、设置会被清空。所以建议定期导出备份，或配置云同步。若配置过云同步，清数据后重新下载即可恢复。

### 写下需要哪些权限？

| 权限 | 用途 |
|------|------|
| 照片/存储 | 选择图片插入日记、导出文件 |
| 网络 | 仅用于你主动配置的云同步、账号登录与权益校验 |
