# 语音笔记

从 2.4.7 版本开始，inBox 接入了完整的**语音输入流水线**，让你可以放下键盘，用嘴巴把想法说出来，由 AI 帮你整理成一篇干净的笔记。

这也是 inBox 在「降低输入压力」这件事上的一次升级——之前我们用聊天式输入框让大家记录更轻松，现在如果你连打字都觉得打断思路，可以直接开口说。


## 什么是语音笔记

简单说，就是你按住录音、把话说完，inBox 会自动帮你做三件事：

1. **录音** —— 把你的声音录下来，原音会作为附件保留在笔记里
2. **转写** —— 把语音转成文字（语音转文字）
3. **润色** —— 由 AI（DeepSeek）把口语化的文字整理成适合阅读的笔记

最终你得到的是一篇**文字笔记 + 一段原音**。文字可以直接读、可以搜索；原音点开就能回放，方便你核对。

## 怎么录音

### 入口在哪

在 inBox 主页底部的输入框**右侧**，有一个麦克风按钮。

这个按钮很「懂事」：

- 当输入框是**空的**时，它会显示出来
- 一旦你**开始打字**，它会自动让位、悄悄淡出，不挡你写字
- 输入框清空后，它又会回来

这样既不抢打字的位置，又能在你想开口时随手就到。

> 详情页写**批注**时，同样可以语音输入，下面会专门讲。

### 录音步骤

1. 点击输入框右侧的麦克风按钮，会弹出录音面板，**打开即自动开始录音**，不用再点一次
2. 对着手机说话即可，面板上会实时显示录音时长、剩余时间和声音波形
3. 录音过程中可以**暂停 / 继续**（临时有事打断又不想结束录音时很方便）
4. 说完后点「停止」，进入待确认状态
5. 点「完成」确认保存，inBox 开始转写和润色；点「不保存」则丢弃这段录音

::: tip 几个小细节
- **打开即录音**：点开麦克风后不用再操作，直接开口就行。
- **最短 3 秒**：录音不足 3 秒会被提示「录音时间太短」，请重新录制，避免白白浪费额度。
- **单次时长上限**：单次最长可达 5 分钟，达到上限会自动结束录音。
- **录音时屏幕常亮**：录音过程中手机不会自动锁屏，不用担心录到一半屏幕黑掉。
- **想反悔也没关系**：停止后只要还没点「完成」，都可以选「不保存」丢弃重来。
:::

## 转写和润色是什么

录音保存后，inBox 会跑一段处理流水线，中间你会看到状态提示依次变化：

- **正在准备音频** —— 处理你的录音文件（统一转成 16kHz，识别更准）
- **正在转成文字** —— 把语音识别成文字，也就是「转写」
- **正在润色表达** —— 由 AI 把口语整理成更适合阅读的笔记，也就是「润色」

两者的区别：

| 环节 | 做的事 | 举个例子 |
| --- | --- | --- |
| **转写** | 语音 → 文字，忠于你说了什么 | 「呃那个我觉得吧，这个功能真的挺好用的，特别方便」 |
| **润色** | 把口语整理成可读笔记 | 去掉口头禅、断句分段、修正错别字，但**不改变原意、不替你扩写** |

润色的原则是：**清理口语、修正表达、自动分段，但保留你的第一人称、原始语气和真实意图**，不会瞎编、不会强行升华。

> 如果转写完发现没识别到有效语音（比如太安静、音量太小），inBox 会提示「没有识别到有效语音」，不会扣你额度让你白等。

### 关于 AI 配置

- 润色默认使用 DeepSeek，配置由 inBox 远程下发，开箱即用。
- 如果你**在设置里配置了自己的 AI**（支持 OpenAI / 智谱 / 通义等兼容端点），润色会**优先用你自己的配置**，原样使用你的 host / apikey / model。
- 你还可以填一段「个人记忆」（设置里的偏好描述），润色时会作为参考，让整理出来的文字更贴近你的表达风格。

::: tip 润色失败怎么办
润色这一步偶尔可能失败（比如网络波动）。这时 inBox 会**自动回退到转写原文**——也就是说，哪怕 AI 没接上，你依然能得到一份「语音转文字」的结果，文字不会丢。之后你可以单独重试润色（见下文）。
:::

## 语音卡片操作

录音保存后，笔记里会出现一张**语音卡片**，左边是播放器、可拖动播放进度，右边是你整理后的文字。

### 播放原话

点卡片上的播放按钮可以回放原音，**支持拖动进度条**直接跳到你关心的位置，方便核对 AI 整理得对不对。

### 查看原话

语音卡片上有一个「🎙️ 原话」入口，点开后可以展开看到**转写阶段的原始文字**（也就是 AI 润色之前的那一版）。

什么时候用得上：

- 觉得 AI 整理后丢了某些细节，想看原话
- 想对比一下「原话」和「整理后的版本」
- 想把原话**复制**出来用

::: tip 只有保留过原话的卡片才能查看
「查看原话」只对那些保留过转写原文的笔记可用（比如刚录完还在本机的笔记）。如果你看不到原话入口，说明这条笔记没有可展示的原始转写文本。
:::

### 按状态精确重试

语音处理可能因为网络、服务波动等原因失败。inBox 会根据失败的具体环节，给你**对应的重试入口**，而不是粗暴地从头重来：

| 卡片状态 | 含义 | 重试时会发生什么 |
| --- | --- | --- |
| 转写失败 | 语音转文字这一步出错了 | 重新转写 + 润色整段录音 |
| 润色失败 | 转写成功、但 AI 整理失败了 | **只重新跑润色**，不重复转写，省时省额度 |
| 整理已中断 | 处理中途被打断（比如 App 退到后台） | 重新转写 + 润色 |

::: tip 润色失败重试很省额度
润色失败时，转写其实已经成功了，文字已经存下来。这时候点重试，inBox 只会重新调用 AI 做润色，**不会再扣一次转写的额度**，更快也更省。
:::

点重试时 inBox 会提示「将消耗一次语音额度」（按具体失败环节说明），确认后就会重新处理。

### 其他操作

- **复制**：可以把整理好的文字（或原话）复制到剪贴板
- **重新整理**：对已转写的文字重新跑一次 AI 润色

## 语音批注（详情页）

在笔记**详情页**，给一条笔记写**批注**时，同样可以用语音。

用法和主页录音一样：详情页输入框右侧也有麦克风按钮（空输入框时显示），点开录音 → 说完 → AI 整理 → 插入到批注里。

这样你给一条笔记补充想法时，不用打字，开口就行，批注会带着整理好的文字 + 原音一起保存。

## 常见问题

### 转写不准怎么办

语音转文字的准确率受**环境噪音、说话清晰度、麦克风质量**影响。建议：

- 尽量在安静环境下、靠近手机说话
- 吐字清晰，语速适中
- 原音会保留在卡片上，遇到不准的地方可以回放核对
- 转写不准但原话没问题的部分，可以查看「原话」并复制出来手动修正

另外，inBox 这次把录音采样率提到了 **16kHz**（匹配语音识别推荐参数），相比之前识别率有明显提升。

### 免费额度用完了怎么办

语音转文字会消耗服务端资源，所以有额度限制：

- **免费用户**：有滚动周期内的次数 + 时长上限

额度用完时，inBox 会提示「语音额度已用完」或「额度不足」。额度会在滚动窗口内逐步恢复。

::: tip 额度会逐步恢复
免费额度不是一刀切重置，而是在滚动周期内**逐步恢复**——早点录的会先释放出来，不用一直等到一个固定时间点。
:::

### 需要联网吗

需要。转写和润色都依赖云端服务：

- 转写走语音识别服务
- 润色走 DeepSeek（或你自己配置的 AI）

录音本身是在本地完成的，但如果网络不通，处理会失败。好消息是：即使处理失败，**录音文件也会保留**在笔记里，等网络恢复后可以重试。

### 为什么我看不到录音按钮

录音按钮（输入框右侧的麦克风）需要满足：

- 当前在**主页**或**详情页**
- 输入框处于**非全屏**状态
- 输入框**是空的**（一旦打字就会自动隐藏，给键盘让位）

清空输入框后，按钮会重新出现。如果在详情页还是看不到，确认一下是否进入了全屏编辑模式。

### 处理到一半退到后台会怎样

如果录音正在处理时你切到了后台、或者处理被中途打断，这条笔记的状态会变成「整理已中断」。回到 inBox 后，在语音卡片上点重试即可继续处理，不会丢录音。

## 后续

语音笔记的目标是让「记录」这件事再轻一点——当你走在路上、灵感来了不想停下来打字，开口说一句，剩下的交给 inBox。后续会继续优化识别准确率、润色质量和额度体验。
