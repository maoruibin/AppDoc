# inBox 笔记可以用来做什么

inBox 是一款主打「打开就写」的碎片化记录应用。下面是一些典型用法，每一条都链接到对应的详细文档。

## 记录

- **灵感速记**：打开就写，三五分钟记下一个想法，见[快速上手](guide.md)
- **用语音开口说**：不方便打字时直接说，见[快速上手 · 用语音开口说](guide.md)
- **图文混排**：文字中间可以插入图片，见[图文排版](markdown.md)
- **AI 配合**：与 AI 模型组合的记录玩法，见 [Kimi 相关](ai_kimi.md)、[DeepSeek 相关](deepseek.md)、[Agent 说明](agent.md)
- **微信里记**：绑定后从公众号直接记笔记，见[微信记笔记](wechat_note.md)

## 整理

- **标签管理**：给笔记分类打标，见[标签使用](tag.md)
- **笔记间关联**：相关内容互相链接，见[快速上手 · 笔记间关联](guide.md)
- **热力图回顾**：看着记录天数一点点填满，见[热力图](heatmap.md)

## 同步与备份

- **云端备份**：支持 S3 / WebDAV 等多种方案，见[数据备份](data_backup.md)、[WebDAV 配置](data_webdav.md)、[S3 配置教程](lesson-web-s3.md)
- **多端数据推送**：手机写完推到云端，见[数据推送](data_push.md)
- **本地备份还原**：不依赖任何云服务，见[本地数据备份还原](data_recovery.md)

## 导出与迁移

- **导出 Obsidian**：见[导出 Obsidian](export_obsidian.md)
- **导出思源笔记**：见[导出思源笔记](export_siyuan.md)
- **从其他平台迁入**：见[导入教程](lesson-import.md)

## 数据存在哪

默认保存在本地；云同步走你自己的存储桶（S3/OSS），数据主权完全在自己手里，见[数据存储指南](data_storage_guide.md)。
