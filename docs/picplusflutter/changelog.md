# 更新日志（Flutter 重写版）

> 咕咚云图 Flutter 跨平台重写实验版，包名与原生版相同（name.gudong.pic / appid 1001），蒲公英落地页共用 picplus-android。原生版日志见 [picplus/changelog.md](../picplus/changelog.md)。

## 4.10.4
> 更新时间：2026/11

- **新增：半屏快选短路径上传**——打开 App 自动弹出最近照片即点即传，选完图自动开始上传并复制链接（两个行为都可在设置中关闭）
- **新增：「我的」页全新改版**——上传统计（累计上传 / 本周上传 / 已接图床）、账号、PRO 权益与活动中心集中呈现
- 新增：设置移入「我的」页右上角独立页面，「关于」入口直达、版本号常驻
- 新增：应用内更新支持直接下载并安装 APK，不再跳转外部浏览器
- 优化：上传进度统一展示在上传按钮上，不再单独占一块区域
- 优化：全部弹层统一交互规范：去除拖拽把手，右上角与底部统一关闭入口，样式更干净
- 优化：设置页排版轻量化，条目更紧凑精致

## 4.10.2
> 更新时间：2026/10

- 新增：上传前检测重复图片，同一图床已上传过的图片会弹「重复上传提示」，可跳过重复、仍然上传或重命名后再传
- 新增：腾讯云 COS / 阿里云 OSS 地域支持自由输入，Endpoint 随地域自动生成
- 修复：普通 / 高清画质压缩后图片四周出现黑边的问题，小于设定尺寸的图片不再被放大
- 修复：升级用户的历史上传不再占用 PRO 图床试用额度，删除图库记录也不会返还额度

## 4.10.1
> 更新时间：2026/10

- **修复：从旧版迁移的阿里云 OSS、腾讯 COS 图床无法上传**——旧版迁移数据缺少接入地址（Endpoint），现按地域自动补齐，升级后即恢复，无需重新配置图床
- 新增：关于页「推荐给朋友」入口，一键把咕咚云图分享给朋友

## 4.10.0
> 更新时间：2026/10
> 界面信息架构改版：底导精简为两页，图库升级为图文列表

- **新增：图库记录详情操作盘**——点开记录从底部弹出，快速复制链接、收藏、删除
- 优化：底导精简为「上传/我的」两页，图库改从上传页「查看全部」进入
- 优化：图库列表全新图文条目样式，缩略图本地优先加载，更快更省流量
- 修复：应用内更新提示条不再遮挡底部导航栏
- 修复：图库部分缩略图不显示的问题
- 修复：从原生咕咚云图迁移后默认图床可能不生效的问题

## 4.9.0
> 更新时间：2026/10

- **新增：Telegraph 图床（telegra.ph）**——免配置免费上传，镜像/CF/官方三线路自动回退
- 说明：Telegraph 国内直连不稳定（官方被墙、镜像有人机验证），建议开启代理后使用

## 4.8.1
> 更新时间：2026/10

- **修复：升级后图库缩略图无法显示的问题**——图片加载切换到内嵌 Cronet 网络栈，不再被 Cloudflare 指纹风控拦截
- 修复：覆盖安装时 S3/七牛/又拍云的按日期分目录设置丢失
- 优化：图片加载失败记录到日志，便于排查反馈

## 4.8.0
> 更新时间：2026/10
> Flutter 重写版首个内测包，从原生 4.7.5 覆盖安装数据自动迁移

- **新增：从链接上传**——粘贴图片链接，下载后转存到自己的图床（支持无后缀 CDN 直链）
- **新增：上传入口改版**——首页 [相册][更多方式] 两按钮，更多方式收拢剪贴板导入与链接上传
- 新增：相册选择器升级，多选与内嵌拍照更快更稳
- 新增：视频上传（PRO，对象存储图床直传，自动封面）
- 新增：图库批量筛选删除、上传记录导出导入
- 新增：导出运行日志（我的页），方便反馈排查
- 新增：删除闭环，本地与远端一起删
- 优化：压缩移入后台线程，大图不再卡顿
- 优化：上传完成结果面板，逐张复制链接
- 优化：R8 体积优化，内嵌 Cronet 网络栈（防 Cloudflare 指纹拦截）
- 修复：覆盖安装原生版时 versionCode 校验不通过的问题
