# 快速上手

随机相册是一款「随机策展」的本机相册：打开就是一墙随机照片，旧照片主动出来见你，看到废片顺手删掉。这篇指南带你走完从授权到日常使用的全部主线流程。

## 安装与授权

1. 从[下载页](/download)获取安装包并安装
2. 首次打开会请求**照片和视频权限**——随机相册需要读取本机相册才能工作，你的照片只在本机处理，不会上传
3. Android 14 及以上如果只授权了「部分照片访问」，建议选择「允许全部」，否则随机池会少很多照片

## 界面概览

打开 App，底部导航分四个主区域：

| 入口 | 作用 |
|------|------|
| **首页** | 随机卡片墙，每次打开随机换一批照片；往下滑还有「那年今天」 |
| **视频** | 纵向全屏随机视频流，像刷短视频一样刷自己拍的视频 |
| **统计** | 重逢了多少照片、清理腾出多少空间、浏览热力图 |
| **我** | 账号与 PRO、主题外观、浏览偏好、收藏入口 |

## 日常玩法：随机 → 浏览 → 处理

### 第 1 步：打开就是随机卡片墙

首页会从你的全部照片里洗牌出 6–12 张卡片，大小不一、带随机旋转角度，像散落在桌上的实体照片。不喜欢这一批？**下拉刷新换一批**。

卡片墙每天跨天自动换新批，冷启动也很快——上次浏览的卡片墙会即刻呈现。

### 第 2 步：点开照片，横滑浏览

点击任意卡片进入全屏浏览：

- **左右横滑**：在随机队列里连续切换
- **双击 / 双指**：放大缩小，下滑关闭
- **长按照片**：顺着拍摄时间翻看这张照片前后的照片
- **点日期标签**：打开「这一天」网格，纵览当天所有照片
- 左下角有**随页记忆条**，显示拍摄时间，比如「2021年8月 · 5 年前」

### 第 3 步：随手处理

浏览时底部有两个主按钮，长按照片/视频还可以唤出更多操作：

| 操作 | 说明 |
|------|------|
| **收藏** | 收进收藏列表，还可顺手归入分组（免费 3 组，PRO 无限） |
| **删除** | 弹出系统确认后彻底删除，直接作用于系统相册 |
| **不再出现**（长按） | 不删照片，但让它别再出现——可选这一张 / 整个相册 / 这一天 |
| **分享 / 详情** | 在「更多」面板里 |

::: tip 不想看到截图和杂图？
随机源会自动跳过截图、下载、缓存目录里的杂图，也可以在「我 → 浏览偏好」里自己调整。
:::

## 刷自己的短视频

切到「视频」页，纵向全屏分页，内容全部来自你本机拍的视频：

- 滑到哪播到哪，离屏自动暂停
- 单击暂停，长按删除
- 支持声音开关与倍速播放

## 那年今天

首页往下滑，如果往年今天有照片，就能看到「那年今天」：按年份重温前几年同一天的照片。PRO 用户还可以开启每日早 9 点的「那年今天」提醒通知。

## 顺手清理

看到废片随手删。统计页会记录你的成果：重新发现了多少张照片、与记忆重逢了多少天、顺手清理腾出了多少空间，还有清理热力图和照片数量趋势。
