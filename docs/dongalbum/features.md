# 功能详解

随机相册不是第二个时间线相册，而是一座「只属于你的随机记忆放映厅」：打开即惊喜，滑动即浏览，不喜欢就删。下面按模块详细介绍每个能力。

## 随机卡片墙（首页）

每次打开 App，从全部媒体中洗牌出 6–12 张卡片：

- 卡片大小不一、随机旋转 -10°～10°，像散落的实体照片
- 从图片主色提取环境光，每张卡片有独立的舞台感
- 下拉刷新换一批；跨天自动换新批
- 冷启动极速呈现——上次浏览的卡片墙会被记住

::: tip 卡片数量
免费最多 12 张，PRO 最多 20 张，在「我 → 设置」里调整。
:::

## 图片详情：沉浸式横向浏览

- 全屏边到边，左右横滑切换随机队列
- 双击放大、拖拽缩放、下滑关闭
- **长按**顺着拍摄时间翻看前后的照片（前后照片条可收起与居中）
- 点日期标签打开「这一天」网格，纵览当天全部照片，支持全屏浏览
- 左下角随页记忆条显示「2021年8月 · 5 年前」式的拍摄时间
- 浏览页双按钮布局可选：微信式底部横排 / 抖音式右侧竖排（外观设置里切换）

## 随机策略

在「我 → 设置」里选择随机的方式：

| 策略 | 说明 | 可用性 |
|------|------|--------|
| 纯随机 | Fisher–Yates 洗牌，单次会话不重复 | 免费 |
| 时光盲盒 | 随机抽一个日期，看那天的照片 | 免费 |
| 记忆增强 | 优先最近少看过的、收藏过的 | PRO |
| 清理模式 | 优先展示截图、连拍等可清理项 | PRO |

时光盲盒还支持限定年份范围（全部年份 / 近 3 年 / 近 5 年 / 只看 5 年前），范围限定为 PRO 权益。

## 那年今天

- 图片页顶部入口，往年的今天有照片时出现
- 按年份分组重温旧照，点日期可纵览当天
- PRO 可开启**每日早 9 点提醒通知**，点击通知直达那年今天页

## 视频流：私人随机放映

- 纵向全屏分页，像刷短视频一样刷自己拍的视频
- 可见页自动播放，离屏暂停，预加载相邻页，翻页顺滑
- 单击暂停，长按删除
- 支持声音开关与倍速；播放时保持屏幕常亮
- 左下角记忆条显示拍摄时间与时长

## 排除控制权：「不再出现」

不想删，但也不想再看到？长按照片/视频：

- **不再出现这一张**：单张照片退出随机池
- **不再出现这个相册**：整个相册退出随机池
- **不再出现这一天**：某一天的全部照片退出随机池

被排除的内容随时可以在「我 → 浏览偏好」里恢复——单张排除支持缩略图网格点击放回。

另外随机源会**智能过滤**截图、下载、缓存目录和杂图，过滤规则同样可在浏览设置中调整。

## 收藏与分组

- 浏览时一键收藏，收藏列表在统计页和「我」页进入，图片视频统一浏览
- 收藏时可顺手归入**分组**整理（抖音式归组）：免费 3 个分组，PRO 无限

## 顺手清理与统计

- 删除直接调用系统相册完成（Android 11+ 走系统删除确认，不绕开）
- 删除成功有轻触觉反馈和粒子消散动画
- 统计页记录：已重新发现多少张照片、与记忆重逢的日子、顺手清理腾出的空间
- **清理热力图**：每天清理的空间一目了然，点击格子可看当天详情
- **照片趋势**：照片数量 / 体积的变化曲线

免费可见最近 7 天，PRO 解锁完整 28 天热力图 + 30 天趋势。

## 批量清理（PRO）

多选候选网格，对可清理项批量执行「不再出现 / 收藏 / 删除」，大扫除一次搞定。

## 桌面小组件

- **随机一张**（2x2）：桌面直达随机照片
- **那年今天**（4x2）：重温往年今天
- PRO 可定制来源相册、刷新频率，并解锁 4x4 大组件

## 主题外观

- 深色画廊风为默认，支持画廊深色 / 浅色 / 跟随系统
- PRO 解锁**纯黑主题**（OLED 省电）
- Material 3 动态取色 + 当前图片环境光
- 支持减弱动态效果
