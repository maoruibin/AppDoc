# 随机相册

> 只属于你的随机记忆放映厅

随机相册（Random Album）是一款本地优先的照片回忆应用。内容全部来自本机相册，本地处理、不联网、不上传。

核心玩法是随机策展：打开即惊喜，滑动即浏览，不喜欢就彻底删除。

## 核心功能

- **随机卡片墙** — 每次打开从全部媒体中洗牌出 6-12 张卡片，随机大小与旋转角度，像散落的实体照片
- **前后照片时间浏览** — 长按照片即可顺着拍摄时间翻看前后
- **「这一天」概览** — 点日期标签网格纵览当天照片，可全屏浏览
- **图片墙** — 艺术化瀑布流，不同高度错位排布，滚动背景视差
- **排除控制权** — 长按照片/视频可选择「不再出现这一张、这个相册或这一天」，随时在浏览设置中恢复
- **桌面小组件** — 卡片墙直达

## 隐私与数据

- 照片与视频全部来自本机相册，仅在本地读取与展示，不上传任何服务器
- 无账号、无广告，删除操作直接调用系统相册完成
- 详见 [隐私政策](/dongalbum/private)
