# 为什么做随机相册

手机里的照片越来越多，但你有多久没翻过它们了？

时间线相册的默认逻辑是「整理」：建相册、打标签、按时间往回翻。可对大多数人来说，整理永远不会发生——照片躺在那里，从几千张涨到几万张，除了偶尔翻到 top，它们再也没被看见。

随机相册的反其道而行：**不整理，让照片自己冒出来。**

每次打开，它从你的相册里随机洗出一墙照片——可能是三年前某个下午的猫，可能是上个月随手拍的天空。卡片散落着、微微倾斜着，像一张真实的桌面。你不带着目的地来，是照片来找你。

看到喜欢的，收藏起来；看到废片，顺手删掉。删的时候系统相册直接确认，绝不绕开。统计页会告诉你：你已经重新发现了多少张照片，与记忆重逢了多少天，顺手清理腾出了多少空间。

三个原则贯穿始终：

- **本机处理**：照片不上传、不联网，媒体全部留在你的手机里
- **随机策展**：不给你整理负担，惊喜本身就是产品
- **顺手清理**：看到废片随手删，让相册越用越轻

照片不该只躺在时间线里，它应该偶尔自己冒出来见你。

这就是随机相册。
