# 更新日志

## 1.1.0 · 2026/08

- **新增：多人速记**——一段速记识别出几个人就出几张卡，逐个确认后批量保存
- **新增：同名合并**——速记遇到已有同名人脉，可选择合并更新（只补空缺字段）或另建新卡
- **新增：关系链**——介绍人自动关联到具体人脉卡，详情页点击可跳转
- **修复：AI 整理不可用**——引擎切换为智谱 GLM（默认免费档 glm-4-flash）

## 1.0.0 · 2026-08-15

- 首个版本上线
- 人脉卡片：姓名/单位/职务/标签/关系链/生日/备注
- AI 速记：说一句话，自动整理成人脉卡片
- 关系温度：热/温/凉，凉了的排最前
- 今日提醒：生日与沉睡人脉
- 互动时间线：见过面、打过电话，随手记一笔
- 数据保存在本机，不上传服务器
