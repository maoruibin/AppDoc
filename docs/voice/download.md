# 下载安装

## Android 下载

录音咚目前支持 Android 8.0 及以上系统。

### 直接下载

点击下方链接下载最新版本 APK：

[下载录音咚](https://gudong.s3.bitiful.net/voice/apk/gudong-voice-release.apk)

### 安装说明

1. 点击上方链接下载 APK 文件
2. 如果浏览器提示安全警告，请选择"仍要下载"
3. 下载完成后，点击安装
4. 如果系统提示"未知来源应用"，请在设置中允许安装来自此来源的应用
5. 安装完成后即可使用

## 系统要求

| 项目 | 要求 |
|------|------|
| 系统版本 | Android 8.0 (API 26) 及以上 |
| 存储空间 | 约 20 MB（不含录音文件） |
| 必要权限 | 麦克风、存储 |
