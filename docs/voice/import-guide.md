# 自动同步系统录音指南

inVoice 语记支持自动检测并导入系统自带的通话录音或其他录音 App 的文件。由于 Android 系统的隐私保护机制（分区存储），我们需要您手动“关联”一次对应的录音文件夹。

## 为什么需要手动关联？
在 Android 11 及更高版本中，应用无法直接读取系统录音目录。通过“添加文件夹”并授权，您可以赋予 inVoice 访问特定目录的”通行证”，从而实现：
- **自动检测**：每次打开 App 自动寻找新录音。
- **一键导入**：无需在文件管理器中反复查找。

---

## 常见手机录音路径

请根据您的手机品牌，在点击“添加文件夹”后定位到以下目录：

### 1. 小米 (MIUI / HyperOS)
- **路径**：`内部存储 / MIUI / sound_recorder / call_rec`
- **说明**：此目录存放所有的通话录音文件。

### 2. 华为 (HarmonyOS / EMUI)
- **路径**：`内部存储 / Sounds / CallRecord`
- **说明**：部分机型可能在 `Recordings / Call`。

### 3. OPPO / vivo (ColorOS / OriginOS)
- **路径**：`内部存储 / Music / Recordings / Call Recordings`
- **说明**：OPPO 机型通常将录音存放在音乐目录下的次级文件夹。

---

## 操作步骤
1. 进入 inVoice 的 **设置** -> 点击右上角 **导入**。
2. 点击页面下方的 **添加文件夹**。
3. 在弹出的系统文件选择器中，按照上述路径找到对应的文件夹。
4. 点击底部的 **使用此文件夹** 并选择 **允许**。
5. 关联成功后，点击 **立即刷新**，您的录音就会出现在列表中。

---

> **提示**：关联后，inVoice 只会读取音频文件，不会修改或删除您的原始录音。
