# 快速上手

本指南将帮助你快速了解并开始使用录音咚。

## 界面概览

Voice 的主界面分为以下几个区域：

1. **项目选择**：顶部可以切换不同的录音项目/文件夹
2. **录音列表**：中间展示当前项目下的所有录音
3. **录音按钮**：底部醒目的录音按钮，一键开始
4. **导航栏**：底部导航切换首页、搜索、设置等页面

## 基础操作

### 开始录音

1. 打开应用，点击底部的 **录音按钮**（红色圆形按钮）
2. 如果开启了「录音前选择项目」，会先弹出项目选择，选择目标文件夹
3. 录音开始后，可以点击 **暂停** 按钮暂时中断
4. 录音过程中可以点击 **书签按钮** 添加时间标记，方便后续定位
5. 点击 **停止按钮** 完成录音
6. 录音文件会自动保存到当前项目中

### 播放录音

1. 在录音列表中，点击任意一条录音进入播放页面
2. 播放页面提供以下控制：
   - **播放/暂停**：控制播放状态
   - **进度条**：拖动跳转到指定位置
   - **变速播放**：调整播放速度
   - **书签列表**：快速跳转到标记的时间点
   - **A-B 循环**：选择片段反复播放

### 管理录音

1. 在录音列表中可以看到所有录音，按时间排列
2. 点击录音可以进入播放页面
3. 长按录音可以进行删除操作
4. 通过顶部的 **项目选择** 可以切换不同的文件夹，分类管理录音

## 进阶操作

### AI 转写

1. 免费版和订阅版用户：开箱即用，无需额外配置
2. 永久版用户：需要自行配置语音转写和 AI 引擎密钥，详见 [永久版高级配置指南](nls-guide.md)
3. 录音结束后会自动进行转写，也可以在播放页面手动触发
4. 转写完成后可以查看文字内容，并进行 AI 润色

### 数据备份

1. 进入 **设置 > 数据管理**
2. 可以手动创建备份
3. 也可以开启 **自动备份**（充电 + WiFi 时自动执行）
4. 支持导出 ZIP 文件，方便迁移到新设备

### 快捷录音

- **桌面小组件**：长按桌面添加 Voice 小组件，一键开始录音
- **快捷设置磁贴**：下拉通知栏，添加 Voice 磁贴，无需打开应用即可录音
