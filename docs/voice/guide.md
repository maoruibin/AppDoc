# 快速上手

inVoice 语记把「**说出口 → AI 整理 → 一键分发**」串成一条完整的创作流水线。这篇指南带你走完从录第一段灵感、到把它变成可发布内容的全部主线流程。

## 界面概览

打开 App，底部导航分三个主区域：

| 入口 | 作用 |
|------|------|
| **灵感** | 所有录音按时间排列，点进去查看转写、润色、分发 |
| **分身** | 管理你的创作分身（AI 助手），每个分身一套独立的写作风格 |
| **设置** | 账号、AI 引擎、发布配置、数据备份等 |

顶部还有搜索入口，随时回找历史灵感。

## 快速上手：录音 → 转写 → 润色

这是最高频的一条主线，三步把一段口述变成可读的文字。

### 第 1 步：开始录音

1. 在「灵感」页点击底部的**录音按钮**（红色圆形）
2. 如果你开启了「记录前选择分身」，会先弹出分身选择，选本次灵感归哪个分身（不选也行，会归到「未分类」）
3. 录音开始后，可以点**暂停**临时中断、点**书签按钮**给关键时间点打标记
4. 说完后点**停止按钮**完成录音

::: tip 极速录音
想要更快？在「设置 → 录音启动偏好」里开启「开屏直录」，App 一打开就开始录。或者用桌面小组件 / 通知栏磁贴，连 App 都不用进。
:::

### 第 2 步：AI 自动转写

录音结束后，inVoice 会自动调用 AI 把语音转成文字。转写在后台进行，你也可以在灵感详情页手动触发「重新转写」。

- 短录音会走**实时转写**，几乎录完即出
- 长录音或实时通道失败时，自动走**文件转写**兜底

转写完成后，文字会显示在灵感详情页，AI 还会顺手给你起好标题。

### 第 3 步：AI 润色

转写好的文字还是「口语原稿」，需要润色成可发布的内容：

1. 在灵感详情页切到**润色**标签
2. 选择润色格式（如果当前分身设了默认格式会自动用）：
   - **文章稿**：段落成文，可直接发公众号
   - **逐字稿**：去掉口语词，保留原意的干净稿
   - **要点提取**：提炼成要点清单
3. 等待 AI 处理，完成后在「原始稿 / 润色稿」之间自由切换

::: tip 润色取决于分身
同一段录音，润色结果完全取决于当前分身的人设。「会议秘书」分身会给你会议纪要，「小红书爆款」分身会给你带 Emoji 的种草文案。所以**先选对分身，再润色**。
:::

## 使用创作分身

创作分身是 inVoice 的灵魂。搞懂分身，你的语音才算真正进入「可发布」状态。

### 选一个分身开始

1. 进入底部「**分身**」页
2. 第一次使用会弹出「开启你的创作分身」引导，看完 5 秒倒计时后开始创建
3. 点**新建分身**，从 8 个内置模板里挑一个最像你场景的（会议秘书、读书笔记本、小红书爆款、情绪微日记……）
4. 模板已经预填好「秘书人设」和「专属记忆」，你可以直接用，或改成自己的信息

### 分身的三件套

每个分身有三个关键配置，决定了它怎么帮你整理内容：

| 配置 | 写什么 | 举例 |
|------|--------|------|
| **AI 秘书人设** | 你要它扮演什么角色、按什么风格和格式输出 | 「你是会议纪要秘书，输出待办 + 决策清单」 |
| **专属背景记忆** | 你的人和事、专有名词、团队代号 | 「团队代号 Voice，咕咚负责开发」 |
| **默认输出格式** | 录音完成后默认用什么格式润色 | 文章稿 / 逐字稿 / 要点提取 |

::: tip 为什么要填「专属记忆」
不填的话，AI 会把你的项目代号拼错、把同事名字听错、把行业术语改错。填上之后，AI 整理时便会「心领神会」，准确率明显提升。
:::

### 分身如何影响转写和润色

录音绑定了哪个分身，转写和润色就按那个分身的人设来执行：

- 录音前在分身页选好目标分身，或开启「记录前选择分身」每次都问一句
- 录音完成后，润色自动套用该分身的人设和默认格式
- 详情页顶部的「分身画像」卡片可以展开，随时查看或编辑当前分身配置

### 让分身越用越懂你

每条录音润色完成后，AI 会自动分析是否需要给分身「升级」：

- 发现新的专有名词、新项目 → 建议追加到「专属背景记忆」
- 发现你新的风格偏好 → 建议更新「秘书人设」

弹出建议卡片后，**你确认了才会写入分身**，不会偷偷改你的配置。多用几次，分身就会越来越懂你。

## 分发内容

整理好的内容，通过详情页右上角的**分发中心**送出去——一个 2×3 宫格面板，把内容送到你想去的地方。

### 发到微信公众号草稿箱

把润色好的文章直接同步到公众号草稿箱，不用复制粘贴：

1. 先去「设置 → 发布配置 → 微信公众号」填入 AppID 和 AppSecret（公众号后台「设置与开发 → 基本配置」获取）
2. 在灵感详情页打开分发中心
3. 选「**公众号文章**」（纯文字草稿）或「**公众号图文**」（带封面图的图文草稿）
4. 等待同步完成，去公众号后台草稿箱就能看到

::: tip 图文需要封面
选「公众号图文」时，如果还没生成封面，App 会先问你是否生成；生成封面并上传后才会同步成图文。
:::

### 发到 inBox 笔记

把灵感沉淀进你的笔记体系：

1. 去「设置 → 发布配置 → inBox 笔记」配置 Token（支持完整 URL / 内网 URL / 纯 Token 三种格式，点「发送测试笔记」验证）
2. 在灵感详情页打开分发中心，选「**发送到 inBox」**
3. 标题 + 润色稿会作为一条笔记存进 inBox（这是 PRO 功能）

### 生成 AI 封面

分发中心的封面相关入口会调用 AI 生成封面：

1. 选好目标平台（公众号 / 小红书风格）
2. AI 自动提炼出不超过 8 个字的主标题 + 一句副标题，渲染成 1080×460 的封面图
3. 封面可保存、分享，或随图文同步到公众号

### 其他分发方式

| 入口 | 用途 |
|------|------|
| 发送文本 | 以纯文本发到微信、邮件等其他 App |
| 生成分享图 | 生成小红书风格精美分享卡片 |
| 导出录音 | 导出原始音频文件 |

分发中心会按你当前看的是「原始稿」还是「润色稿」来发送对应版本。

## AI 灵感观察

在灵感详情页可以触发「**灵感观察**」，让 AI 基于你的分身背景对这段内容做一段客观评价，帮你发现思维里的闪光点或盲点，启发更深层的思考。每次约 100 字，精炼不啰嗦。

## 桌面小组件和快捷录音

灵感往往来得突然，inVoice 提供三种「秒开即录」的方式：

| 方式 | 怎么用 |
|------|--------|
| **开屏直录** | 「设置 → 录音启动偏好」开启，App 一打开就自动录音 |
| **桌面小组件** | 桌面长按添加 inVoice 小组件，一键开始录音 |
| **通知栏磁贴** | 下拉通知栏添加 inVoice 磁贴，点一下快速录音 |

::: tip 录音启动偏好
「设置 → 录音启动偏好」里集中管理这两个开关：开屏直录、记录前选择分身。两个选项有逻辑互斥保护，避免冲突。
:::

## 数据备份

你的录音和数据默认全部存在本地。进「设置 → 数据管理」做备份管理：

- **手动备份**：随时创建一份本地备份
- **自动备份**：开启后，充电 + 连 WiFi 时每天自动备份一次
- **导入导出**：打包成 ZIP 文件，方便迁移到新设备，或从 ZIP 恢复

::: tip 永久版额外权益
永久版（FOREVER）包含云备份能力，权益跨设备登录后继承。
:::
