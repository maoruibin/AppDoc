# 更新日志

## 0.0.2
> 更新时间：2026/05

- **新增：AI 转写功能，支持多个 AI 引擎（GLM/DeepSeek/自定义）**
- **新增：AI 文本润色，支持语法纠正、摘要生成、内容优化**
- **新增：录音书签功能，录音和播放时可添加时间标记**
- **新增：项目管理，支持创建/编辑/删除录音文件夹**
- **新增：桌面小组件，一键快速录音**
- **新增：快捷设置磁贴，通知栏快速启动录音**
- **新增：数据自动备份（WiFi + 充电时）**
- **新增：ZIP 格式数据导入导出**
- 新增：A-B 循环播放
- 新增：变速播放
- 新增：WAV 自动转 AAC 格式
- 新增：AI 自动生成录音标题
