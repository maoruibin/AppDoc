# 隐私政策

- 更新日期：2026 年 5 月 11 日
- 生效日期：2026 年 5 月 11 日

北京小茅屋科技有限公司（以下简称"我们"）深知个人信息对你的重要性，并承诺在符合法律法规的前提下，以最小化、透明、可控的原则保护你的隐私与数据安全。请在充分阅读并理解本政策后使用我们的产品与服务。

## 一、我们如何收集和使用你的信息

inVoice 语记 遵循"本地优先、最小收集"的原则：

- **本地数据**：你的录音文件、转写文本及相关信息默认存储在你的设备本地数据库中；我们不主动将该数据上传到我们的服务器。
- **不采集设备标识**：我们不采集设备唯一标识（如 IMEI、IMSI、OAID 等）。
- **不内置统计 SDK**：本软件不内置第三方行为统计 SDK。

## 二、本地存储与备份

- **本地存储**：inVoice 语记 的所有数据默认保存在你的设备本地。你可以通过应用内功能进行数据导出与备份。
- **手动备份**：你可以在应用内手动创建备份文件。
- **自动备份**：开启后，在充电且连接 WiFi 时自动执行每日备份。备份文件存储在设备本地。
- **导出导入**：支持将数据打包为 ZIP 文件导出，以及从 ZIP 文件导入恢复。

## 三、AI 转写数据处理

当你使用 AI 转写功能时：

- 音频数据会通过 API 发送至你所配置的 AI 服务（如 GLM、DeepSeek 或你自定义的 API）进行语音识别处理。
- inVoice 语记 本身不存储、不中转你的音频内容。
- 音频数据的处理和存储方式以你所选 AI 服务的隐私政策为准。
- 你可以随时在设置中关闭自动转写功能，改为手动触发。

## 四、我们如何共享、转让、公开披露你的信息

我们不会向任何无关第三方提供、出售、出租或交易你的个人信息，除非：

1. 事先获得你的明确同意；
2. 依据法律法规的规定或有权机关的合法要求；
3. 为保护我们及关联方、用户或社会公共利益免遭损害。

## 五、权限使用说明

为提供相关功能，inVoice 语记 可能请求以下设备权限（实际以应用内提示为准）：

| 权限 | 用途 |
|------|------|
| 麦克风（RECORD_AUDIO） | 录制音频 |
| 存储权限 | 保存录音文件、备份数据 |
| 网络权限（INTERNET） | AI 转写服务调用 |
| 前台服务（FOREGROUND_SERVICE） | 后台持续录音 |
| 通知权限 | 显示录音状态通知 |

你可在系统设置中管理或关闭权限，但可能影响相关功能的正常使用。

## 六、你的权利

你享有对个人信息的访问、更正、删除等权利：

- **访问/管理**：可在应用内查看、播放、删除你的录音数据。
- **导出**：可通过导出功能将所有数据保存到本地。
- **删除**：可在应用内删除录音数据；删除后不可恢复。
- **撤回授权**：可在系统设置中撤回对相关权限的授权。

## 七、未成年人保护

我们的产品与服务主要面向成年人。我们不会主动收集未成年人的个人信息。如发现存在未成年人信息被不当收集，我们将尽快删除相关数据。

## 八、政策更新

我们可能会适时修订本隐私政策。对于重大变更，我们会通过应用内公告或同等显著的方式通知，并提供合理的过渡期。若你不同意该等变更，可停止使用我们的服务；你继续使用即表示同意受更新后的隐私政策约束。
