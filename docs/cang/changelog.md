# 更新日志

本页面记录仓咚咚应用的版本更新历史。

# v1.3.0

> 发布日期: 2026/08

## 新增功能
- **分类支持 emoji 表情图标**：150+ 彩色表情可选，记账更有个性
- **图标选择器全新升级**：图标和表情双 Tab 切换，支持搜索
- **「恢复默认分类」入口**：分类管理页新增，删错的分类随时找回

## 功能改进
- **取消系统分类限制**：所有分类均可自由编辑名称、图标和类型
- **删除分类自动迁移**：历史交易自动归入替代分类，数据不丢失
- **崩溃日志落盘**：异常情况可导出日志辅助排查问题

# v1.1.0

> 发布日期: 2026/07

## 新增功能
- **全新应用图标**：红金配色品牌图标
- **资产搜索**：首页新增搜索入口，支持按名称、备注、标签、机构等多维度搜索

- **全新主题色系**：主色改为图标红 #A01010，危险色调整为橙色，与品牌图标统一
- **全新设计语言**：全局统一视觉风格，白卡片+细边框+灰阶层级
- **首页精简**：移除记账模块，专注资产管理，底部导航精简为资产+我的
- 资产详情页重设计：卡片式布局，字段横排，状态色 token 化
- 添加资产/应收资产表单：分组卡片+填充式输入框
- 资产分析页重写：占比条+进度条替代饼图
- 关于页/导入导出页/设置页全面适配新设计风格
- 资产列表性能优化：排序过滤结果缓存
