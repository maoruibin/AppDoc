# 更新日志

本页面记录仓咚咚应用的版本更新历史。

# v1.1.2

> 发布日期: 2026/07

## 功能改进
- **主题色调整为蓝色系**（#0060B0），与应用图标统一
- **状态栏沉浸式优化**：透明背景透出 AppBar 实际色，滚动时跟随 tint 渐变
- 设置页全面重设计：白卡片+细边框，与主应用风格统一
- 分类管理页重设计：卡片式列表+拖拽手柄+图标方块
- 数据管理页重设计：备份/导入导出全面适配新风格
- 排序按钮图标优化：更直观的排序图标
- 危险色调整为橙色（#EA580C），避免与主题色冲突

# v1.1.0

> 发布日期: 2026/07

## 新增功能
- **全新应用图标**：红金配色品牌图标
- **资产搜索**：首页新增搜索入口，支持按名称、备注、标签、机构等多维度搜索
- **资产回收站**：删除资产保留 30 天，支持恢复和彻底删除

## 功能改进
- **全新主题色系**：主色改为图标红 #A01010，危险色调整为橙色，与品牌图标统一
- **全新设计语言**：全局统一视觉风格，白卡片+细边框+灰阶层级
- **首页精简**：移除记账模块，专注资产管理，底部导航精简为资产+我的
- 资产详情页重设计：卡片式布局，字段横排，状态色 token 化
- 添加资产/应收资产表单：分组卡片+填充式输入框
- 资产分析页重写：占比条+进度条替代饼图
- 关于页/导入导出页/设置页全面适配新设计风格
- 资产列表性能优化：排序过滤结果缓存

## 问题修复
- 修复资产详情页在资产被删除后崩溃红屏
- 修复导入数据后内存缓存不刷新
- 修复资产列表页顶部标题行布局溢出
