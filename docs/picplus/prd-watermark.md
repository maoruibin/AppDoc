# PRD：自定义水印功能

> 版本：v1.0 | 日期：2026-04-16 | 状态：草案

---

## 一、背景与目标

### 1.1 背景

PicPlus 作为图床管理工具，用户上传的图片经常被第三方直接引用。部分用户（博客作者、自媒体、设计师）有明确的防盗图和品牌标识需求，目前应用内无任何水印能力。

### 1.2 目标

- 为用户提供上传前的图片水印处理能力
- 支持文字水印和图片水印两种形式
- 提供灵活的位置、大小、透明度控制
- 水印功能作为可选模块，不影响现有上传流程

### 1.3 成功指标

- 水印功能上线后，设置页水印相关配置入口点击率
- 启用水印用户的上传成功率不低于现有水平（水印处理不应导致上传失败）

## 三、功能设计

### 3.1 整体流程

```
选图 → [水印开关开启?] → 是 → 应用水印处理 → 上传
                      → 否 → 直接上传
```

水印处理在「选图完成」与「上传开始」之间，作为可选的预处理步骤。

### 3.2 功能模块

#### 3.2.1 水印开关（P0）

- **位置**：设置页 → 高级设置（SettingAdvanceActivity）
- **行为**：全局开关，开启后所有上传默认附加水印
- **存储**：SharedPreferences（`CommonSettings`）
- 单次上传时可通过上传确认页临时关闭

#### 3.2.2 文字水印（P0）

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 水印文字 | 用户自定义输入，最多 50 字 | 空（首次提示输入） |
| 字体大小 | 小 / 中 / 大 三档 | 中 |
| 字体颜色 | 白色 / 黑色 / 自定义 | 白色 |
| 描边 | 开/关（增强在复杂背景上的可读性） | 开 |

#### 3.2.3 图片水印（P1）

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 水印图片 | 从相册选取一张图片作为 Logo | 无 |
| 缩放比例 | 滑块调节，10% ~ 50% | 20% |

- 选取的图片缓存到应用私有目录，避免重复选择
- 支持透明背景 PNG 图片

#### 3.2.4 水印位置 — 九宫格（P0）

提供 9 个预设位置，以九宫格形式展示：

```
┌─────────┬─────────┬─────────┐
│  左上    │  上中    │  右上    │
├─────────┼─────────┼─────────┤
│  左中    │  居中    │  右中    │
├─────────┼─────────┼─────────┤
│  左下    │  下中    │  右下    │
└─────────┴─────────┴─────────┘
```

- 默认位置：右下角
- 每个位置对应一组 (x, y) 坐标计算规则（含 padding 偏移）
- 边距 padding：16dp（适配不同分辨率）

#### 3.2.5 透明度（P0）

- 范围：10% ~ 100%
- 默认值：50%
- 滑块调节，实时预览效果

#### 3.2.6 水印大小（P1）

- 文字水印：通过三档（小/中/大）控制，无需滑块
- 图片水印：滑块控制，范围 10% ~ 50%（相对于原图短边的比例）

### 3.3 水印配置页

### 4.3 核心逻辑

```kotlin
// WatermarkConfig.kt
data class WatermarkConfig(
    val enabled: Boolean = false,
    val type: WatermarkType = WatermarkType.TEXT,
    val text: String = "",
    val textSize: WatermarkSize = WatermarkSize.MEDIUM,
    val textColor: Int = Color.WHITE,
    val strokeEnabled: Boolean = true,
    val imageUri: String? = null,
    val imageScale: Float = 0.2f,
    val position: GridPosition = GridPosition.BOTTOM_RIGHT,
    val opacity: Int = 50  // 10-100
)

enum class WatermarkType { TEXT, IMAGE }
enum class WatermarkSize { SMALL, MEDIUM, LARGE }
enum class GridPosition {
    TOP_LEFT, TOP_CENTER, TOP_RIGHT,
    MIDDLE_LEFT, MIDDLE_CENTER, MIDDLE_RIGHT,
    BOTTOM_LEFT, BOTTOM_CENTER, BOTTOM_RIGHT
}
```

```kotlin
// WatermarkProcessor.kt 核心接口
object WatermarkProcessor {
    fun apply(bitmap: Bitmap, config: WatermarkConfig): Bitmap
}
```

### 4.4 注意事项

- **大图处理**：超过 4096px 的图片需做 inSampleSize 采样处理后再加水印，避免 OOM
- **EXIF 保留**：使用 `ExifInterface` 读取原图 EXIF，水印处理后写回
- **格式保持**：PNG 输入保持 PNG 输出，JPEG 输入保持 JPEG 输出
- **异步处理**：水印绘制在 IO 线程执行，不阻塞 UI

## 七、FAQ

**Q：水印会增加多少图片体积？**
A：文字水印通常增加 < 5%，图片水印取决于 Logo 大小，一般在 10% 以内。

**Q：水印处理会拖慢上传速度吗？**
A：文字水印处理通常在 100ms 以内（普通照片），批量上传时并行处理，用户感知不明显。大图可能需要 500ms-1s。

**Q：能支持拖拽自定义位置吗？**
A：当前版本暂不支持，采用九宫格预设位置。自定义拖拽可作为后续迭代需求。
