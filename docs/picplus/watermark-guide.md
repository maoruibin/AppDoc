# 水印使用指南

咕咚云图支持在**上传图片时自动添加水印**，无需额外步骤，一键保护你的版权或植入个人 logo。

水印功能为 **PRO 专属**，升级 [PRO](/inbox/pay) 后可解锁全部自定义能力。

## 功能入口

打开咕咚云图 → 右上角「设置」→ 找到 **水印设置**（摘要文案为「上传图片时自动添加自定义水印」），点进去就是水印配置页。

配置页从上到下依次是：总开关、实时预览、水印类型、内容与样式参数。右上角「保存」按钮统一提交，保存后立刻对后续上传生效。

## 启用与关闭

页面顶部的「**启用水印**」开关控制整个功能的总开关：

- 打开：上传时自动按当前配置给每张图打水印。
- 关闭：上传时不再添加任何水印，原样上传。

开关下方的预览图会同步变化：开启时预览清晰，关闭时预览变暗，让你一眼看出当前是否生效。

::: tip
只打开总开关、但不填水印文字时不会生效（文字水印至少要有内容）。保存前先确认文字框有内容，或已选好图片水印的 logo。
:::

## 两种水印类型

水印支持两种类型，在「水印类型」处单选切换：

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 文字水印 | 在图片上绘制一段自定义文字 | 版权署名、个人 ID、博客地址 |
| 图片水印 | 在图片上叠加一张 logo 图片 | 品牌 logo、二维码、个人图标 |

::: warning 图片水印为 PRO 功能
非 PRO 用户切换到「图片水印」时会弹出升级提示并被切回文字水印。PRO 用户保存的图片水印配置（含已选 logo）会持久保留。
:::

## 文字水印

文字水印支持以下自定义项：

### 水印文字

- 输入框最多 **50 个字符**，单行显示。
- 常见填法：你的昵称、`@gudong`、博客域名、版权声明等。

### 水印位置（九宫格）

提供 9 个位置可选，点选高亮即可：

| | 左 | 中 | 右 |
|---|---|---|---|
| **上** | 左上 | 顶部居中 | 右上 |
| **中** | 左侧居中 | 正中 | 右侧居中 |
| **下** | 左下 | 底部居中 | **右下（默认）** |

::: tip 位置自定义需 PRO
非 PRO 用户只能使用默认的「右下角」，点其他格子会弹出升级提示。PRO 用户可自由选择 9 个位置中的任意一个。
:::

### 字体大小

三档可选：**小、中（默认）、大**。非 PRO 用户只能使用「中」，「小」和「大」两档需升级 PRO。

实际字号会跟随系统屏幕密度自适应缩放，在不同分辨率的设备上观感一致。

### 字体颜色

可选 **白色（默认）** 或 **黑色**，根据底图的明暗选择对比度更高的那个。黑色为 PRO 专属。

### 描边

「描边」开关默认开启，作用是给文字加一圈与字色相反的描边（白字加黑边、黑字加白边），保证水印在任何背景上都清晰可读。一般建议保持开启。

### 透明度

滑块范围 **10% – 100%**，默认 50%。数值越低水印越淡，越不容易喧宾夺主。

## 图片水印

切到图片水印类型后，配置项切换为 logo 相关参数：

### 选择水印图片

点「**选择水印图片**」按钮，从系统相册中挑选一张 logo 图片。选好后下方会出现缩略图预览。

::: tip 图片建议
推荐使用背景透明的 PNG（如品牌 logo、二维码），这样叠加后不会遮挡底图内容。
:::

### 水印位置（九宫格）

和文字水印一样，9 个位置可选，PRO 用户可自由切换，非 PRO 用户限定右下角。

### 透明度

滑块范围 **10% – 100%**，默认 50%。

### 水印大小

滑块控制 logo 相对于**原图短边**的比例，范围 **10% – 50%**，默认 20%。比如底图短边是 1000px，20% 的 logo 宽度约为 200px。

## 上传时如何自动添加

水印是**上传流程的一个内置环节**，你不需要额外操作：

1. 像平时一样选择图片、点上传。
2. 云图在上传前（压缩步骤之前）会逐张读取当前水印配置。
3. 对每张图按配置绘制水印，生成一张带水印的临时图片。
4. 把带水印的图片替换原图进入后续的上传/压缩流程。
5. 上传完成后临时文件会自动清理。

::: warning 这些情况不打水印
- **总开关关闭**：完全跳过。
- **文字水印未填内容**：跳过该图，按原图上传。
- **GIF 动图**：为避免破坏动画，一律跳过不打水印。
:::

::: tip 水印只影响上传后的图
水印处理发生在上传链路里，不会修改你相册里的原图。处理后的临时图保存在应用缓存目录，上传或失败后会被清理。
:::

## 免费版与 PRO 能力对比

| 能力 | 免费版 | PRO 版 |
|------|--------|--------|
| 文字水印总开关 | 可用 | 可用 |
| 默认配置（右下 / 中号 / 白字 / 描边 / 50% 透明度） | 可用 | 可用 |
| 自定义水印位置（9 宫格） | 仅右下角 | 全部 9 个位置 |

升级入口在点击受限选项时弹出的提示框中，点「升级 PRO」即可跳转支付页。

## 常见问题

### 开了水印但上传后图上没水印？

按以下顺序排查：

1. 确认「启用水印」总开关是开的。
2. 文字水印要确认输入框里有内容；图片水印要确认已选好 logo。
3. 该图是不是 GIF？GIF 默认跳过。
4. 是否在非 PRO 状态下选了被锁定的选项？保存时这些项会回落到默认值。

### 换了手机水印配置还在吗？

水印配置存在本机设置中。如果通过云图内置的数据导出/导入或 WebDAV 备份恢复过设置，配置会随之迁移；否则新设备上需要重新设置一次。

### 图片水印会不会让原图很模糊？

不会。水印绘制使用原图尺寸画布，并按原图短边比例缩放 logo，导出时 JPEG 质量 95、PNG 无损，画质损失几乎不可见。同时会保留原图的 EXIF 信息（拍摄时间、设备型号、方向等）。
