# 配置 又拍云 为个人图床

## 写在前面

使用又拍云做图床之前，需要先注册又拍云账号：

[https://console.upyun.com](https://console.upyun.com)

又拍云的对象存储以「服务」为单位，每个服务对应一个 Bucket，需要绑定一个加速域名作为图片的外链地址。

> 域名要求：绑定的加速域名需要已完成 ICP 备案。还没有域名的话建议先用其他图床，或使用阿里云 / 腾讯云等不需要自备域名的方案。

## 配置需要的参数

+ Bucket（服务名称）
+ Operator（操作员账号）
+ Operator Password（操作员密码）

## 第一步：创建存储服务

打开又拍云控制台，进入「对象存储」→「创建服务」：

1. **服务名称**：自定义，如 `gudong-img`，这个就是 App 里的 Bucket。
2. **加速域名**：填一个你已备案的域名（或子域名），如 `img.example.com`，上传的图片将通过这个域名访问。
3. 其余参数保持默认。

创建完成后，在服务列表可以看到服务名和绑定的域名，记下来备用。

## 第二步：创建操作员

进入控制台的「操作员管理」（或在服务的「权限管理」中）：

1. 点击「创建操作员」，设置操作员名（Operator）和密码（Operator Password）。
2. 创建后为该操作员**授权刚创建的服务**，权限给「读取 / 写入 / 删除」。

把 Operator 和 Operator Password 复制保存，发送到手机备用。

## 第三步：在 App 中填写

| 表单项 | 填什么 | 示例 |
|---|---|---|
| Bucket | 服务名称 | `gudong-img` |
| Operator | 操作员名 | — |
| Operator Password | 操作员密码 | — |

**高级配置**（一般不用动）：

+ **Endpoint / 域名**：留空即可，App 默认使用又拍云标准接口地址。
+ **存储路径**：图片在服务里的目录前缀，如 `images/blog`，留空则传到根目录。
+ **自动按日期分目录**：默认开启，图片按 `2026/11/02/` 这样的日期目录归类。
+ **URL 后缀**：如配置了又拍云图片处理（缩略图、水印等），可填处理后缀拼到最终链接上，留空则用原图。

图片外链形如 `https://<加速域名>/<存储路径>/<文件名>`。

填写完毕后，点击右上角的「测试一下」，测试成功后点小对勾保存即可正常使用。测试失败时按弹窗提示检查，最常见的原因是操作员未授权该服务、或密码复制不完整。

## 关于 PRO

又拍云属于 PRO 图床：免费用户可以先试用上传 10 张（按成功上传次数累计），确认好用后再升级 PRO 不限量使用。上传记录的删除（本地 + 远端）不占额度，全免费。
